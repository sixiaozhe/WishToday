# 功能补齐清单

> 日期：2026-11-06
> 目的：对照滴答清单调研，列出当前实现与目标之间的功能缺口，并给出优先级。
> 图例：✅ 已完成 / 🟡 部分完成 / ⬜ 未实现

---

## 1. 当前已经具备

- 本地 SQLite-WASM + OPFS 数据层、单档案。
- 任务增删改查、完成/取消完成、删除/恢复、已跳过历史、放弃/重新开始、任务副本。
- 清单（项目）、文件夹、标签、优先级、日期/时间/结束日期/跨天。
- 列表、看板、时间线、四象限、日历 7 视图（日/周/月/年/日程/多日/多周）。
- 日历拖拽改期/改时间、边缘改时长、重复任务单周期覆盖、列表拖动成子任务/拖到清单。
- 标准重复、法定工作日/节假日、Ebbinghaus 引擎；重复任务跳过/恢复/自动合并；间隔/星期/结束条件/完成重复。
- 多提醒、稍后提醒、提醒中心、浏览器通知 + 应用内 toast。
- 全局搜索、保存过滤器、智能清单（明天/最近 7 天/已放弃）、批量操作、撤销/重做。
- 子任务、检查事项、进度、Markdown 笔记与预览、附件、评论、任务模板、任务链接 `[[标题]]`。
- 标签管理、文件夹/清单编辑、设置页、JSON/CSV/ICS 备份恢复与自动备份。
- 专注（番茄/正计时）、习惯打卡、纪念日/倒数日、笔记、摘要、统计与成就。
- 农历/主要节日标签、2026 法定节假日 `休/班` 徽标。
- 浅色/深色主题、日历显示时段设置。

## 5. 建议的补齐顺序

### 第一批：让任务系统完整

1. ✅ 子任务 + 检查事项 + 进度（基础完成）。
2. 标签管理 + 文件夹/分组。
3. 全局搜索 + 过滤器 + 智能清单补齐（明天/最近 7 天/已放弃/摘要）。
4. 数据备份/恢复/导出（JSON/CSV/ICS），并做恢复演练。

> 这一批完成后，才算“可以替代滴答记录日常任务”。

### 第二批：让时间管理完整

5. 提醒完善（多提醒、稍后提醒、持续提醒、提醒中心）。
6. 重复规则 UI（农历、自选日期、完成重复、结束条件）。
7. 日历订阅（ICS）+ 固定时间/固定时区 + 辅助时区。
8. 看板 + 时间线 + 四象限。

### 第三批：模块与平台

9. 专注、习惯、纪念日、笔记/摘要、统计/成就。
10. Tauri 原生能力、CLI/MCP、移动端、导入、多档案、同步/共享。
