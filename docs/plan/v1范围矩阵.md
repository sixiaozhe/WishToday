# v1 范围矩阵

> 配套：`docs/plan/复刻实施差距分析与路线图.md`
> 目的：把“大部分功能”变成可排期、可验收、可拒绝的范围
> 日期：2026-11-05

---

## 1. 产品定义

**一句话**：一个本地优先、无需账号、无需订阅的个人任务与时间管理应用，覆盖 Windows 桌面与 Web/PWA；功能对标滴答清单的核心体验，视觉语言保持一致，但不复制其品牌资产。

### 1.1 范围原则

1. **本地优先**：除日历订阅等显式联网能力外，全部功能离线可用；桌面与 Web/PWA 都使用本地库。
2. **无账号、无会员、无配额**：首次启动创建本地档案；不做登录、支付、会员墙。v1 单档案。
3. **视觉语言一致，资产原创**：布局层级、信息密度、主要交互路径与滴答清单保持一致；Logo、图标、插画、空态文案、主题命名、字体选用必须原创或合法授权，不做像素级复制。
4. **先闭环，后长尾**：先保证“记录 → 排期 → 提醒 → 完成 → 回顾”可靠，再做协作和平台集成。
5. **数据可带走**：JSON 全量备份、通用 CSV/ICS 导出；不锁定用户。
6. **默认不收集数据**：无遥测；崩溃报告需用户显式开启。

### 1.2 “大部分功能”的量化口径

v1 覆盖滴答清单帮助中心中**任务、组织、视图、提醒/重复、专注、习惯、纪念日、笔记、搜索、备份**这 10 个核心域，并同时交付 **Windows 桌面 + Web/PWA**；不覆盖**多人协作、微信生态、官方云同步、AI、原生小组件、课表 OCR**等依赖平台或服务端的长尾能力。

## 3. 功能范围

标记说明：

- **Must**：v1 发布阻塞项。
- **Should**：v1 尽量做；可顺延到 v1.1，不影响发布。
- **v1.1**：确认不在 v1，后续版本再做。
- **Won't**：当前路线图内不做，避免范围蔓延。

### 3.8 视觉一致性边界

“和滴答一致”按以下方式落地：

| 保持一致 | 必须原创/授权 | 明确不做 |
|---|---|---|
| 布局层级（侧边栏、列表、详情、日历） | Logo、应用图标、勋章图标 | 像素级复刻 |
| 信息密度、行高、留白节奏 | 插画、空态图、引导图 | 直接截取官方界面 |
| 主要交互路径（快速添加、拖动、右键） | 文案、提示语、主题命名 | 内置官方主题/铃声/字体 |
| 色彩语义（优先级、清单色、四象限） | 字体（使用开源字体） | 复制官方付费素材 |
| 快捷键习惯与操作反馈 | 音效、动效素材 | 使用官方商标/名称 |

> 目标：用户从滴答清单迁移过来“不用重新学”，但一眼能看出是另一个产品。

## 4. 明确不做（v1）

| 不做 | 原因 |

| AI 助手/语音/录音总结 | v1.1；避免拖慢核心闭环 |
| 滴答清单 CSV 专用兼容 | 不做官方备份格式逆向；通用 CSV/ICS 足够 |
| 官方主题/图标/铃声/字体 | 版权风险；使用原创或开源授权资产 |
| 像素级复刻官方界面 | 版权/商标风险；只做视觉语言一致 |
| 课表 OCR/教务网导入 | 格式多样、维护成本高；后置 |
| 原生小组件/手表/控制中心 | 平台原生开发；移动端后置 |
| 位置提醒 | 移动端原生能力；桌面无 |
| 遥测/广告/增长功能 | 与本地优先、隐私目标冲突 |

## 6. 决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 首发平台 | Windows 桌面 + Web/PWA | 桌面验证完整能力，Web 覆盖跨平台与轻量使用 |
| 桌面框架 | Tauri 2 | 体积小、原生能力可通过插件/自定义 Rust 补齐 |
| 数据层 | SQLite + WAL + FTS5 | 成熟、可迁移、支持全文搜索 |
| Web 存储 | SQLite-WASM + OPFS（已验证） | 直接执行 `schema-v1.sql`；COOP/COEP 缺失时内存降级并提示 |
| UI | React + TypeScript | 生态成熟，桌面/Web 同构复用 |
| 领域层 | 纯 TypeScript | 可在桌面/Web/CLI/MCP 复用，便于单测 |
| 富文本 | Markdown 为真源 | 可导出、可搜索、避免 HTML 锁定 |
| 重复任务 | 自研展开器 | 农历/节假日/完成重复无法直接套 RRULE |
| 时间线 | v1 Must | 项目管理核心视图，不能后置 |
| 多档案 | v1.1 | Schema 已预留，v1 单档案降低复杂度 |
| AI | v1.1 | 不拖慢核心闭环；后续自带 Key |
| 账号 | 无 | 本地档案 + 可选应用锁 |
| 付费 | 无 | 全功能解锁；技术保护上限代替商业限额 |
| 同步 | v1 不做 | 保留 `device_id`/`change_log` 供未来扩展 |
| 协作 | v1 不做 | 单独立项，避免拖垮核心 |
| 视觉 | 与滴答视觉语言一致，资产原创 | 降低迁移学习成本，同时规避商标/版权风险 |
| 数据格式 | JSON + 通用 CSV + ICS | 可迁移、可互操作；不做滴答专用兼容 |

## 7. v1 发布出口标准

必须全部满足：

- [ ] 连续自用 30 天，无 P0 数据丢失/重复/错乱。
- [ ] 10 万任务性能达标；搜索、滚动、启动不卡顿。
- [ ] 重复规则属性测试通过；跨时区/DST/农历/节假日用例通过。
- [ ] 备份 → 清空 → 恢复，数据与附件完整。
- [ ] 应用关闭/休眠/重启后，提醒不丢；错过提醒有明确补偿。
- [ ] Windows 安装包可安装/卸载/自动更新；无管理员权限依赖。
- [ ] Web/PWA 可安装、离线可写、刷新不丢；浏览器兼容矩阵通过。
- [ ] 时间线视图可缩放、拖动改期/改时长；与日历/列表数据一致。
- [ ] 核心流程键盘可完成；无阻塞性无障碍问题。
- [ ] 无官方商标/图标/文案/主题资产；第三方许可证审计通过。
- [ ] 视觉评审通过：布局/密度/交互与滴答一致，但不含复制资产。
