# 打造专属纪念页

> 原文: https://help.dida365.com/articles/7322503597483098112
> articleId: 680f1ce71c42a13a390ba1ae

每个倒数纪念日都承载着独特的意义，为重要的日子设计专属的视觉印记，让每一天的等待都充满温度与期待。

# 设置样式入口

倒数纪念日支持设置样式，你可以为你每个倒数纪念日挑选一款心仪的样式，让它在你的列表中更加醒目、有仪式感。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入一个倒数纪念日页面，点击右下角的「样式」按钮，即可开始为这个纪念日挑选样式。

![l](https://cdn.dida365.cn/hc/all/987d5c8a6a4ca038ed1ba999deb57f0e.png)


::::

::::tab [desktop]
将鼠标悬停在某个倒数纪念日卡片上，点击右上角的「...」-「样式」按钮，即可进入样式设置界面。

![](https://cdn.dida365.cn/hc/all/9c8c63a9251b0ae70127e843a4ecea86.png)



::::

:::::

# 超多样式
滴答清单提供了丰富多样的样式选项，满足你对不同重要日子的表达需求。无论是简洁大方、温暖治愈，或者是萌趣卡通、热情多巴胺......都可以找到契合心情的风格。

![](https://cdn.dida365.cn/hc/all/0a6e46a4c8822469b996a31a40f929cf.png)

# 自定义图片

当你选择了「图片样式」后，还可以进一步替换背景图片，赋予每个纪念日独一无二的故事和情感。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
选择图片样式后，切换到「图片」选项，即可替换图片或者上传心仪的背景图，让每一个纪念日更加生动有趣。


![l](https://cdn.dida365.cn/hc/all/18f99e3f02e5d71247cd24dc9087b2ca.png)

::::

::::tab [desktop]

在样式编辑窗口，点击「切换图片」，可以上传新的背景图片，让每一个纪念日更加生动有趣。


![](https://cdn.dida365.cn/hc/all/3393ec38036fdecceed5d78f3dd179cf.png)




为每个倒数纪念日设置样式后，你的页面会变得更加丰富而有温度。

## 天周年显示切换
当你看到「已经恋爱 2000 天」，是不是也想知道这是多少年，或是多少周？
:::::tabContainer [mobile|desktop]

::::tab [mobile]
点进一个倒数纪念日，在倒数纪念日详情页中，点击中间的天数，就能在**天、年、周**三种单位间快速切换，用不同的单位更直观地感受时间的流逝。

::: video https://cdn.dida365.cn/hc/all/784e823b98a662369220bb5a62bf123b.mp4
:::


::::

::::tab [desktop]
点击倒数纪念日卡片上的天数，就能在**天、年、周**三种单位间快速切换，用不同的单位更直观地感受时间的流逝。

![](https://cdn.dida365.cn/hc/all/4bdb06441f15809607d5a83729d6fc2b.png)

# 添加备注
想记录关于这一天的小故事，或者留下一些提醒信息？在纪念日详情页中，你可以点击左下角的「备注」按钮，为这个日子添加一段文字记录。

写备注时，点击左下角的「**插入时间**」按钮可以快速插入当前时间；你还可以设置备注是否「**在详情页中显示**」，让重要信息一眼就能看到。
