# 注册与登录
注册与登录主要有3种方式：
1. 手机：使用手机号注册，填写短信验证码，即可完成注册。
2. 邮箱：使用邮箱注册时，点击邮件链接进行验证，即可完成注册。
3. 第三方账号：你可以使用通过微信、微博、QQ、Apple ID快捷注册进行登录。

# 账号绑定
一个账号可以绑定手机、邮箱、微信和QQ。绑定后可以实现更多功能，例如：

* 绑定后微信，除了使用微信快捷登录之外，还可以在微信中创建和查询任务。
* 绑定手机号或者邮箱后，在忘记密码时，可以通过手机号或者邮箱找回。

# 常见问题
::: spoiler 忘记密码怎么办？
如果你忘记了登录密码，在登录页面中点击登录框下方的忘记密码，即可进行密码重置。

在网页中输入你的注册邮箱或手机号，点击重置密码后，在注册邮箱中查收重置密码链接或在手机短信中查收验证码，按照提示重新设置密码即可。
:::
