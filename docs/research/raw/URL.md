# URL

> 原文: https://help.dida365.com/articles/7190979764138541056
> articleId: 6630a1c947c89fff9258e291

你可以通过 URL 链接，将第三方应用内容订阅到滴答清单中，以便在滴答清单中查看这些事件，并获得提醒。

# 添加日历

:::::tabContainer [mobile|desktop]

::::tab [mobile]
在「设置」-「导入与关联应用」-「日历」，选择「URL」，输入第三方日历的 URL 链接即可订阅成功。

![--65.97%](https://cdn.dida365.cn/hc/all/e157b64c41fafee873b22fac42ef1755.png)
::::

::::tab [desktop]
点击「头像」-「设置」-「关联与导入」，选择「URL」，输入第三方日历的 URL 链接即可订阅成功。


![--75.32%](https://cdn.dida365.cn/hc/all/0873ece4122a12fc3c76baccfa6249cf.png)


![--75.32%](https://cdn.dida365.cn/hc/all/c6ec0ac98c8bf5adad914f9ea34cd585.png)


::::

:::::



# 获取 Todoist 清单链接
右键需要订阅的项目，选择「订阅项目日历」，复制项目链接粘贴到滴答清单订阅 URL 日历输入框中，即可成功订阅。

![--81.73%](https://cdn.dida365.cn/hc/all/1968f22adf591d619bcf919cc577ab72.png)

![--81.73%](https://cdn.dida365.cn/hc/all/a78466859f3c0151d1d7c9ec62a82d09.png)

# 获取 Google 日历链接
右键需要订阅的日历，选择「设置和共享」，找到「获取共享链接」，复制日历的功效链接粘贴到滴答清单订阅 URL 日历输入框中，即可成功订阅。

![--81.73%](https://cdn.dida365.cn/hc/all/b6f08d4697a9b537156a9c0b6f03febe.png)

![--81.73%](https://cdn.dida365.cn/hc/all/77bdc4a979c3dc153294b70ec1a2aad5.png)


# 常见问题
:::::: spoiler 如何退订日历？

:::::tabContainer [mobile|Web|macOS|Windows]

::::tab [mobile]
在订阅日历的编辑页面，点击取消订阅即可退订日历。


![m](https://cdn.dida365.cn/hc/all/b1be07c49d71c9299f368db3e8bf3fbc.png)

::::

::::tab [Web]
在「设置」-「关联与导入」点击想退订日历旁的「编辑」，取消订阅即可。

![--73.2%](https://cdn.dida365.cn/hc/all/505f039ba0405d1c793cfb2bdb1a9200.png)

![--73.2%](https://cdn.dida365.cn/hc/all/b228036bf6d600c2ae2320a5c4fbba4b.png)


::::

::::tab [macOS]

在「日历订阅」左侧栏中选择想要退订的日历，点击「-」，即可退订。

![](https://cdn.dida365.cn/hc/all/22afed3bd85d402a4ce876d3443db44b.png)

::::

::::tab [Windows]
在「设置」-「日历订阅」点击一下要退订的日历，点击「取消订阅」，即可退订。


![--57.06%](https://cdn.dida365.cn/hc/all/4b0551d4c6f5dd182bcadce8c3978262.png)
