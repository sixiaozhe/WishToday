# 用文件夹管理任务

> 原文: https://help.dida365.com/articles/6957521286893404160
> articleId: 62df50a3336d236a95d761f4

随着清单数量越来越多，可以使用文件夹来整理你的清单。 例如你可以创建「生活」文件夹，将「生活日常」、「购物」、「运动」等清单放入其中。

# 创建文件夹



::::tab [mobile]
- 方式一：拖动清单到另一清单上方，松手后，在弹窗内输入名称即可创建文件夹。


![m](https://cdn.dida365.cn/hc/all/c1411bbe0e22e25ed1ebb59e366c6c33.png)


- 方式二：点击右下角「添加」-「清单」，在清单编辑页「更多设置」-「文件夹」-「添加文件夹」，输入文件夹名称，点击完成即可创建成功。

![l](https://cdn.dida365.cn/hc/all/168545be5481a6a2d070aa38a1c1536e.png)

![l](https://cdn.dida365.cn/hc/all/ba1031ab186b4a66eda02bcda7c29a27.png)

::::



# 解散文件夹

在移动端可通过左滑、长按的方式，解散文件夹。在桌面端可通过右键，解散文件夹。
