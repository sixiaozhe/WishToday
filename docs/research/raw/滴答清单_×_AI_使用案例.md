AI 不仅可以帮助创建任务。随着任务和项目越来越多，AI 还可以帮助整理任务、规划时间、生成清单、拆解目标，甚至参与回顾与复盘。

下面分享一些实用的 AI 使用案例分享，你可以根据自己的工作习惯进行调整。

# 一、用 AI 管理任务
很多人刚开始使用 AI 时，最先想到的是：帮我创建一个任务。但随着任务越来越多，你会发现，真正耗费时间的往往不是记录任务，而是管理任务。

事实上，大多数任务系统失效，并不是因为记录得不够多，而是因为缺少持续整理和维护。这也是 AI 特别适合发挥价值的地方。相比手动逐个检查任务，AI 更擅长快速分析整个任务系统，帮助你整理与组织。

下面分享几个适合日常使用的场景。

## 整理收集箱

收集箱最大的价值，是帮助你快速记录。无论是突然冒出的想法、临时事项，还是暂时没有决定是否执行的计划，都可以先放进收集箱。

但如果长期不整理，收集箱很容易变成一个堆积区。随着任务不断增加，模糊任务越来越多，一些任务长期没有处理，很多事项甚至已经忘记为什么记录下来... 久而久之，收集箱里的内容越来越多，却越来越难以真正开始执行。

这时，可以尝试让 AI 帮你完成一次系统整理。

![--56.3%](https://cdn.dida365.cn/hc/all/4f870d04fe6c4b7a571d32eedad6f8c7.png)

**可复制参考的 Prompt：**

```

帮我整理收集箱中的任务。

请按以下步骤进行：

1. 检查收集箱中的新任务、未安排时间的任务、最近新增任务以及长期未处理任务。

2. 识别无法直接执行的模糊任务，并推荐更具体的行动描述。

3. 根据任务内容推荐：
- 所属清单
- 标签
- 优先级

4. 判断哪些任务需要安排时间：
- 优先级较高或有明确时间要求的任务，推荐安排到今天或本周
- 暂时没有明确时间要求的任务，继续保留在收集箱中

5. 识别长期未处理任务，并建议：
- 保留
- 延后
- 归档
- 删除

最后输出：

① 建议修改的任务
② 推荐移动的任务
③ 推荐安排时间的任务
④ 建议归档或删除的任务 
```

## 制定今日计划

很多时候真正让人感到压力的，是不知道应该先做什么。面对几十条待办事项，大脑会不断在各种任务之间切换，反而更难进入工作状态。

这时，可以让 AI 帮你完成当天的规划。

![--56.3%](https://cdn.dida365.cn/hc/all/0cb1e294fe0d75f2656d316088e3a038.png)

**可复制参考的 Prompt：**

```
帮我规划今天的任务安排。

请先分析：

- 今天已有时间的任务及固定安排
- 逾期任务
- 收集箱中的新任务

然后：

1. 推荐今天最重要的任务
2. 建议延期或放弃低价值任务
3. 判断今天还能承载多少任务
4. 根据优先级和任务时长生成时间安排
5. 保留适当缓冲时间

最后输出：

① 今日重点任务
② 建议延期任务
③ 今日时间安排
④ 今日注意事项
```

## 清理长期积压任务

任务系统最容易出现的问题之一，就是积压。有些任务已经存在几个月，却始终没有推进。每次看到它们都会产生压力，但又迟迟没有行动。

这时，可以让 AI 帮你进行一次任务大清理。

**可复制参考的 Prompt：**

```
帮我清理长期未处理任务。

请检查：

- 超过30天未更新任务
- 多次延期任务
- 长时间未完成任务

对于每个任务，请判断：

- 保留
- 重新拆分
- 延后
- 归档
- 删除

并说明原因。

最后输出：

① 建议保留任务
② 建议重新拆分任务
③ 建议归档任务
④ 建议删除任务
```

## 检查任务系统健康度

任务系统并不是建立一次就结束了。随着时间推移，系统会不断产生新的任务、新的项目和新的积压事项。

因此，定期维护系统同样重要。

**可复制参考的 Prompt：**

```
请帮我检查当前任务系统的健康状态。

请分析：

- 收集箱积压情况
- 未安排时间任务数量
- 模糊任务比例
- 长期未完成任务
- 当前任务负荷

然后告诉我：

1. 当前系统最大的风险是什么
2. 哪些地方最需要整理
3. 哪些任务应该优先处理
4. 哪些任务应该删除或归档

最后给出一份系统维护建议。
```

# 二、用 AI 复盘与总结
AI 不仅可以帮助你创建任务、安排计划，也可以帮助你回顾已经完成的事情。

当你持续使用滴答清单记录任务、安排日程、管理项目和追踪习惯后，这些数据本身就会成为一份有价值的个人记录。

相比手动翻看任务列表、统计完成数量和整理项目进展，AI 更擅长从大量任务记录中提取重点，帮助你看清自己的完成情况、推进节奏和时间投入。

下面分享 3 个适合日常使用的 AI 复盘场景。

## 每日复盘：回顾今天完成了什么

每天结束时，我们常常只记得自己很忙，却不一定清楚今天真正完成了什么。

这时，可以让 AI 根据当天的任务记录，帮你快速生成一份今日复盘。

它可以帮你总结今天完成了哪些任务、哪些事情被延期、今天的任务主要集中在哪些方面，以及明天应该优先处理什么。

**可以直接复制使用的 Prompt：**

```
帮我复盘今天的任务完成情况。

请分析：

- 今天完成了多少任务
- 主要完成了哪些事情
- 哪些任务没有完成或被延期
- 今天的任务主要集中在哪些方面
- 明天有哪些需要优先处理的事项

最后输出：

1. 今日完成概况
2. 重点完成事项
3. 未完成与延期任务
4. 今日状态总结
5. 明日建议
```

## 本周总结：回顾这一周的推进情况

一周结束后，单看每天的任务记录，很难判断这一周整体推进得怎么样。

AI 可以把过去一周的任务、项目和完成情况整理在一起，帮你看清这一周主要完成了什么、哪些项目推进最多、哪些事情被延期，以及下周需要继续关注什么。

![](https://cdn.dida365.cn/hc/all/28de4a885071b97eea9bf7eb0fcb17bb.png)

**可以直接复制使用的 Prompt：**

```

帮我总结本周的任务完成情况。

请分析：

- 本周完成了多少任务
- 本周主要推进了哪些项目或事项
- 哪些项目投入最多
- 有哪些重要进展
- 哪些任务被延期或仍未完成
- 下周需要继续关注什么

最后输出：

1. 本周完成概况
2. 主要推进事项
3. 重点项目进展
4. 延期与遗留任务
5. 下周关注重点

```

## 时间投入分析：看清长期重心

很多时候，我们以为自己把时间花在了某些重要事情上，但真实情况未必如此。

如果你长期使用清单、标签、日程、习惯或专注记录来管理工作和生活，AI 可以帮助你分析一段时间内的时间投入结构。

它可以帮你看到哪些项目占用了最多精力，哪些事情出现得最频繁，哪些目标被持续推进，哪些方向投入很多但产出不明显。

![](https://cdn.dida365.cn/hc/all/803a140452a74cb685adb3641bd05d75.png)


**可以直接复制使用的 Prompt：**

```

帮我分析最近一个月的时间投入情况。

请分析：

- 这段时间主要投入在哪些项目或清单
- 不同类别的任务数量和占比
- 哪些事项投入最多
- 哪些任务完成率较高
- 哪些方向投入较多但推进不明显
- 是否有长期目标被持续推进

最后输出：

1. 时间投入概况
2. 主要投入方向
3. 时间投入排行榜
4. 投入与产出分析
5. 后续优化建议

```

你也可以根据需要替换时间范围，例如：
- 帮我分析这个月的时间投入情况
- 帮我复盘最近三个月的健身记录
- 帮我总结过去半年的任务记录
- 帮我分析最近一个月的习惯坚持情况


AI 复盘的价值，不只是帮你统计完成了多少任务。

更重要的是，它可以帮助你从每天的记录中发现状态，从一周的任务中看清推进节奏，从长期的投入中理解重心变化。

当任务记录持续积累后，滴答清单不只是一个待办工具，也会成为你的个人工作记录、时间投入记录和成长记录。
