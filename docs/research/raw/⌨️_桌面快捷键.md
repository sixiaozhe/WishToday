使用快捷键和指令菜单来实现应用内操作，无需鼠标，效率更高。
# 指令菜单
使用 ⌘+K 或者 Ctrl+K 打开「指令菜单」，输入名称，轻松前往应用内各大功能模块。

![](https://cdn.dida365.cn/hc/all/1ec7268334184ae886098139a67732a2.gif)

> Mac 应用程序暂时不支持此功能。

# 快捷键
用且只用键盘上的某个按键或者多个按键的组合完成某一项操作，节省时间，解放鼠标。

你可以输入「?」，方便的查看快捷键列表。

![](https://cdn.dida365.cn/hc/all/93f4e156764e54f42ad08713c4cb29a9.png)


# 常见问题

::: spoiler 如何修改快捷键？
- 在设置里查看快捷键界面，可以修改。
- 在侧边栏打开快捷键界面，可以修改。
- 在「指令菜单」-「帮助」-「显示键盘快捷键」打开快捷键界面，可以修改。
> 显示为灰色的快捷键不能修改。
:::
