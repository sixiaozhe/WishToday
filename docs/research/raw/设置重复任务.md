# 设置重复任务

> 原文: https://help.dida365.com/articles/6950660365923385344
> articleId: 62c65ae81e3a8b2ac64c83a9



写日报、周报、更换隐形眼镜、交房租、保险扣费...  总是有周期重复的事情需要我们记住。   

接下来，把它们都交给滴答清单，设置为重复任务，为大脑减轻负担😎。


# 如何设置重复？

首先将所有重复发生的事情都收集起来，逐一创建在滴答清单当中。创建任务后，在「任务详情页」-点击「日期&重复」- 选择「重复」，就可以选择你需要的重复选项。



![](https://cdn.dida365.cn/hc/all/32ee6b23db5839167ebb82b74823487d.png)





> 滴答清单提供 「 每天 / 每周 / 每月 / 每年 / 法定工作日 / 艾宾浩斯记忆法 / 自定义 」 重复，满足你的各种需求。


重复的选项这么多，选哪个？ 可以简单的分为 4 类：
* 常见重复 （🌈 日常琐事）
* 工作日&节假日重复 （💼 打工人必备）
* 农历重复（🥮 传统佳节）
* 艾宾浩斯记忆法  （📝 学习记忆神器）
* 自定义重复 （😄 随心所欲）


::: spoiler 如何取消重复？
点击任务进入编辑页，点按**日期**区域进入设置页，找到**重复**选项并点击旁边的 **✖**，即可清除重复设置。

![l](https://cdn.dida365.cn/hc/all/aa6633a7f1f1aaf4706ba30d7a8030e3.png)



:::

::: spoiler 编辑重复
进入任务编辑页，点击**日期**区域，在设置页面中点击 **重复** 修改已有规则即可完成编辑。
:::


#  每天、每周、每月、每年

* 每天（遛狗、慢跑）
* 每周 （周报、超市购物）
* 每月（花呗、信用卡账单还款）
* 每年（家人、朋友生日🎂）

如：每月 31 号信用卡还款，点击「日期&重复」，在日历上点击还款日期 “ 31 ”- 设置「重复」-「每月」即可。

![](https://cdn.dida365.cn/hc/all/9a746da192bf1000785515d41a640be1.png)


# 工作日

- 每周工作日（周一到周五）

固定在每周一至周五重复，适合规律性的工作任务。

- 法定工作日

为工作中的任务设置「法定工作日」重复，任务将避开周末和法定节假日，在法定工作日重复，确保你的工作安排永远精准。

![](https://cdn.dida365.cn/hc/all/21c2aaf08f23855d815bd0dd4456e7ce.png)


# 节假日

- 每周末

固定在每周六和周日重复，适合周末的休闲计划。

- 法定节假日

为休息日专用任务设置「法定节假日」重复，任务将遵循国家放假安排，在法定节假日重复，完美匹配你的放假节奏。


![](https://cdn.dida365.cn/hc/all/3d9cd12b56e6ca3950f9b86dc878620f.png)



# 农历重复

适用于所有按中国传统农历计算的重要日子：

- 农历每年（春节、中秋节、家人农历生日）

- 农历每月（初一/十五祈福）

如：每年庆祝中秋节，将日期设置为今年中秋 ， 然后设置「重复」-「农历重复」- 选择「农历每年」。


![](https://cdn.dida365.cn/hc/all/a521d2f4bb56a5b40438a561608485aa.png)


# 艾宾浩斯记忆法 
“艾宾浩斯记忆法”是根据人类大脑的遗忘规律来记忆，在遗忘节点对于记忆内容进行复习巩固，来加深记忆。


艾宾浩斯记忆法的重复周期按照 1，2，4，7，15，15，15，15，15，15，15，15…… 循环。
> 简单来说即为“一二四七”，在学习的当天（一）、第二天（二）、第四天（四）、第七天（七）对所学知识进行复习巩固，在记忆上可事半功倍，达到长久记忆效果。

如：背单词，点击「日期&重复」， 设置「重复」-选择「艾宾浩斯记忆法」

![](https://cdn.dida365.cn/hc/all/79b54c84b84d936f2eace03d5b8480bd.png)


# 自定义重复

若常见重复中没有你需要的重复周期，你还可以使用「自定义重复」，随心所欲设置你需要的重复周期。

自定义重复，包括 3 种重复类型：到期重复、完成重复、自选日期重复。

![l](https://cdn.dida365.cn/hc/all/74e9e0f30eeb27458f89e869cc4423a2.png)




##  到期重复

到期重复是指到「设置的时间」就会提醒的重复。


如：小明计划每周五 13:00 安排下周的工作
* 在设定每周五 13：00 的到期重复后，滴答清单将在每周五 13:00 及时发送提醒。



![m](https://cdn.dida365.cn/hc/all/7143161b2e66fe755dff4ecd93df8933.png)





## 完成重复
> 完成重复是指按上次任务完成的时间，再开始计算下次提醒时间，再次提醒的时间会跟随完成时间而变化。

如：小明计划每三天健身一次
* 当第一次健身是在周二时，第二次将会在周五（隔三天）进行提醒。
* 但如果小明在周五有事耽搁了，直到周六才完成。那么下一次将会在周二（隔三天）进行提醒。

![m](https://cdn.dida365.cn/hc/all/997be9b1bfc3ad0f70b78aeab4e42db5.png)



## 自选日期重复

> 自选日期重复是指自由设置任务的重复时间，可以选择一天，也可以随意选择多天。

![m](https://cdn.dida365.cn/hc/all/d3bf77417981adf8b21a73bdda736a2c.png)



# 常见问题 
::: spoiler 如何结束重复？

常见重复任务默认一直重复。你可通过设置「按日期结束重复」和「按次数结束重复」来自动结束任务的重复。

![m](https://cdn.dida365.cn/hc/all/1c8df857747b1031fac784307b94e2cd.png)


- 按日期结束重复：设置一个重复的截止日期，此“日期”之后不再重复创建此任务。
- 按次数结束重复：设置一个重复次数，到达“次数”以后不再重复创建此任务。
:::


::: spoiler 到期重复和完成重复有什么区别？

假设你原本设置的任务日期是 1 号，每个月重复。但是这个任务拖延了，3 号才完成。

* 设置到期重复，下个任务提醒时间就还是 1 号。
* 设置完成重复，下个任务提醒时间将会是 3 号。
:::

::: spoiler 如何修改重复任务的单个周期？
可以在日历视图页面，修改重复任务的日期和时间，然后选择弹窗中的「仅此周期」即可。
:::
::: spoiler 如何显示未来所有重复周期？
在日历视图的「显示设置」中，开启「显示未来重复周期」即可。
:::
