![--56.33%](https://cdn.dida365.cn/hc/all/0383a9fe16e701d5d49adb7d87cd565a.jpg)

上学时，我们会将每章节中重点内容整理在便利贴上，粘贴在章节最前面方便复习。

工作后，我们会将一天的 todo list 写在便利贴，贴在电脑显示屏上，时刻提醒自己。

从学生到职场，便利贴一直陪伴着我们。

我们的新功能「桌面便签」和传统的便利贴一样，能够用来快速记录你的碎片化信息，或者将一段时间内的重点事项钉在桌面上，方便你跟进处理。 

相信在工作场景中，桌面便签能够帮助你快速记录所思所想。

看看如何使用👇



# 打开便签

我们提供了两种方法打开便签。

## 方法一：任务打开便签

你可以通过右击任务选择「打开便签」，或者 在任务详情页中，点击右下角「...」-「打开便签」。


![](https://cdn.dida365.cn/hc/all/14aa87a583f544d69b65215aab70533a.png)




## 方法二：快捷键打开便签

如果想要能够直接开启便签功能，你只需要设置「添加便签」的快捷键就能快速添加。

**第1步：设置快捷键**

点击头像-「设置」-「快捷键」-「全局操作」-「添加便签」。

你可以根据自己的使用习惯设置快捷键。

![](https://cdn.dida365.cn/hc/all/5872f5c1c6d37ab434705cf434ddd0c7.GIF)

**第2步：使用快捷键打开**

设置成功后，你就能够在桌面中或者其他场景快速使用快捷键随时唤起便签功能。
![](https://cdn.dida365.cn/hc/all/9df216cd8a1282dc9fbe8dda6bb6c80a.GIF)

::: spoiler 如何批量打开便签？
在任务列表页面，按下 “Shift”键点击需要批量打开任务范围，再在右边选择打开便签，所选择的任务就能够一次批量打开。
![](https://cdn.dida365.cn/hc/all/c091af9a18ad202e2b1f067302b09f56.gif)
:::

:::::: spoiler 如何关闭便签？
你可以在便签右上角点击关闭按钮关闭便签，也可以使用快捷键关闭。
:::::tabContainer [Windows|macOS]

::::tab [Windows]
Windows端：Ctrl+w

::::

::::tab [macOS]
Mac端：⌘+w
::::

# 常用的操作与技巧

## 便签设置
你可以在便签设置中根据自己的偏好，设置：默认颜色、字体大小、默认置顶、默认便签间距、排列恢复默认大小等。

使用方式：打开「设置」-「功能」-「便签」。

![](https://cdn.dida365.cn/hc/all/5cab98b7e736669a43a8b5ac90385aaa.png)

::::::: spoiler 如何切换便签颜色？
对于已打开的便签，你也可以快速切换它的颜色。

使用方法：
将鼠标移至便签顶部，点击衣服形状按钮，即可选择你喜欢的颜色；
或者也可以使用颜色快捷键来进行切换。
:::::tabContainer [Windows|macOS]

::::tab [Windows]
切换颜色快捷键：Ctrl+Shift+C  
::::

::::tab [macOS]
切换颜色快捷键：⇧+⌘+C 
::::

:::::::



## 置顶便签
当我们在视频会议或者查找资料时，便签保持在页面最前端，可以方便我们快速记录要点。

使用方法：
将鼠标移至便签顶部，点击便签右上角「置顶」按钮，即可置顶便签；
或使用便签置顶快捷键 F12。
![](https://cdn.dida365.cn/hc/all/99d63e011f96a14615d20fe48e7cdbd0.gif)


::: spoiler 如何使新建的便签默认置顶？
使用方法：打开「设置」-「功能」-「便签」- 启用「默认置顶」。
![](https://cdn.dida365.cn/hc/all/8b40a67fe2f7602429eb6c3f927ef5e9.png)

:::

## 一键排列
如果你一次性打开了多个便签，可以使用一键排列功能来整理它们。


使用方法：

❶ 点击便签右下角「...」-「排列」

❷ 使用一键排列快捷键

![](https://cdn.dida365.cn/hc/all/884d3505dccc12aa206efa13c0a9c91f.gif)

:::::: spoiler 一键排列快捷键
:::::tabContainer [Windows|macOS]

::::tab [Windows]
顶部排列，Alt+↑

居左排列，Alt+←

居右排列，Alt+→
::::

::::tab [macOS]
顶部排列，/⌥ + ⌘+↑

居左排列，/⌥ + ⌘+←

居右排列，/⌥ + ⌘+→
::::

## 便签单行

将一天的所有任务都打开便利贴钉在桌面上，占据的空间较大；
这个时候你就可以先双击便签顶部，将便签变成单行，自由拖动它调整位置。

![](https://cdn.dida365.cn/hc/all/58e281658bc27108c527dd9314686b1e.png)

当你需要完成一项任务时就再双击放大它，查看任务详情。

![](https://cdn.dida365.cn/hc/all/3ec5208ec2b53bd1eb6fe88533a48926.gif)


# 常见问题


::: spoiler 如何直接建立一个便签？
可以使用快捷键快速打开一个便签，在「设置」-「快捷键」-「全局操作」中设置「添加便签」快捷键。

![](https://cdn.dida365.cn/hc/all/7b437c59169951d46e9b9eda93ddd938.png)
:::



::: spoiler 手机上如何同步便签？
目前便签功能为电脑端功能，无法在手机上打开。
:::
::: spoiler 如何关闭便签在Windows状态栏的显示
目前，Windows用户可以自定义便签是否在状态栏显示窗口。

使用方法：「设置」-「偏好与功能」-「便签」- 「不在任务栏显示」
启用「不在任务栏显示」后，你可以通过快捷键 Win + Tab 查看所有已打开便签。
:::
