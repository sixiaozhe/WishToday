# ⏳ 倒数纪念日

> 原文: https://help.dida365.com/articles/7322192298849075200
> articleId: 680dfafb1c42a13a390ba095

在快节奏的生活里，总有一些特别的日子，不想被遗忘，也不愿匆匆应对。滴答清单的「**倒数纪念日**」功能，陪你用心记录每一个重要日子。

🎂 **纪念日**，记住那些值得庆祝的时刻：恋爱、结婚、生日、第一次带宠物回家的那天…… 每一年的这一天，是属于你们的庆祝日。滴答清单会准时提醒，陪你一起迎接这些重要时刻。

⏳ **倒数日**，为每一个期待的瞬间倒数：旅行、考试、演出、目标达成…… 每天看着天数一点点减少，是坚持的动力，也是期待的暖意。滴答清单陪你一起规划好每一步，让准备更从容。

📌 适合这些场景：

- 不想错过重要日子的人

- 喜欢提前安排和准备惊喜的人

- 需要一个倒数激励目标的人

- 想让生活多点仪式感的人

这些日子也许不是最紧急的，但往往是最暖心的。纪念日记录过往，倒数日期待未来。一个帮你记得爱，一个帮你坚持梦想，现在就去添加你的重要日子吧！
