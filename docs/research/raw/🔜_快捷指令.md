**「快捷指令」**
是 iOS 系统推出的一个自动化工具，它可以通过对各动作的简单排序来实现想象中的各种功能。 你也可以理解为它是一个简易版编程工具，你可以通过它创建和自定义一系列操作序列，以便以更高效的方式执行常见任务。

# 组合多个快捷指令
将 iPhone 升级至 **iOS 27 或更高版本**，并将滴答清单更新至**最新版本**后，你可以在「快捷指令」App 中组合多个滴答清单快捷指令，让一个快捷指令完成多个操作。
## 🍅 添加任务后直接开始专注

有时候想到一件事情后，想马上开始处理，但需要先添加任务，再找到任务并开启专注。

现在可以将「添加任务」和「开始专注」两个快捷指令组合起来：

**添加任务 → 开始专注**

**具体设置方法：**
1.  打开 iPhone 的「快捷指令」App，创建一个新的快捷指令。 
2.  添加滴答清单的「添加任务」操作。 
3.  添加滴答清单的「开始专注」操作。 
4.  将「添加任务」创建的任务作为「开始专注」的任务。 
5.  根据需要设置专注时长和专注模式。 
6.  保存快捷指令。 

![l](https://cdn.dida365.cn/hc/all/162fbe88131fb8a1143e5df94fb3931a.png)

设置完成后，运行该快捷指令，输入任务内容即可在创建任务后直接开始专注。

![l](https://cdn.dida365.cn/hc/all/748a996df8f01c282c0995988dbe5e11.png)

## 🏃 开始运动，一键打卡并记录专注

如果你平时会使用滴答清单记录运动习惯，可以将「习惯打卡」和「常用专注」组合起来。

**完成打卡 → 常用专注**

**具体设置方法：**
1.  添加滴答清单的 「习惯打卡」 操作。 
2.  选择需要打卡的习惯，例如「健身」或「跳舞」。 
3.  添加滴答清单的 「开始专注」-「常用专注」 操作。 
4.  保存快捷指令。


![l](https://cdn.dida365.cn/hc/all/92f55740ee4923a532f3462a115ad8be.png)

以后开始运动时，只需要运行一次：
 完成习惯打卡 → 开始计时

# URL Scheme
使用 URL Scheme 可以从其他应用发送指令到滴答清单，配合 iOS 系统「快捷指令」等第三方应用，你可以进行一些自动化操作。

目前滴答清单的 URL Scheme 能执行以下指令，比如：

- 添加任务：添加一个叫“购买鸡蛋”的任务
- 显示智能清单：显示“今天”智能清单
- 搜索任务：搜索包含“开会”的任务

这些指令将通过特定的链接来传达，链接的格式为：

> ticktick://v1/command?parameter1=value1&parameter2=value2&…

打开这些链接将启动滴答清单并执行指令。其中：

- command 表示指令的类型，目前滴答清单支持“添加任务”、“显示”、“搜索”三种指令
- parameter 表示参数，比如添加一个任务，参数包括“任务标题”、“开始时间”、“任务内容”等
- value 表示具体的值，比如参数“任务标题”的具体值是“购买鸡蛋”。

举个例子，如果你想要显示“今天”智能清单，这个链接就应该是下方这种格式：

> ticktick://v1/show?smartlist=today

接下来，你将了解到三种指令的具体使用方式。

## ✅ 添加任务指令
“添加任务”的指令支持 [ x-call-back](https://www.twitter.com/xcallbackurl) 的回调约定，即当你通过“添加任务”的指令打开滴答清单应用并成功添加任务后，可以回到发起指令的应用程序中。目前滴答清单支持三种回调：x-success, x-error, x-cancel。

因此，“添加任务”指令的特定链接格式如下：

> ticktick://x-callback-url/v1/add_task?parameter1=value1&parameter2=value2&…&x-success={{下一个app的scheme}}

“添加任务”的指令包括以下参数：
- title：任务标题（必填）
- startDate：开始时间
	- 格式（带时区）：2018-05-07T18:00:00.000+0000
	- 格式（不带时区）：2018-05-07T18:00:00.000（注意：不带时区时，会按照设备的当前时区来解析）
- endDate：结束时间
	- 格式（带时区）：2018-05-07T01:20:00.000+0000
	- 格式（不带时区）：2018-05-07T01:20:00.000（注意：不带时区时，会按照设备的当前时区来解析）
	
- allDay：是否是全天任务
	- 是全天任务时=true；不是全天任务时=false
	- startDate 或 endDate 有值时必填

- priority：优先级
	- 无优先级=0；低优先级=1；中优先级=3；高优先级=5
	- 默认=0

- content：任务内容
- list：所属清单名
	- 默认=inbox
- subtasks：检查事项

举例：添加任务“购买鸡蛋”

> ticktick://x-callback-url/v1/add_task?title=buy%20some%20eggs&x-success={{下一个app的scheme}}

举例：添加任务“明天下午6点购买鸡蛋”到“购物”清单

> ticktick://x-callback-url/v1/add_task?title=buy%20some%20eggs&startDate=2018-05-08T18:00:00.000+0000&allDay=false&list=shopping&x-success={{下一个app的scheme}}

添加任务成功后，若回调的是 x-success，则滴答清单会返回以下参数，以供下一个 x-callback-url 指令调用：

- title：任务标题
- taskID：任务的唯一标识

## “显示”指令
“显示”指令的特定链接格式如下：

> ticktick://v1/show?parameter=value

“显示”的指令包括以下参数：

- smartlist：智能清单名（必填）
	- 所有=all
	- 今天=today
	- 明天=tomorrow
	- 最近7天=next_7_days
	- 分配给我=assign_to_me

举例：显示“今天”智能清单

> ticktick://v1/show?smartlist=today

## “搜索”指令
“搜索”指令的特定链接格式如下：

> ticktick://v1/search?parameter=value

“搜索”的指令包括以下参数：
- keyword：关键字（必填）

举例：搜索所有包含关键字“shopping”的任务

> ticktick://v1/search?keyword=shopping
