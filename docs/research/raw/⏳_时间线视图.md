# ⏳ 时间线视图

> 原文: https://help.dida365.com/articles/7019123502271692800
> articleId: 63bf6c2ba078ed9016ad4064

![100%](https://cdn.dida365.cn/hc/all/09d3e02e9a6a11a0fad546ddaa87eebb.jpeg)


**时间线视图**是一个简单的可视化图表，项目中所有的任务按照制定的时间顺序展示。当你在清单中开启了时间线视图，任务就会显示在横向的时间线中。

使用「时间线视图」，你可以在项目管理中非常直观地看到各任务到来的时间和截止的时间、各任务在整个项目中所处的位置，还可以快速了解每个人的工作进度，以便及时调整工作计划。也可以在一个更长的时间范围内，规划安排工作和生活。

现在，让我们来看看如何使用它吧👇

# 开启时间线视图

:::::tabContainer [desktop|mobile]

::::tab [desktop]
点击任意一个「普通清单」、「文件夹」或者「过滤器」，找到右上角「...」-「视图」-「时间线视图」即可开启。

![](https://cdn.dida365.cn/hc/all/222c9a99f99b849b9cacfc9f2d82c169.jpg)
::::

::::tab [mobile]
点击任意一个「普通清单」、「文件夹」或者「过滤器」，找到右上角「...」-「视图」-「时间线视图」即可开启。

![](https://cdn.dida365.cn/hc/all/ada6522fc362108d3d06e36fe022dba1.png)


::::

:::::


::: spoiler 为什么找不到「时间线视图」？

只有普通清单才支持切换视图，「今天」、「明天」、「最近7天」等智能清单暂不支持时间线视图。

:::


# 常用操作与技巧

## 创建与修改任务

:::::tabContainer [desktop|mobile]

::::tab [desktop]

**创建任务**

在时间线视图中，添加任务非常简单，你可以单击空白区域，直接添加任务，任务会根据你点击的日期，自动带上时间。

例如，图中在4月2日添加的任务，会自动设置4月2日。

![](https://cdn.dida365.cn/hc/all/c0808464223b90e206ab99bc65ce9e63.gif)

**安排任务**

时间线视图只能显示有时间的任务，没有时间的任务会显示在右侧的安排任务中。

你可以通过拖动，直接将任务安排到时间线中，设置好时间。

![](https://cdn.dida365.cn/hc/all/1a7c74dab98a562ec42e66093fd81450.gif)

**修改任务时长**

在时间线视图中，任务的长度，代表了任务的时长。 

如果你想对任务的时长进行调整，只需要将鼠标移动到任务边缘拖动即可。

![](https://cdn.dida365.cn/hc/all/ee1fb577ef646c851c4462da4a50600d.gif)

**修改任务时间**

任务的位置，代表着任务的开始时间和结束时间。 

当任务时间需要调整时，你只需要单击按住任务，将任务拖动到对应的位置即可。

![](https://cdn.dida365.cn/hc/all/74a8a1f709767ab41667213eff215ca2.gif)

拖动后，任务会根据你松手的位置自动对应的时间。

::::

::::tab [mobile]

**创建任务**

在时间线视图中，你可以通过长按空白区域，直接添加任务。

任务会根据你点击的日期，自动带上时间。

![](https://cdn.dida365.cn/hc/all/586bfe5d4d4bc148c0b485021b75e3d7.gif)


**修改任务时长**

任务的长度，代表了任务的时长。 如果你想对任务的时长进行调整，只需要长按任务后拖动任务边缘即可。

![](https://cdn.dida365.cn/hc/all/cf794b634e5cdfd9efb7b4a07dd2e6b0.gif)



**修改任务时间**

任务的位置，代表着任务时间。 当任务时间需要调整时，你只需要按住任务，将任务拖动到对应的位置即可。

![](https://cdn.dida365.cn/hc/all/a188ab9a663495939a54fca708dd0e3e.gif)

## 查看任务

:::::tabContainer [desktop|mobile]

::::tab [desktop]

**滑动查看**

按住鼠标左右滑动，即可拉动时间线，在时间线中查看数周、数月的任务。

![](https://cdn.dida365.cn/hc/all/41e61c6793bb087807ffa58425468796.gif)

**切换显示比例**

当任务时间跨度较大时，你可以通过点击视图右上角的「日」、「周」、「月」来调整显示比例。

![](https://cdn.dida365.cn/hc/all/f72695e1f27655dc15a6b9eaa056125c.gif)


::::

::::tab [mobile]

**滑动查看**

轻触屏幕左右滑动，即可拉动时间线，在时间线中查看数周、数月的任务。

![](https://cdn.dida365.cn/hc/all/72ab4a4eba839fddb770dd99f6769eb4.gif)




**切换显示比例**

当任务时间跨度较大时，你可以通过点击视图右上角的「日」、「周」、「月」来调整显示比例。

也可以双指捏和放大时间跨度，双指外划缩小时间跨度。

![](https://cdn.dida365.cn/hc/all/c9c34eb65d48100199d10a931cd78b16.gif)

# 使用场景推荐

**安排个人工作**

将「💪🏻 工作」设置成一个文件夹，再将常规的工作按类别分为几个清单。

将每月、每天的任务分配在各个清单板块中，即可让你对每天、每月的工作有清晰的了解，做到真正的心中有数！

![](https://cdn.dida365.cn/hc/all/a3f271ebf06ea2bb55d2465dd3abbf84.jpg)




**管理复杂项目**

先建立一个项目清单，再将所有需要参与到此项目中的团队都建立一个分组，然后开启时间线视图，即可让你迅速了解各团队的工作进度。

为了更好的团队协作，你还可以将这个任务清单共享给各团队负责人并且将对应的任务直接指派给他。

![](https://cdn.dida365.cn/hc/all/886a24b0ba19dcbc8f748917d9395d1b.jpg)




**制定生活计划**

我们还可以使用时间线视图来做月度计划、复习计划、备婚计划、装修计划等等等等。

![](https://cdn.dida365.cn/hc/all/d3f2839c461577f291112fe449d12d96.jpg)




# 常见问题
::: spoiler 移动端时间线视图支持横屏吗？
支持，旋转手机至横屏即可。
:::
::: spoiler 如何修改视图中任务块的颜色？
在时间线视图中，找到右上角「...」-「显示设置」即可设置任务块颜色。
:::
