# 企业微信、钉钉、飞书等日历

> 原文: https://help.dida365.com/articles/7190959806838996992
> articleId: 66308f3347c89fff9258e216

当你想在滴答清单中查看企业微信、钉钉、飞书、QQ邮箱等日历，你可以通过 CalDav 的方式，轻松实现。

# 企业微信日历

:::::tabContainer [mobile|desktop]

::::tab [mobile]
**添加日历**

在「设置」-「导入与关联应用」-「日历」，选择 CalDav ，输入企业微信日历的「服务器地址」、「用户名」、「密码」，即可完成同步。

![--65.97%](https://cdn.dida365.cn/hc/all/964fac800b27191fe7098d394eccaeeb.png)
::::

::::tab [desktop]
**添加日历**

点击「头像」-「设置」-「关联与导入」-「企业微信日历」，通过 CalDav 方式订阅企业微信日历到滴答清单中显示 ，输入「用户名」、「密码」、「服务器地址」，即可完成同步。

![--75.32%](https://cdn.dida365.cn/hc/all/8bffb3981c0f6fe4fbf477c8a3df7d69.png)
![--75.32%](https://cdn.dida365.cn/hc/all/0db81516873470242c79263f88b75ab8.png)

::::

:::::



**获取账号密码**

在企业微信中，点击「头像」-「设置」-「日程」-「同步至其他日历」

![--66.22%](https://cdn.dida365.cn/hc/all/c6b4ecfa81890be710ac38258950b65e.png)

![--66.19%](https://cdn.dida365.cn/hc/all/641d660dd0ec24589a79bd7e0b4d7f9b.png)



![--66.19%](https://cdn.dida365.cn/hc/all/e37c792870444bcf3d2ccb58e839e6b1.png)


分别将“帐号/用户名、密码、服务器地址”填写到滴答清单 CalDAV 订阅中即可成功订阅。（需要将获取的服务器地址修改为“caldav.wecom.work”）

> 移动端：在企业微信中，点击「日程应用」-「日程设置」-「同步至其他日历」。

::::tab [mobile]

![--65.97%](https://cdn.dida365.cn/hc/all/964fac800b27191fe7098d394eccaeeb.png)
::::

::::tab [desktop]
**添加日历**

点击「头像」-「设置」-「关联与导入」-「钉钉日历」，通过 CalDav 方式订阅钉钉日历到滴答清单中显示 ，输入「用户名」、「密码」、「服务器地址」，即可完成同步。

![--75.32%](https://cdn.dida365.cn/hc/all/3ffdf0ed41593eef0642a1579953a5b3.png)
![--75.32%](https://cdn.dida365.cn/hc/all/ead54e70a199ef10400adae6a1d0876b.png)



::::

:::::


**获取账号密码**

在「日历」-「日历设置」-「同步」中，找到 CalDav 同步，点击「进入配置」。

![](https://cdn.dida365.cn/hc/all/a6e29874496c8988d83b08182c4f99f1.png)


你可以选择你需要同步到的设备，如“Mac、windows、Android、iPhone、 iPad、other”。

![](https://cdn.dida365.cn/hc/all/7c523f07a9ff1b608b0023fa20f58e21.png)

选择好设备后，点击「生成」该设备的「专用密码」，将密码填写到滴答清单「CalDav」中，即可完成对钉钉日历的同步。

![](https://cdn.dida365.cn/hc/all/59ac40ccd167ee376b4311aedf9174e3.png)
