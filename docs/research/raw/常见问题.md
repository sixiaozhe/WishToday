# 常见问题

> 原文: https://help.dida365.com/articles/6950411584711688192
> articleId: 62c573361e3a8b2ac64c8104

::: spoiler 如何补计专注记录？
在「专注统计」中找到「专注记录」，点击右边「+」，即可补记专注记录。
:::
::: spoiler 如何删除专注记录？
在「专注统计」中进入「专注记录」，进入需要删除的记录，点击最下角 删除记录，即可删除。
:::
::: spoiler 如何设置应用白名单？
在专注设置中，将需要的 App 添加到白名单即可。

iOS 用户需要升级到 iOS16。
:::
::: spoiler 为什么专注不同步？

你可以在专注页面点击右上角「...」-「专注设置」中开启专注多端同步。

![l](https://cdn.dida365.cn/hc/all/dd76531b5416c4c675ff154341568b6f.png)

:::
::: spoiler 如何在日历中显示专注记录？
在「日历」选择「显示设置」，点击打开「显示专注记录」，就可以在日历视图中同步自己的专注时间块，一天的专注时间线一目了然！
:::
