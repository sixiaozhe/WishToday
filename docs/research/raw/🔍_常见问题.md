# 🔥 热点问题
::: spoiler 如何备份数据？
你可以登录 Web 端进行数据备份。

- 登录帐号 - 点击左上角「头像」 -「设置」-「账户与安全」-「备份与还原」-「生成备份」，即可将数据备份保存至本地。

![--66.87%](https://cdn.dida365.cn/hc/all/83ef4d38d1583037fe4a8d34782165a4.png)

:::

::: spoiler 如何合并账号数据？
如果你想合并两个账号的数据，可以先备份一个账号的数据，然后将备份好的数据导入另一个账号。
1. 备份数据：登录 Web 端 ，点击头像 -「设置」-「账户与安全」-「备份与还原」-「生成备份」来保存备份数据；
2. 导入备份：在 Web 端登录需要导入数据的账号，点击头像 -「设置」-「账户与安全」-「备份与还原」-「导入本地备份」完成合并。
:::

::::: spoiler 任务到期不提醒?
:::::tabContainer [Android|iOS]

::::tab [Android]
由于 Android 系统安全服务和第三方安全应用可能会影响滴答清单的提醒功能，请先根据以下步骤进行检查： 
1. 滴答清单是否已经获得通知权限？ 
请确保滴答清单已经获得通知权限，否则滴答清单将无法正常提醒。 
2. 手机系统是否自带安全服务？ 
如果有，请允许滴答清单自启动并在待机时保持后台运行。 
3. 是否安装第三方安全应用？ 
如果有，请确保在每个安全软件中，将滴答清单加入自启动白名单和内存加速白名单。 
你也可以在 app 内点击「设置 」- 「声音、提醒与通知」-「提醒没有生效？」，在该页面查看更多解决办法。
::::

::::tab [iOS]

::: spoiler 为什么 Markdown 语法输入后没有触发对应格式？

部分 Markdown 语法需要在格式符号后输入**空格**，才能触发对应的文本样式。

例如：


1. `*斜体*` + 空格 → *斜体*
2.  `**加粗**` + 空格 → **加粗**
3. `~删除线~` + 空格 → ~~文字~~
4. `==文字==`+ 空格 → ==文字==


如果直接输入 Markdown 符号后继续输入文字，没有触发对应格式，可以在符号后增加一个空格再继续输入。
:::

请将滴答清单**更新至最新版本**后再查看。

::: spoiler 管理任务总共有哪些层级？
滴答清单拥有清晰的任务层级：「文件夹」-「清单」-「分组」-「任务」-「子任务」，能够帮助你高效地管理任务。

![l](https://cdn.dida365.cn/hc/all/24e2e38b5a96cdc1ca500f5de2f3082c.png)


- 文件夹：文件夹常被用来管理清单。如果你的同类清单数量较多，例如：会议、报告、差旅，你可以创建一个“工作”文件夹去整理它们。
- 清单：清单可以被用来对任务进行分类整理。你可以根据个人的生活和工作安排创建常用清单，将同类任务放入同一个清单。另外，清单还可以被共享出去，与他人进行协作。
- 任务：任务是进行日程管理的基础层级。
- 子任务：子任务是比任务低一级的层级，任务可以被拆分成几个子任务，一 一达成。

::::: spoiler 任务到期不提醒怎么办？
:::::tabContainer [iOS|Android]
::::tab [iOS]
如果你是 iOS 用户，请先确认系统设置中，是否已经允许滴答清单的提醒通知。具体步骤为：点击手机系统中的「设置」-「通知」-「滴答清单」，即可查看通知提醒状况。
::::
::::tab [Android]
由于 Android 系统安全服务和第三方安全应用可能会影响滴答清单的提醒功能，如果你是 Android 用户，请先根据以下步骤进行检查：
1. 滴答清单是否已经获得通知权限？
请确保滴答清单已经获得通知权限，否则滴答清单将无法正常提醒。
2. 手机系统是否自带安全服务？
如果有，请允许滴答清单自启动并在待机时保持后台运行。
3. 是否安装第三方安全应用？
如果有，请确保在每个安全软件中，将滴答清单加入自启动白名单和内存加速白名单。
你也可以在 app 内点击「设置 」- 「声音、提醒与通知」-「提醒没有生效？」，在该页面查看更多解决办法。
::::

> 如果上述方法仍没有解决你的问题，请在滴答清单 app 内点击「设置」-「反馈与建议」，向我们提交问题反馈，我们会尽快为你处理。

# 🤝 共享协作
::::: spoiler 如何与他人共享清单？
滴答清单不仅能帮助您管理您的个人事务，还可以让您和他人共享协作。将清单共享给其他成员，所有成员都可以在清单内查看、编辑、添加和删除任务。
:::::tabContainer [mobile|desktop]
::::tab [mobile]
点击某个清单进入任务列表页，点击右上角「···」-「共享协作」，选择「添加新成员」即可。

![l](https://cdn.dida365.cn/hc/all/e65145ae1954a280196f4144fc5e98e1.png)


邀请新成员有以下三种方式：
- 联系人邀请：输入联系人电子邮箱或名字，回车即可发送邀请，未注册过滴答清单的邮箱可以通过点击邮箱内的链接来激活共享。您也可以从最近邀请和团队成员里显示的联系人中选择一个或者多个进行邀请。
- 共享链接邀请：点击即可创建一个共享链接，可复制链接发送给其他人。若其他成员确认加入该清单，您将会收到申请加入的通知，在您确认同意后，该成员即可共享此清单。
- 微信好友邀请：可点击「邀请微信好友」直接转跳至微信进行邀请，也可以通过二维码邀请好友加入。
> 以上三种邀请方式均可以对被邀请人进行权限设置，权限分为可评论、只读和可编辑三个层级。
::::
::::tab [desktop]
在清单页，点击右上角「···」-「共享」，即可邀请新成员。

![](https://cdn.dida365.cn/hc/all/37c9b5ac27e6afe83bb074722338c31a.png)

邀请新成员有以下两种方式：
- 联系人邀请：输入联系人电子邮箱或名字，回车即可发送邀请，未注册过滴答清单的邮箱可以通过点击邮箱内的链接来激活共享。您也可以从最近邀请和团队成员里显示的联系人中选择一个或者多个进行邀请。
- 共享链接邀请：点击即可创建一个共享链接，可复制链接发送给其他人。若其他成员确认加入该清单，您将会收到申请加入的通知，在您确认同意后，该成员即可共享此清单。
> 加入共享清单的用户都可以对该清单的内容进行编辑，在清单编辑界面或共享界面可以看到清单共享者的用户名。

::: spoiler 为什么我找不到共享协作功能？
「今天」、「明天」、「最近7天」等智能清单不支持共享协作，需要在自己建立的普通清单中使用共享协作功能。

具体操作为：点击某个清单进入任务列表页，点击右上角「···」-「共享协作」。
:::



::: spoiler 共享成员都要高级会员吗？
不需要。付费用户和免费用户都可分享以及加入共享清单，但是付费用户每个共享清单可加入29位成员，免费用户的共享清单只可加入1位共享成员。
:::


::::: spoiler 如何为他人指派、分配任务？
共享清单中的任何成员都可以对任务进行分配，指派任务给执行者。任务的指派人会在「通知中心」收到通知提醒。
:::::tabContainer [mobile|desktop]
::::tab [mobile]
你可以进入任务详情页，点击右上角「指派」图标指派任务。

![m](https://cdn.dida365.cn/hc/all/cddec7906b3850ed78941bb06e318f22.jpg)

::::
::::tab [desktop]
你可以进入任务详情页，点击右上角「指派」图标指派任务。

![m](https://cdn.dida365.cn/hc/all/3b286e530cc2317439a3db93588e184a.png)

:::::: spoiler 不想收到共享清单中指派给别人的任务提醒怎么办?
你可以开启「勿扰」，共享清单中如果没有指派给自己的任务时，你将不会收到提醒。
:::::tabContainer [mobile|desktop]
::::tab [mobile]
在左侧边栏中左滑共享清单，点击「编辑」进入清单编辑界面，选择「通知」即可开启勿扰模式。

![](https://cdn.dida365.cn/hc/all/9fb19a33b47c5ae75509e7a2fb14ca25.png)



::::
::::tab [desktop]
在左侧边栏中右键共享清单，点击「编辑」进入清单编辑界面，即可开启勿扰模式。
