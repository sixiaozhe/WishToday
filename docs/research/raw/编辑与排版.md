# 编辑与排版

> 原文: https://help.dida365.com/articles/7506636172735545344
> articleId: 6aacfbba035abcbe8d77e172

滴答清单编辑器支持 **Markdown** 和可视化编辑工具，你可以在任务、笔记等内容中使用不同的文本格式，帮助你更清晰地记录、整理和查看内容。

## 使用 Markdown
如果你习惯使用 Markdown，也可以直接输入对应的 Markdown 符号，快速设置文本格式。
> 注意： 部分 Markdown 格式需要在符号后输入空格，才能触发对应的样式。

| 输入方式          | 效果      |
| ------------- | ------- |
| `#` + 空格      | 一级标题    |
| `##` + 空格     | 二级标题    |
| `-` + 空格      | 无序列表    |
| `1.` + 空格     | 有序列表    |
| `- [ ]` + 空格  | 待办列表    |
| `>` + 空格      | 引用      |
| ``` + 换行      | 代码块     |
| `**文字**` + 空格 | **加粗**  |
| `==文字==` + 空格 | 高亮      |
| `*文字*` + 空格   | *斜体*    |
| `~~文字~~` + 空格 | ~~删除线~~ |
| `---`         | 水平分割线   |


## 修改或取消格式
在编辑内容时，你可以随时修改已有格式，也可以取消不需要的格式。不同格式还可以组合使用，让重点更加清晰。

**切换已有格式**

如果已经设置了某种格式，但后来想换成其他样式，可以选中文字后直接选择新的格式。

> 例如：将「项目截止时间」设置为**加粗**，后来希望它更加醒目，可以选中这段文字，将其改为**高亮**，也可以同时使用加粗和高亮。

![l](https://cdn.dida365.cn/hc/all/a91d06dd384f79f6837cc9ed528ea045.png)

这样可以根据内容的重要程度，随时调整文字的展示方式。

**取消格式**

如果不再需要某种格式，可以选中文字后，通过编辑工具栏取消对应格式，让文字恢复为普通文本。

![l](https://cdn.dida365.cn/hc/all/5638d6893b444e755b7486d6e1f64ca2.png)

**组合使用多种格式**

不同格式可以组合使用，用于突出不同类型的信息。

例如：
- 加粗 + 高亮：突出重要信息
- 斜体 + 高亮：强调补充说明
- 加粗 + 删除线：突出已修改或取消的内容

![l](https://cdn.dida365.cn/hc/all/3c8e4311cab08d430930fc9045f77e15.png)

你可以根据内容需要组合使用不同的文本格式，让重点更加清晰。

## 折叠较长内容
当一条内容包含较多信息时，可以使用不同等级的标题划分内容，并折叠暂时不需要查看的部分，让内容结构更清晰，也方便快速浏览。

### 使用标题组织内容
可以根据内容结构，使用不同等级的标题。
在 Markdown 中：
- `#` + 空格：一级标题
- `## `+ 空格：二级标题
- `###` + 空格：三级标题

以此类推，可以根据内容的层级和复杂程度添加不同等级的标题。

![l](https://cdn.dida365.cn/hc/all/d0a7b50fbcce6c63d715cdd84f3139b5.png)

### **折叠 / 展开标题下的内容**

创建标题后，可以点击标题旁的折叠按钮，将该标题下的内容暂时收起；再次点击即可展开。

![l](https://cdn.dida365.cn/hc/all/834009f86950551fa7f5c3890f3b5a94.png)

# 复制和粘贴内容
为了减少粘贴后的手动排版，编辑器会保留支持的富文本格式，并识别纯文本中的部分 Markdown 写法。**其他应用独有的样式不支持识别** ，粘贴后的显示可能与原内容不同。

**常见复制粘贴场景**

|           **复制来源**           | **粘贴后的效果**                                    |
| :--------------------------: | :-------------------------------------------- |
|      在滴答清单编辑器中复制，再粘贴回编辑器     | 保留原有格式和内容结构                                   |
| 从部分 AI 工具、Notion、飞书等复制带格式的文字 | 按富文本处理，保留支持的格式，如加粗、斜体、链接等                     |
|         从记事本等纯文本工具复制         | 保留文字和换行，并识别部分 Markdown 语法                     |
|          复制其他应用特有的格式         | 不识别不支持的特殊格式                                   |
|         从滴答清单复制到其他应用         | 格式是否保留取决于目标应用；如果目标应用仅支持纯文本，文字样式、待办勾选状态等信息可能丢失 |


**纯文本的特殊识别**

为了减少重复设置格式，粘贴纯文本时，编辑器会识别以下写法并进行转换：

|    **粘贴内容**    | **处理结果**         |
| :------------: | :--------------- |
|     `# 标题`     | 转换为标题            |
| `- 项目`、`1. 项目` | 转换为对应列表          |
|     `> 引用`     | 转换为引用            |
|       网址       | 自动识别为链接          |
|    `**文字**`    | 转换为加粗            |
|     `*文字*`     | 保留 `*` 符号，不转换为斜体 |

::: spoiler 为什么保留单星号？
有些文本中的 `*` 是内容本身，并不是斜体标记。为避免误识别、改变原文，编辑器不会将 `文字` 自动转换为斜体。从其他应用复制的实际斜体文字，仍可通过富文本格式保留。也可以在粘贴后选中文字，通过编辑工具栏设置斜体。
:::
# 常见问题

::: spoiler 从其他应用复制内容后，为什么部分格式发生了变化？
不同应用支持的文本格式不同，复制到滴答清单时会根据内容进行转换，因此部分特殊格式可能无法完全保留。

桌面端支持从 Notion、Bear、飞书，以及 ChatGPT、Claude、Gemini、DeepSeek、Kimi、通义千问、豆包等常见应用复制内容。
:::

::: spoiler 为什么完成框复制到其他应用后变成了无序列表？

完成框在复制到其他应用时，会转换为无序列表样式。这是正常的复制行为。
:::
