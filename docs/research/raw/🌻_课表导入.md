在课表视图点击加号键，输入课程相关信息即可添加课程。课程信息包含课程名称、周数、节数、教室以及老师。

# 导入课程

## 方式一：图片导入

**操作步骤**

1. 在日历的课表视图，选择 「立即导入」-「图片导入」。

2. 点击 「立即开始」，选择或拍摄一张课表图片进行识别。

3. 等待识别完成后，在 「课表预览」 页面检查并修改结果。

4. 确认无误后，点击 「导入」 完成操作。

![l--101.54%](https://cdn.dida365.cn/hc/all/ef656997384258cd28571492e7533860.png)

![l--101.59%](https://cdn.dida365.cn/hc/all/46fb7d356e10725d43b675754eb2d67d.png)



**上传图片要求**

为确保系统能够准确识别课表，请在上传前注意以下事项：

1. **拍摄**

- 确保照片亮度充足、均匀，避免阴影或反光。

- 保持画面清晰，避免模糊。

- 课表在照片中保持正向，避免过度倾斜或扭曲。

- 照片完整呈现课表内容，不遗漏边缘。

2. **截图**

- 截图内容清晰，文字完整、可读，避免模糊。

- 完整截入课表信息，不遗漏上下或左右部分。

- 避免截入通知栏、聊天窗口等无关信息。

- 确保截图中的课表内容直立、规范，不出现扭曲或倾斜。

**推荐课表样式**

1. **标准表格型**

课表以表格形式呈现，列为星期（如周一至周五）、行为节数，每个单元格包含相应的课程信息（课程名称、教师或教室等）。表格边界清晰，内容完整且排列整齐，便于系统识别。

![--63.98%](https://cdn.dida365.cn/hc/all/c5beea5d2bf2215dc5c212c9ae8bf532.png)

2. **标准列表型**

课表以列表形式呈现，第一行为表头，包含课程名称、上课周次、上课节次、上课地点等信息，后续每行对应一堂课程，确保每条课程信息完整且排版整齐，便于系统识别。

![--43.2%](https://cdn.dida365.cn/hc/all/5194f41e93e84212628ff302e052ff02.png)

**常见识别失败原因**

以下情况的图片可能无法被系统准确识别：

1. **非课表图片**：不是课表图片，图片中没有课程名称、上课周数、上课节次等关键字段的。

2. **关键信息缺失**：课程名称、上课周数、上课节次等其他关键信息不完整，被遮挡或截断的。

3. **多余或干扰信息**：图片中包含与课表无关的内容。

4. **课表方向不正确**：课表旋转或倒置，未保持正向的。

5. **非常规样式或样式不规范**：课表布局过于特殊或文字排版混乱。


::: spoiler 一次可以识别多张课表图片吗？
目前不支持批量识别。请一次上传一张完整的课表图片进行识别。如果您的课表分多张图，请尝试将它们拼接成一张完整的图片后再上传。
:::
::: spoiler 导入的课程会包含哪些信息？
通常包括课程名称、上课周次、上课节次、上课地点和上课老师。系统会尽可能地从图片中提取这些字段，最终导入取决于课表是否包含该信息以及系统能否准确识别和匹配。
:::

::: spoiler 识别出来的课程信息有误、不完整怎么办？
识别完后，请确认识别到的内容是否正确，若发现有识别错误的信息，可以修改后再导入。
:::

::: spoiler 课程导入成功后，如果课表有变动怎么办？
如果后续课表有调整，您可以在课表视图点击课程进入「编辑课程」页面，手动修改相应的信息。
:::
::: spoiler 我的课表图片上传后会被保存吗？隐私如何保障？
请放心，您的课表图片仅用于本次识别过程。识别完成后，图片数据不会被我们存储或用于任何其他用途。所有处理均在安全的环境下进行。
:::


## 方法二：教务网导入

在日历课表视图，点击「立即导入」-「教务网导入」-「立即开始」，选择你的学校，登录教务网站，打开课表界面，点击「确定导入」添加课程。

![--66.01%](https://cdn.dida365.cn/hc/all/96e2eea729127731fada047de7326cd1.png)

![l--103.89%](https://s3.cn-north-1.amazonaws.com.cn/dida-hc/hc/all/da76df46ba4fdba8d5a4a82d07dae4da.png)

> 目前我们已经支持近1000所学校课表导入，但是由于教务系统更新等原因，部分学校的课表需要适配才能导入成功，你可以在导入过程中申请适配。

# 智能清单中显示课程
在课表视图中，点击右上角「...」-「课表管理」中开启「在智能清单中显示课程」。

你就能够在“今天”、“明天”、“最近7天”清单中看到课程。

![--101.54%](https://cdn.dida365.cn/hc/all/695c757a394ef0eb499966b4bef55a40.png)

# 在日历中显示课表
除了在课表视图查看课程，你也可以开启「在日历中显示课表」，这样就可以在日历中，同时看到课程和任务，方便你更好地管理日程。

在「课表视图」中，点击右上角「...」-「课程管理」-「在日历中显示课表」，开启此功能，就能够在周视图中看到课程与任务。
