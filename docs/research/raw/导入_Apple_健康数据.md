# 导入 Apple 健康数据

> 原文: https://help.dida365.com/articles/7309849895597244416
> articleId: 67e1143947c89fff925914d1

滴答清单现已支持导入 **Apple 健康数据**，你可以在日历视图中查看相关健康信息，以更好地管理时间与健康。

> 健康数据同步仅支持 iOS 平台（iOS 16 及以上版本），并且应用版本请更新到v7.5.20或以上。

![](https://cdn.dida365.cn/hc/all/df15a84dc2b84b12fae96dbfb61f6cdc.png)



# 导入健康数据
进入 **「设置」**，选择 **「导入与关联应用」**，点击 **「Apple 健康数据」**，选择需要同步至滴答清单的健康数据。

![](https://cdn.dida365.cn/hc/all/c50ed59fc05d780c35692dc9f95489a3.png)

# 显示健康数据
授权后，数据将在 日历视图 中显示。

![](https://cdn.dida365.cn/hc/all/df15a84dc2b84b12fae96dbfb61f6cdc.png)

点击单个事件可以查看具体的数据情况。

![](https://cdn.dida365.cn/hc/all/ce183514586e0504ae09a8538e1adf15.png)


# 专注时间同步到 Apple 健康
开启 「专注时间」 功能后，滴答清单的专注时间可同步至 Apple 健康正念中。


![m](https://cdn.dida365.cn/hc/all/9cfdfff354e24d3ae469574b7eaae7b8.png)



# 常见问题
::: spoiler 为什么在电脑端看不到同步数据？
目前健康数据仅支持在 iOS 平台显示，暂不支持多端同步。
:::

::: spoiler 未显示 Apple 健康数据？
1. 确保在「苹果系统设置 > 隐私与安全 > 健康」中，已授予滴答清单访问权限。
2. 重新授权：在「苹果系统设置 > 健康 > 数据访问与设备」中，移除滴答清单的访问权限，然后重新授权。
:::

::: spoiler 是否支持同步所有的健康数据？
目前支持自动同步“前6个月~最新”的记录。
:::

::: spoiler 是否可以调整健康数据的显示方式？
不支持自定义显示方式，数据默认按 Apple 健康中的记录进行同步和展示。
:::
