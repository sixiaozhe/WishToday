# Exchange 日历

> 原文: https://help.dida365.com/articles/7193074856341012480
> articleId: 663840fe47c89fff9258e3c5


如果你想要在滴答清单中显示 Exchange 中的日历事件，你可以通过订阅 Exchange 的方式轻松实现。

# 添加日历

:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入「设置」-「导入与关联应用」-「日历」，选择 Exchange，输入账号密码，授权成功后即订阅成功。


![--65.97%](https://cdn.dida365.cn/hc/all/cd63a6b05d32dcfb42c29c1dca8d8579.png)
::::

::::tab [desktop]
点击头像 -「设置」-「关联与导入」，选择 Exchange，输入账号密码，授权成功后即订阅成功。


![](https://cdn.dida365.cn/hc/all/0c346d0c9fc4bca7a731e095d5b56482.png)

::::

:::::

# 常见问题
::: spoiler Exchange 为什么订阅企业微信日历不成功？
由于企业微信限制，第三方应用无法使用 Exchange 方式订阅成功，你可以使用 [CalDav 方式订阅企业微信日历](/articles/7190959806838996992)。
:::
