# 年视图：查看年度任务完成情况

> 原文: https://help.dida365.com/articles/7397517843383713792
> articleId: 6920035dfd36d294de7a6e5d

**年视图** 让你从全局视角回顾过去一年的任务完成情况。
通过热力图分布，你能直观地看到哪些月份任务完成度最高，哪些阶段效率相对较低，从而更清晰地了解自己的时间节奏与成长变化。

# 热力图显示
年视图支持以热力图方式展示任务完成频率，帮助你更直观地了解任务活跃程度。

默认情况下，热力图为关闭状态，可在显示设置中手动开启。
:::::tabContainer [mobile|desktop]

::::tab [mobile]
右上角「⋯」 → **显示设置 → 样式** → 热力图 → 显示「热力图」。

![--66.01%](https://cdn.dida365.cn/hc/all/026aec094a540278b788ff683c4b3eb7.png)

::::

::::tab [desktop]
右上角「⋯」 → 显示设置 → 样式 → 热力图 → 显示「热力图」。


![](https://cdn.dida365.cn/hc/all/dbb59b173390f342cff688dd8e382958.png)

![](https://cdn.dida365.cn/hc/all/890bdc6ca15f070fc0b83db61ca6b83e.png)

> 颜色越深，代表当天完成的任务越多。


# 常见问题

::: spoiler 为什么我在年视图中看不到任务？
- 若任务较多，数据加载可能稍有延迟，稍等片刻即可加载完成。
- 年视图仅显示「已设置日期」的任务。如果任务没有设置日期或时间，将不会出现在年视图中。请先为任务添加日期。
:::
::: spoiler 年视图能查看过去的任务记录吗？
可以。你可以切换年份，查看过往年度的任务完成情况与执行趋势。

:::

 
::: spoiler 年视图支持显示哪些内容？
年视图会根据「显示范围」设置展示内容。

除任务外，还可显示日历事件、习惯、纪念日等项目。

如果隐藏了“已完成任务”，则不会在年视图中显示。
:::
