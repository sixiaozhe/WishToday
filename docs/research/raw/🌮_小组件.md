![](https://cdn.dida365.cn/hc/all/eccd4e6332565b81951b4c1f8d3dcd4d.gif)


::: spoiler 如何添加“锁屏小组件”

> iOS 系统需升级到 iOS 16，并将滴答清单更新到 6360 版本及以上。

![](https://cdn.dida365.cn/hc/all/ae8944e2c288c15fe40a9f94a5d45ef3.png)

1. 在锁屏状态下，长按屏幕进入设置模式，点击「自定」。
2. 点击屏幕中间的「添加小组件」，找到「滴答清单」。
3. 选择需要的小组件类型，点击或拖移即可添加。
:::
::: spoiler 如何添加 iPad 锁屏小组件？
你需将iPadOS升级到 iPadOS 17，并将滴答清单更新到 6700 版本及以上。
1. 锁屏后长按屏幕，出现自定义按钮，点击自定义。
2. 在屏幕左侧栏点击添加小组件，找到滴答清单选择需要的小组件。

![](https://cdn.dida365.cn/hc/all/2b3e4f241099878603d47830ff388ba7.png)

 **桌面小组件**

滴答清单为大家准备了各功能模块的专属小组件，添加到手机桌面上，即可快速查看任务、日历、习惯等信息，提高效率。

> iOS 27 及以上系统中，部分小组件还支持全新的超大尺寸。

**1. 任务**

我们提供「任务」、「任务完成统计」、「添加任务」3款小组件。

![l](https://cdn.dida365.cn/hc/all/26f3c12d43e8d7d882720f865816f6c4.png)


- 「任务」：你可以查看、访问任务列表，了解每日的任务安排。
- 「任务完成统计」：你可以查看近30天内，每天完成的任务数量。
- 「添加任务」：你可以快速打开 App 添加任务。


**2. 日历**

我们提供「今日日历」、「日视图」、「月视图」3款小组件。


![l](https://cdn.dida365.cn/hc/all/b6be35be269fe237ebc68778f3acb9dc.png)



- 「今日日历」： 你可以查看“本月日历”和“今日任务”，点击任务还可以快速访问「今天」智能清单。

- 「月视图」：本月所有事情即刻呈现，轻松扫一眼即可知晓何时忙碌、何时空闲。



**3. 四象限**

- 你可以在四象限中查看你的任务，并且将更多精力聚焦在重要且紧急的事情上。

**4. 习惯**

![l](https://cdn.dida365.cn/hc/all/bc1f2010e08114a07fea622590ccea74.png)

**其他 iOS 小组件**

**1. StandBy 小组件**

iOS 17 新增了 StandBy 功能。在充电状态下，将 iPhone 横放即可进入 StandBy 模式，以翻页钟等形式展示信息。

![l](https://cdn.dida365.cn/hc/all/83b76e0694db0ae55a58689b07ab8197.png)

::: spoiler 如何在 StandBy 使用小组件？
1. 将手机系统升级至iOS 17后，在充电状态下锁定手机再将手机旋转成横屏放在支架上。
2. 进入 StandBy 模式后，长按时钟或者日历根据提示解锁手机。
3. 在屏幕左上角点击➕图标添加滴答清单小组件。
:::
::: spoiler iPad 如何进入 StandBy 小组件？
目前iPad 还不支持 StandBy小组件。

**2. 控制中心**

从 iOS 18 开始，你可以在「控制中心」中添加滴答清单控件，根据自己的需求打造更高效的快捷操作。

![m](https://cdn.dida365.cn/hc/all/848c0c08dec8d6c50b5ab1b9790a25a3.gif)


滴答清单一共带来了8个控件，分别是：添加任务、今日任务、番茄专注、正计时、打开日历、打开四象限、打开专注、打开习惯。

![m](https://cdn.dida365.cn/hc/all/95893d0da0563d399bd83e99227138a8.png)
> 通过这些控件，你可以快速开启专注模式或者快速跳转至指定页面中。

::: spoiler 如何添加控件？
向下滑动拉出控制中心，点击上角“+”号进入编辑状态，再点击最下方“添加控制”，找到“滴答清单”就可以添加滴答清单控件。
![l](https://cdn.dida365.cn/hc/all/a4c96eb4e793f8f7c6fa1912fd52a5f5.png)
:::

如果你想要更大一点的控件，你可以拖动图标右下角进行调整。

![m](https://cdn.dida365.cn/hc/all/a40fa8429e168bd205170839e825fea2.gif)

> 比如：常用的番茄专注，打开日历，可以调整为大一点的控件方便查看和点击。

::: spoiler 如何修改控制配置？
目前，添加任务、番茄专注、正计时、打开日历，这4个控件支持配置，可以进入编辑模式指定到不同的清单。

操作方式：向下滑动拉出控制中心，点击上角“+”号进入编辑状态，点击对应控件进入编辑状态，更改配置。
:::

# 如何添加小组件？
:::::tabContainer [iOS|Android|鸿蒙|macOS|Windows]

::::tab [iOS]
**添加“锁屏小组件”**

> iOS 系统需升级到 iOS 16，并将滴答清单更新到 6360 版本及以上。

![](https://cdn.dida365.cn/hc/all/ae8944e2c288c15fe40a9f94a5d45ef3.png)

1. 在锁屏状态下，长按屏幕进入设置模式，点击「自定」。
2. 点击屏幕中间的「添加小组件」，找到「滴答清单」。
3. 选择需要的小组件类型，点击或拖移即可添加。


> 如果在锁屏小组件列表内，没有找到滴答清单，可以尝试以下两种方法：
> 
> 1.如果你刚升级应用，请先打开重新打开一次 APP，然后再进行添加。
> 
> 2.如果还没有找到，重启手机后再进行添加（或者在「设置」-「通用」-「语言与地区」中切换语言，实现快速重启）。

# 常见问题
::: spoiler iOS 小组件为什么不能支持点击完成任务？
iOS桌面小组件已支持交互，需要将系统升级至 iOS 17，滴答清单升级为最新版本，即可体验。
:::

::: spoiler Mac 如何把小组件放在桌面上？
目前 macOS 14.0 已经支持将小组件放在桌面上，并且支持交互。需要将系统升级至 macOS 14.0 ，在编辑小组件时将小组件拖拽至桌面即可。
:::


::: spoiler 如何编辑小组件？
在桌面长按小组件，可以对小组件的“主题”、“显示内容”、“夜间模式”等等进行配置。
:::
::: spoiler 安卓为什么没有日视图？
安卓端的日视图叫做时间轴，你可以长按小部件，选择「编辑小部件」进入到「配置桌面小部件」进行设置。
:::
::: spoiler 有没有四象限小组件？
我们已支持四象限小组件，你可以向左滑动寻找。

:::
