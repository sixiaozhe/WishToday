# 教育优惠申请

> 原文: https://help.dida365.com/articles/7208410033590108160
> articleId: 66700afd47c89fff9258ec97

我们始终相信教育事业能给个人、给世界带来美好的变化，并希望能帮助更多学生和教职工管理好学习和生活、迎接挑战、达成目标。为此，我们特意推出教育优惠：在校学生和教职工可以获得滴答清单高级会员七五折优惠。

您可以使用尾缀为 edu.cn、csss.cn 和 ucas.ac.cn 的教育邮箱注册，或将当前账号切换为您的教育邮箱，再进行申请。
具体申请流程可以查看 [申请教育优惠](https://www.dida365.com/education)


以下是申请教育优惠的注意事项：

::: spoiler 一共可使用多少次教育优惠？
同一个滴答账户最多可申请 4 次。
:::

::: spoiler 可以连续申请教育优惠吗？是否有时间间隔？
* 申请后，以完成验证当天起，这次教育优惠的有效期为 1 年。
* 本次教育优惠的有效期内，不可重复申请。
* 本次教育优惠的有效期结束后，可进行下一次申请。
:::

::: spoiler 申请了但是没有购买，对剩余可用次数有影响吗？
* 申请了但尚未完成验证，不会影响剩余可用次数。
* 申请了并且完成验证，那么剩余可用次数减一。若在这次教育优惠的有效期内没有购买，等同于浪费了一次可申请机会。
:::

::: spoiler 教育优惠只能购买 1 年高级会员吗？
是的，教育优惠只支持购买 1 年高级会员，购买1个月时无法享受教育优惠。
:::

::: spoiler 使用教育优惠购买后，可申请退款吗？
使用教育优惠购买后，可以在 14 天内申请退款。但退款后，教育优惠的剩余可用次数不会返还。
:::

::: spoiler 教育邮箱不是 .edu 或 edu.cn 格式还能申请吗？
目前仅支持 .edu 或 edu.cn 的教育邮箱，如果你的教育邮箱后缀不同，暂时无法申请教育优惠。
:::
