# 打卡方式——每种场景都游刃有余
为了适应不同的打卡场景，滴答清单特意内置了三种不用的记录方式，最大程度的方便大家记录每一次的打卡成就。

## 自动记录
单次习惯完成量比较固定，推荐你设置自动记录。
如，喝水，大部分的情况是喝完一杯就打卡一次，完成量都是固定的一杯。

每滑动一次就自动记录完成了一杯。

![l--101.59%](https://cdn.dida365.cn/hc/all/79f1eeb20b80a51a0af2d46ca5ce2aad.png)

## 手动记录
当你的习惯完成量并不固定，推荐你设置手动记录。
如，背单词，可能早上状态比较好，一次背了3页，晚上有点累背了1页，每次的数量都不固定。

每次打卡时就能够根据当时的情况，手动输入完成的量。

![l--101.59%](https://cdn.dida365.cn/hc/all/b8ffe0b773b5399b729abee3408987aa.png)

## 完成全部
当然我们也有能够一次就能完成目标的习惯。
比如，早睡，这种习惯当天完成了就直接完成全部，没有完成量的记录。

滑动打卡就直接完成了这个习惯。

![l--101.59%](https://cdn.dida365.cn/hc/all/7eee5798cdc27db87c95a68afe95881d.png)

::: spoiler 如何设置打卡方式？
打卡界面点击右上角「...」-「编辑」-「目标」-「打卡时」中选择打卡方式。

![m--216.42%](https://cdn.dida365.cn/hc/all/2f72b9cdd921d5ce6e8d32d83666b94b.png)

:::

# 打卡提示——每次提醒都恰到好处
你可以根据自己完成习惯的时间来设置提示，如，喝水，提示时间可分在各个时间段9:00、12:00、18:00、21:00，到点都会自动提醒你喝水。


另外只要对单独一个习惯设置了时间提醒，在日历对应的时间轴中会出现，帮助你更好地查看日程安排。

![m--216.42%](https://cdn.dida365.cn/hc/all/12cd40e69002f5c25bb43ac8ac52dcc6.png)

::: spoiler 如何关闭在日历中显示习惯打卡？
在日历页面点击右上角「...」>「显示设置」，关闭「显示习惯」即可隐藏习惯打卡记录。

![l--101.59%](https://cdn.dida365.cn/hc/all/d3f4c4cef8529dd5cf21483725bbad8e.png)

:::


你还能够记录每天，完成习惯的心情以及日志，方便回顾。

![m--216.42%](https://cdn.dida365.cn/hc/all/2bc41ebd8e17711b94ad7dbe13856905.png)

::: spoiler 如何关闭打卡日志？
在「编辑习惯」中底部，可以将打卡日志关闭。

![m--216.42%](https://cdn.dida365.cn/hc/all/157b95fa728ef447f6bb770cbffd93d8.png)

如需在智能清单中显示习惯，可在习惯页面右上角点击管理图标，选择「在“今天”、“最近7天”中显示」。

![l--101.59%](https://cdn.dida365.cn/hc/all/2c2ec704830f43e2be285953d4aaa1b8.png)

在习惯统计中，我们提供了「打卡概览」和「月度打卡表」，你可以随时查看自己的打卡情况，即使哪一天没有背够5页的单词，也能记录自己完成3页的付出和努力。

# 常见问题
::: spoiler 当习惯不需要坚持，怎么归档？
如果你的习惯不需要坚持了，可以点击习惯详情页右上角「...」-「归档」。

![l--101.59%](https://cdn.dida365.cn/hc/all/d4503530d2bdfaadb8cb0895287dad94.png)

:::

::: spoiler 怎么设置打卡分组？
在编辑习惯页面，为习惯按照「上午/下午/晚上/其他」的时间段进行分组，将习惯分类，模块化展示，只需要长按拖动即可快速移动，更容易管理和查看。
:::

::: spoiler 如何在日历中显示习惯？
你可以在「显示设置」中开启「显示打卡」，这样日历中就能够显示习惯。

![l--101.59%](https://cdn.dida365.cn/hc/all/5bbf223d7afde15f40bc8152ccea9c8d.png)

:::
::: spoiler 删除和归档有什么区别？
- 删除：习惯将被永久移除，所有打卡记录也会被清空，无法恢复。
- 归档：习惯会从主视图中隐藏，但不会被删除，可在「已归档」中随时恢复。
:::


::::::: spoiler 如何恢复已归档习惯?

:::::tabContainer [mobile|desktop]

::::tab [mobile]

![--66.01%](https://cdn.dida365.cn/hc/all/856721036ebfdebd8d5390e35d6c743f.png)

::::

![](https://cdn.dida365.cn/hc/all/4f9183f8446b520e21c564915bdc1c5b.png)
