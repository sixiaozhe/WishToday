# 微信公众号
通过绑定滴答清单的微信服务号，你可以直接与服务号对话，无论是输入文字还是发送语音，滴答清单都能自动识别并保存为任务，并可设置提醒，确保你的待办不被遗漏。

这一方式省去了在应用间切换和复制粘贴的麻烦，让你随时随地快速记录灵感与事务。

## 操作说明

**1. 关注滴答清单服务号（didalist）**

微信扫描下方二维码，或者搜索“滴答清单”服务号。

![s](https://cdn.dida365.cn/hc/all/e34dda37b796acd4b76f151b560de294.png)


**2. 绑定滴答清单账号**

你需要先在滴答清单中绑定微信账号，操作方法如下：
:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入「账户信息」页面，在「第三方账户」中绑定微信。

![l](https://cdn.dida365.cn/hc/all/ef06d3a65f8c57a506a77b84ef8aca50.png)


::::

::::tab [desktop]
前往网页版滴答清单的「设置 > 账户安全」，完成微信绑定。

![l](https://cdn.dida365.cn/hc/all/eb06f9308fd09e78cb421da5ce99debc.png)

**3. 在服务号中直接输入任务内容**，支持文字、图片、语音、网页（文件暂不支持）

**4. 建议将服务号置顶，便于随手添加任务**
> 例如输入 “买牛奶 🥛” 或发送一张购物清单截图，即可自动保存为任务，默认保存在「收集箱」中。


## 配置滴答清单公众号
1. 关注「滴答清单」微信公众号
2. 进入公众号菜单栏，点击「更多功能」 > 「配置公众号」
3. 按照页面提示，完成相关功能配置

![l](https://cdn.dida365.cn/hc/all/da2c67fd93bcf7c62993c63f246d3f2d.png)



::: spoiler 如何解绑/更换？
进入「账户信息」页面，在「第三方账户」栏目中，点击「微信」旁的解除绑定按钮，即可完成解绑操作。

解绑后，你可以使用新的微信账号重新绑定。

# 滴答小助手
你可以在微信聊天中，将需要保存的文字、图片、网页等信息转发给「滴答小助手」，内容将自动同步到滴答清单 App 中，帮你快速收集待办，轻松管理琐事灵感。

## 绑定滴答小助手
- 进入「设置 > 导入与关联应用 > 微信」
- 选择「添加小助手」并保存二维码 → 添加为微信好友即可。

![l](https://cdn.dida365.cn/hc/all/1b684b4968c7d4a054610c061e954abf.png)


>💡 若尚未绑定滴答清单账号，请先关注公众号「滴答清单」，在「更多功能 > 我的账户」中完成账号绑定。


## 使用方法
成功添加并绑定后，只需将微信中的文字、图片、网页、聊天记录等转发给「滴答小助手」，内容会自动采集至滴答清单 App。

![l](https://cdn.dida365.cn/hc/all/3fac01f079494067111fad67dadb984a.png)


## 在滴答清单中查看
所有转发内容会统一保存至标签：#微信采集，你可以：
- 进入任务后进一步编辑内容
- 对不再需要的任务进行删除整理
- 重新归类或添加更多标签，便于后续管理


# 常见问题
::: spoiler 微信公众号和滴答小助手有什么区别？


滴答清单服务号更加适合用于**创建任务**，可支持文字/语音并且自动识别时间创建任务，同时也会回复你：创建任务成功。

![m](https://cdn.dida365.cn/hc/all/331ff981f94a6d7c84bb4de25bbb33f5.png)


而「滴答小助手」则更适合「转发消息」，你可以将所有想要收藏的内容转发给ta，小助手会将你所有发送的消息都将直接保存至滴答清单中，不会给你任何回复。

![m](https://cdn.dida365.cn/hc/all/de1727a8f8cd9864fc239be46f31239a.png)

PS. 助手不支持语音识别的哦，会将语音文件保存至滴答清单中。


:::

::: spoiler 如果被滴答小助手删除好友怎么办？
由于添加小助手有人数限制，太久没有使用会被系统清理，如果需要使用需要再次添加。

具体操作步骤如下：

1.删除滴答小助手联系人；

2.确认是否删除成功，微信中搜索滴答小助手，没有对应的联系人；

3.重新扫码添加滴答小助手（免验证通过的，无需我们做任何操作）。



![s](https://cdn.dida365.cn/hc/all/fcba0321b52710ff3b7c93f8e20f538f.png)

PS.滴答小助手为高级会员功能
:::
::: spoiler 为什么合并转发无法获得文章链接？
目前，不同系统对「合并转发」的支持能力存在差异：

- iOS 用户：支持在合并转发时生成并获取文章链接

- Android 用户：暂不支持通过合并转发获取文章链接

因此，Android 用户如需获取文章链接，需要通过逐条转发的方式进行操作。

我们会持续关注各平台的能力变化，并在条件允许的情况下优化相关体验，感谢你的理解与支持。
:::
