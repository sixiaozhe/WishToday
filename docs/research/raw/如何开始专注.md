# 开启功能模块
:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入「设置」-「功能模块」中，找到「番茄专注」，点击前方加号即可开启模块。 开启后，你将在底部导航栏看到「番茄专注」功能。


![](https://cdn.dida365.cn/hc/all/79e24183d568152982d2d1af995fae01.png)

::::

::::tab [desktop]
点击头像，进入「设置」-「功能模块」，找到「番茄专注」，点击开关启用模块。 开启后，你将在侧边导航栏看到「番茄专注」功能。

![--66.93%](https://cdn.dida365.cn/hc/all/d3d9a38068695d1277cf51de26d9c44a.png)

::::

:::::

# 在专注模块开始专注

:::::tabContainer [mobile|desktop]

::::tab [mobile]

在开始专注前，你可以先选择一种计时模式：

- 番茄计时：以倒计时方式进行，每轮 25 分钟专注 + 5 分钟休息，有助于保持专注并适度放松。

- 正计时：以正计时的方式持续记录专注时长，适合不希望被打断、希望沉浸式计时的人群。

![l](https://cdn.dida365.cn/hc/all/e3ceeb5ba5b26ba3a9b03164107ac45e.png)


如果你希望追踪每个任务的专注时间，还可以在开始前点击时间上方的「专注」，将此次专注关联到具体任务，方便后续进行数据分析。接着，点击下方的开始按钮，即可进入专注状态。

![m](https://cdn.dida365.cn/hc/all/1ceb94a82fd2b73f18bfc3b2cc518918.png)


::::

::::tab [desktop]
当你开启番茄专注功能，可以直接在侧边栏点击专注进入页面，点击「开始」快速进入到专注状态。

![l](https://cdn.dida365.cn/hc/all/ec45f46400bb993856637fcc40bf7824.gif)
:::::

# 在任务模块开始专注


## 在任务列表中开始专注

:::::tabContainer [mobile|desktop]

::::tab [mobile]

1. 任务滑动操作

在「设置-更多设置」中选择「滑动操作」，再选择「开始专注」。这样你就可以在任务列表中，通过滑动的方式，直接开始专注。

![](https://cdn.dida365.cn/hc/all/c6557a6a41ee7da9b80a5d13e5387be7.png)



2. 任务长按菜单


如果你是iOS用户，你也可以在「设置-更多设置」中开启「任务长按菜单」。这样你就通过长按任务的方式，快速开始专注。


![l](https://cdn.dida365.cn/hc/all/54ab2f7144f66393260c68bb559b1350.png)


::::

::::tab [desktop]
在任务列表页，右键单击需要专注的任务名称，点击「开始专注」后选择计时方式后即可开始专注计时。

![--73.2%](https://cdn.dida365.cn/hc/all/25c25d17930d0ace8d9f3b3301a9a97d.png)

:::::



## 在任务详情中开始专注

:::::tabContainer [mobile|desktop]

::::tab [mobile]
点击任务进入详情，点击右上角「...」-「开始专注」进入专注。

![m](https://cdn.dida365.cn/hc/all/07bd87da347fe1bd2c6a83445c5953fc.png)

::::

::::tab [desktop]
在任务详情页右下角的「...」中，点击「开始专注」后选择计时方式后即可开始专注计时。

![--73.2%](https://cdn.dida365.cn/hc/all/9b05ac1adfb4a80ad8eed6557c58c5c4.png)
:::::


## 提醒弹窗中开始专注
可以直接在任务提醒弹窗中点击「专注」快速开始。

# 专注多端同步

番茄专注支持多端同步。当你在某一端开启专注时，在其他端也会同步进入专注状态；当你在一端暂停或者结束专注时，其他端也会暂停或者结束。

:::::tabContainer [mobile|desktop]

::::tab [mobile]

如何使用？点击番茄专注页面右上角「 ... 」，在「专注设置」中开启「专注多端同步」即可。

![l](https://cdn.dida365.cn/hc/all/b34436a57bb266156e0f08324383e652.png)


::::


::::tab [desktop]

如何使用？点击番茄专注页面中的「 ... 」-「专注设置」，选择开启「专注多端同步」即可。

![](https://cdn.dida365.cn/hc/all/269a9f4e9d18abd7ef52b536f8794d5d.png)

# 专注小技巧

## 专注中调整时间
:::::tabContainer [mobile|desktop]

::::tab [mobile]

在专注页面中以及专注沉浸页面中点击时间区域会出现加减，你可以根据需要点击「+」或「-」调整时间。

![m](https://cdn.dida365.cn/hc/all/512424cfb9afb699fe30df286a3cb832.jpg)


::::

::::tab [desktop]

你可以在专注页面将鼠标移动至时间区域，点击时间两边的「+」「-」号即可调整专注时间。

![--73.2%](https://cdn.dida365.cn/hc/all/18de27c971f6a0e8e6233ca93810c849.png)

::::

:::::

## 专注笔记
:::::tabContainer [mobile|desktop]

::::tab [mobile]

在专注页面中底部点击「记录专注笔记」按钮，就能够在专注时随时记录所思所想。

![l](https://cdn.dida365.cn/hc/all/5a69f37d26cfeac6019c28ac82411f68.png)


::::

::::tab [desktop]

在专注页面右下方「专注笔记」区域可快速记录所思所想。

![--73.2%](https://cdn.dida365.cn/hc/all/53db977aa98cd1c1b842803d9858367a.png)

## 专注结束后编辑或补充时间

:::::tabContainer [mobile|desktop]

::::tab [mobile]

专注计时结束后，如果你仍在继续处理任务，可以点击计时器数字下方的额外时间，将后续时间也计入记录。

如果你提前完成任务却忘记结束计时，也可以在专注结束页面中点击计时器数字或者右上角「...」-「编辑专注时长」手动调整时长，使记录更加准确。

![l](https://cdn.dida365.cn/hc/all/2696ddd9722c068af931c82e1a286295.png)

::::

::::tab [desktop]

专注计时结束后，如果你仍在继续处理任务，可以点击计时器数字下方的额外时间，将后续时间也计入记录。

![--67.25%](https://cdn.dida365.cn/hc/all/afff6543659eed37b500892fc54f5e48.png)

如果你提前完成任务却忘记结束计时，也可以在专注结束页面中点击计时器数字或者右上角「...」-「编辑专注时长」手动调整时长，使记录更加准确。
