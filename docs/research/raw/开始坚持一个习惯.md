# 开启习惯打卡模块
你可以在移动端或桌面端开启「习惯打卡」功能，开启后即可开始记录和管理你的习惯养成进度。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
前往「设置」>「功能板块」，开启「习惯打卡」功能。

![l--101.59%](https://cdn.dida365.cn/hc/all/9c02bcbaae6f9f25f8e110f2f93546b9.png)

::::

::::tab [desktop]
点击头像进入「设置」>「功能模块」，开启「习惯打卡」功能。

![](https://cdn.dida365.cn/hc/all/4e15b7785c28fad113dd2ab503283504.png)

#  如何添加一个习惯？


## 习惯库添加
滴答清单习惯库中有超过60+的小习惯，覆盖生话、健康、运动、心态四大场景，你可以在分类中搜索自己想get的新技能，一键添加至打卡页面。


:::::tabContainer [mobile|desktop]

::::tab [mobile]
在下方栏中找到「打卡」，点击「+」，进入习惯库。

![l--101.59%](https://cdn.dida365.cn/hc/all/7031961ad5b6fd26d20ca1c8566ce722.png)

::::

::::tab [desktop]
在左侧边栏找到「打卡」，打开习惯列表页面，点击右上角的「+」，选择习惯图标，在「习惯库」中选择你需要的习惯。

![](https://cdn.dida365.cn/hc/all/8223f526d0265f4e97a32eb3e8b48edb.png)
::::

:::::

## 自定义习惯

如果习惯库中没有你想要的习惯，你也可以自定义习惯！
在习惯库中点击「自定义习惯」，你可以填写习惯名称、选择图标、还能根据情况写点鼓励自己的话，再点击下一步，就能对习惯进行再编辑。

![l--101.59%](https://cdn.dida365.cn/hc/all/30e7a6f9439c0acdbac58c76e6dc8ada.png)

#  编辑你的习惯
## 保持频率坚持做
在培养习惯时，我们不可能“一口吃成个胖子”，像健身这个事情，我们就不需要制定为每天都必须要做的一件事，你可以设置为一周完成3次。

你可以根据不同的习惯设置不同的打卡频率，如：健身，我只需要一周完成3次即可。

你可以在「编辑习惯」频率中设置。

![m--216.42%](https://cdn.dida365.cn/hc/all/a22cd3304e64f7296ed03f60ac970daf.png)

## 设立一个简单的目标
在建立习惯的初期，其实我们是在建立「不间断」的习惯，这时，为了让这件事情变得简单且易操作，我们不妨真的把它设置的超级简单，简单到你完全无法找理由不做。

- 你想要养成背单词的习惯，试试将完成目标设置为每天5个。
- 你想养成读书的习惯，不妨将完成目标设置为每天读2页书。

你可以在建立习惯时，「目标」中选择「当天完成一定量」设置。

![m--216.42%](https://cdn.dida365.cn/hc/all/f6b07a633fdf240f56b651ddc5544d36.png)

# 实时跟进打卡进度

你可以使用习惯热力图小组件，将习惯都钉在桌面上方便自己实时跟踪查看。

把它和今日习惯放在一起方便自己查看这一段时间的习惯的坚持情况。
