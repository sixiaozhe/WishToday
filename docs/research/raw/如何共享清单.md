# 共享清单
**只有你自己创建的普通清单支持共享，「今天」、「明天」等智能清单以及「收集箱」不支持共享协作**。因此，在开始共享前，请先新建一个用于共享的普通清单。

接着，进入该清单详情页面，点击右上角的「**···**」 → 选择「**共享协作**」 → 点击「**添加新成员**」，即可邀请对方加入共享清单。

# 邀请新成员
邀请新成员有以下三种方式：
- 联系人邀请：输入联系人电子邮箱，回车即可发送邀请，未注册过滴答清单的邮箱帐户，可以通过点击邮箱内的链接来激活共享。您也可以从最近邀请和团队成员里显示的联系人中选择一个或者多个进行邀请。
- 共享链接邀请：点击即可创建共享链接，复制发送给其他人。
- 微信二维码邀请：将二维码发送给好友通过扫一扫加入清单。（仅限 App 端）

# 接受邀请
 收到邀请后，被邀请人可以进入通知中心查看，选择接受邀请，即可加入共享协作。
