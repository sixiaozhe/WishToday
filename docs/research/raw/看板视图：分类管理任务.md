# 看板视图：分类管理任务

> 原文: https://help.dida365.com/articles/6950656501543337984
> articleId: 62c6574e1e3a8b2ac64c8317

看板是一种可视化的任务管理工具，你可以通过看板获得更多维度的任务分解、更加直观的信息展示、更具象化的进度监控。

你可以用看板随时随地分组管理你的大小事务，项目拆解、信息展示、流程跟踪、团队协作等等。
- 个人成长（年度规划、职业竞升、技能学习...）
- 团队协作（招聘管理、办公室采购、销售流程、市场运营...）


# 切换看板视图

看板并不是独立的功能模块，它是清单的一种显示方式。区别于其他视图，通过看板视图你能够更加清晰的查看到自己各个分组中的事项。

:::


> 目前已经支持在各智能清单、文件夹以及标签中切换看板视图。

# 使用看板视图
## 管理个人事项
在「最近7天」中选择看板视图，能够快速查看到自己在近7天中每一天需要完成的事情。

方便自己更加清晰的知道自己每天：有多少任务？具体是什么？以及任务的完成情况。

![--61.82%](https://cdn.dida365.cn/hc/all/a99fff00dd6d35feee2505d1dbc1d245.png)

也可以排序中选择**时间+优先级**，这样每天有哪些任务优先级更高清晰可见。

![--61.82%](https://cdn.dida365.cn/hc/all/8f4b6984ed20ffa8e867d138be98e0d1.png)

还可以在「今天」排序中选择清单+时间能够更聚焦自己各板块的事项安排以及完成情况，上班时重点关注工作清单，下班后重点关注其他清单。

![--61.82%](https://cdn.dida365.cn/hc/all/32feda03b7f7766c80abac26efc0cc14.png)


💡 如果计划出现变动时，你可以点击任务直接拖动到其他分组中，方便你灵活地调整任务。

::: video https://cdn.dida365.cn/hc/all/0f7459bfdbdb69407b442612100db6f3.mp4

# 制作个人看板
个人看板

你可以根据周期来制定看板，用看板将需要执行的任务可视化表现。
> 可以以一年为周期，也可以选更短的周期，比如一个季度、一个月、一周等等。

如：今年计划
- 第一列「想要做」，在这一年里，任何想法、需要做的事情都可以写进来。
- 第二列「准备做」，从第一列的想法里面挑几个放进来，建议控制在三件以内。
- 第三列「正在做」，这里放的是你正在专注做的事。
- 第四列「已完成」，如果一件事已经完成了，我们就可以移动到第四列来。

![](https://cdn.dida365.cn/hc/all/09b789aa3d58766ff426619c7f29bcf9.png)



当然，你还可以根据需求创建不同类别的分组：
- 按主题：英语、政治、专业课…
- 按进度：未开始、进行中、已完成…

# 团队看板

滴答清单的「看板视图」能有效帮助团队：
- 保持团队专注：目标明确标注在看板上，集中精力专注达成。
- 提高工作透明度：成员可以看到整个工作流程，明确项目方向并且权责清晰。
- 提高完成效率：负责人可以通过看板轻松组织任务和排期，

你可以根据团队的情况自由的创建卡片（分组），并将任务分配给团队成员。

拖拽即可灵活排序看板卡片，轻松应对团队工作中的任何变化。

## 指派负责人
创建好任务，通过「指派」完成任务的分配，成员会收到“任务指派通知”。


* 在看板视图右键任务，选择「分配给」即可。


![--63.83%](https://cdn.dida365.cn/hc/all/58b10b4baf94919ae873ce4cb04005df.png)





## 解决信息差
常规的看板视图是一种「被动」展示项目进展的方式，但在滴答清单中，你可以和你的成员通过「任务评论」进行沟通，有效地解决成员间的“信息差”。

- 当任务有所进展时，可以将动态发在评论区
- 点击任务，点击弹窗里的「评论」，在输入框里写下你的评论即可。


![--66.45%](https://cdn.dida365.cn/hc/all/c3fd31edbcbb860268f9de172c775afc.png)



另外，惊喜的是，每个任务被创建或编辑，滴答清单都帮你自动生成「任务动态」，你可以随时查看整个任务进行过程中的一切变动。


- 点击任务，点击弹窗右下角「...」-「任务动态」。


![--68.16%](https://cdn.dida365.cn/hc/all/b5c1052c5431b358a340d746a4c0310b.png)

# 常见问题
::: spoiler 智能清单支持看板视图吗？
智能清单支持看板视图，你可以在电脑端清单右上角「排序」或者手机端「...」-「排序」中选择不同的分组方式，来帮助你更好地在智能清单中使用看板视图。
:::

::: spoiler 看板视图支持调整宽度吗？
电脑端看板视图支持调整宽度，有小、中、大三种尺寸供你选择。点击看板视图右上角「...」进入「显示设置」即可调整。

![--57.34%](https://cdn.dida365.cn/hc/all/87c815cafcadb8ad562581afb7ab8faa.png)

在「显示设置」中，你还可以设置「显示输入框」，帮助你更快地在看板中添加新任务。

:::

::: spoiler 为什么我无法「编辑分组」或者「管理分组」？
需要先在清单右上角的「排序」中将「分组」改为「自定义」，才可以管理分组。
:::
