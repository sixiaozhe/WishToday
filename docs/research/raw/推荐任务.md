# 推荐任务

> 原文: https://help.dida365.com/articles/7401559568137846784
> articleId: 692eb783fd36d294de7a7152

待处理的任务还有很多，却不知道该从哪些任务开始时，试试「**推荐任务**」。它会根据任务的时间、修改频率、到期时间等因素，对任务进行归类展示，帮助你更快决定“今天做什么”。

# 查看推荐任务

根据任务的创建时间、修改记录、创建时间和截止日期，我们帮你整理出了四类推荐任务。

## 最近添加

担心忘记那些刚添加、但没有安排时间的任务？在「最近添加」分组中，你可以查看**刚刚**、**今天**、**昨天**添加、未设定时间的新任务。快速回顾这些新任务，并将需要尽快处理的安排到「今天」。

![l--101.59%](https://cdn.dida365.cn/hc/all/8e9874481da0eb0e18e139abca082bc6.png)


## 多次修改时间

你是否有些任务一拖再拖却始终没有完成？在「多次修改」分组中，任务会按修改时间的次数顺序从高到低排序。点击「多次修改」进入详情页，查看修改**超过 5 次**、**超过 3 次**、**超过 2 次**的任务，选择并优先处理那些拖延很久的任务。

![l--101.59%](https://cdn.dida365.cn/hc/all/22010adf7cdbbc8c3a5d2c99d27eb50c.png)


## 长时间未完成

有些任务创建了很久却一直没有完成？在「长时间未完成」分组中，你可以查看那些被搁置已久的任务，比如：创建**超过7天**、**超过14天**、**超过30天**未完成的任务。浏览这些久未行动的事项，挑选还要继续推进的任务安排到今天。

![l--101.59%](https://cdn.dida365.cn/hc/all/7a0e553cae2dbd95944f7ca9ad703a36.png)


## 即将到来

今日的任务都已经完成，还有剩余时间？在「即将到来」分组中，你可以查看**明天**、**后天**到期的任务。选择即将到期任务安排到今天提前处理，让你的执行节奏更加从容。

![l--101.54%](https://cdn.dida365.cn/hc/all/1167a944335efd3dea9db8b0b31e3e0a.png)


# 添加到「今天」

从推荐任务列表中，挑选你想今天执行的任务，点击右侧的 「**+**」 按钮，即可快速将任务添加到「今天」，无需手动复制或编辑。

# 常见问题（FAQ）

::: spoiler 1. 推荐任务会在我所有任务中进行推荐吗？推荐范围是什么？

推荐任务将筛选所有无重复、非今天的未完成任务，再根据一定的条件进行分类推荐。

:::
