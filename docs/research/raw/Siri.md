# Siri

> 原文: https://help.dida365.com/articles/6950042073403752448
> articleId: 62c41b13c3bb3bd197e6e93b

你可以将一些常见的操作添加到 Siri 作为语音指令，

以后只需要对 Siri 说活就能自动执行，听起来是不是很酷！

如果你习惯每天早上检视一遍今天的任务，

就可以把「查看"今天"」添加到 Siri 捷径并录制语音指令（比如录制：“今天做什么？”），

那么以后只要对 Siri 说：“今天做什么？”，Siri 就会帮忙自动打开滴答清单的智能清单“今天”了。



# Siri 创建任务
在「设置」-「Siri」中开启「通过 Siri 添加任务」，即可通过 Siri 创建任务。

![m](https://cdn.dida365.cn/hc/all/f65e1a2cfe233d9e360eccdd1e3fb7eb.png)

# Siri 快捷指令
你可以将常见操作添加到Siri作为语音指令，设置成功后，只需对Siri发出语音指令，Siri就能帮你自动执行。
