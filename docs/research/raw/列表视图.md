# 列表视图

> 原文: https://help.dida365.com/articles/6950656708259610624
> articleId: 62c657801e3a8b2ac64c8341

列表视图将任务以垂直列表的形式呈现在我们眼前，通过上下滑动可以快速浏览清单内的待办事项。

![m](https://cdn.dida365.cn/hc/all/e7b0c15ce65f70c10f2a30c94d6204b9.png)



# 排序

目前，在任务列表页，滴答清单为你提供了多种排序方式，你可以根据自己的需求选择不同的排序方式。


![l](https://cdn.dida365.cn/hc/all/537f7af7106921fa5eedba218155b77c.png)


# 拖动排序

你还可以自已手动拖动任务的顺序，让任务排序更灵活。

按住任务，自由选择放置任务的位置。多种操作，一“指”搞定。

# 拖动生成子任务

滴答清单不仅支持拖动调整任务排序，你还可以用拖动来实现「任务」➡️「子任务」的转换。

长按任务，将其拖至另一个任务右下方，即可将这个任务转换成子任务。


![m](https://cdn.dida365.cn/hc/all/316162fc2255870e6f334194eff533c0.png)

# 置顶

滴答清单还贴心提供了置顶功能，你可以将重要信息「置顶」，让其始终展示在列表的最前端，看一眼就能心中有数。

点击任务详情页右上角「···」，选择「置顶」即可设置成功。

![l](https://cdn.dida365.cn/hc/all/5f071b78417dde1a0e13960f7021142f.png)

# 滑动操作

在任务列表页可以通过滑动单条任务进行快速操作。

将任务向左短滑，可以看到任务右侧出现了三个选项，它们分别代表：「移动任务」、「删除任务」、「修改日期」，根据需要点击对应的选项进行操作。

![m](https://cdn.dida365.cn/hc/all/f0ce6701f7a9c40e5ac2d5be33678ec2.png)


向右滑动分别为「完成」、「置顶」。

![m](https://cdn.dida365.cn/hc/all/a1210517d0048027a2e51077747fdfe2.png)

还可以在「设置」 - 「更多设置」- 「滑动操作」中，进行自定义配置，根据自己的偏好习惯来设置更顺手的滑动方式。


![](https://cdn.dida365.cn/hc/all/7a8d8944c679d52e12c76d5bb0f1b9f4.png)

# 批量编辑任务
:::::tabContainer [iOS|Android|desktop]

::::tab [iOS]
在任务列表页点击右上角的「...」图标 - 「批量编辑」 - 选中多个任务后，即可在下方选项中根据需要选择为任务进行：编辑新日期、编辑新所属清单、删除，甚至进行优先级、分享和合并任务的操作。

![l](https://cdn.dida365.cn/hc/all/de8a34287d26202c674dd832444402b7.png)



::::

::::tab [Android]
安卓用户需要长按住一条任务切换到批量选择界面，然后选择多个任务，在右下角的选项中根据需要为任务进行：编辑新日期、编辑新所属清单、删除，甚至进行优先级、分享和合并任务的操作。

![m](https://cdn.dida365.cn/hc/all/347cfae0a4560d666f982f3b52dfb48d.png)


::::

::::tab [desktop]
桌面端按住Shift同时，选择多个任务，或者选择首尾任务即可进行批量操作。

![--59.6%](https://cdn.dida365.cn/hc/all/5f77a6a36707104cb09178f124c98efb.png)

# 视图多端独立配置
你可以为手机端和桌面端分别设置清单视图，不同设备的视图设置互不影响。
> 仅支持 Android 和网页端。


:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入对应清单 → 「显示设置」 → 「视图跨设备同步」。

![l](https://cdn.dida365.cn/hc/all/6fd744207ab3c8973928040b853cbc3f.png)


::::

::::tab [desktop]
进入对应清单 → 「显示设置」 → 「视图跨设备同步」。

![l](https://cdn.dida365.cn/hc/all/3d470f31f74df04d651e79057407dc3b.png)
