# 超强大的提醒功能

> 原文: https://help.dida365.com/articles/6950660229746917376
> articleId: 62c65ac71e3a8b2ac64c8397

当你的任务设置了「提醒」，将会根据你设置的提醒时间，按时提示你，帮助你高效完成各个任务。

# 如何设置提醒


在任务详情页，点击任务标题上方的「日期&重复」按钮，选择「设置提醒」。

![m](https://cdn.dida365.cn/hc/all/8f1aeba4fb5dbad765b095d5e92df7af.png)



你还可以为任务设置「多个提醒」。

![l](https://cdn.dida365.cn/hc/all/08e87e88f224982a5bceaafb0639ef22.png)





::: spoiler 如何自定义提醒时间？
在设置提醒时选择 **自定义**，即可自由选择所需的提醒时间。

![](https://cdn.dida365.cn/hc/all/06cd9612202fd3607be3d8d085641e44.png)


:::

::: spoiler 如何为任务设置同样的提醒？
你可以通过修改「任务默认值」，在「设置」-「更多设置」-「任务默认值」-「默认提醒」中选择常用的提醒，将它设置为默认提醒。

![l](https://cdn.dida365.cn/hc/all/b7a42b128fc51bdfc8e7de87fb2c6895.png)



- 你还可以为任务设置「默认日期」、「默认优先级」、「默认清单」等等。
:::


# 提醒弹窗

为任务设置好提醒时间后，到时间滴答清单会准时提醒你完成这个任务。

将会弹出「提醒弹窗」提醒你处理任务。你可以根据自己的实际情况，选择「忽略」、「开始专注」、「完成」以及「稍后提醒」。

除了在应用内收到提醒，你还可以在应用外以及锁屏时收到提醒弹窗。


::: spoiler 为什么没有收到提醒？
可以在「设置」-「声音、提醒与通知」中开启通知权限。

:::

::: spoiler 为什么任务没有准时提醒？
因为安卓系统限制的原因，部分手机需要在「设置」- 「声音、提醒与通知」中，开启「闹钟模式」。
:::

# 微信提醒
除此之外，滴答清单还支持「微信提醒」，当你的任务设置了提醒，将会根据你设置的提醒时间，同步在「微信」中给你提示。

![60%](https://cdn.dida365.cn/hc/all/889f5123e6d03c77bae1394ef930dbd9.gif)

::: spoiler 如何开启微信提醒？
👉🏻在「设置」-「声音、提醒与通知中」-「微信提醒」中完成微信绑定，开启微信提醒。

![l](https://cdn.dida365.cn/hc/all/62d0cced8830ab920163085c5aea3dee.png)

:::


# 更多场景下的任务提醒
## 农历生日提醒
及时的生日祝福不仅能够增加与他人亲密友好关系，也会让我们自己感到快乐和满足。在滴答清单中设置「农历生日提醒」，再也不用担心会忘记家人朋友的生日。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
在「设置」-「显示农历」开启后，选择农历日期对应的阳历日期，点击「设置重复」，选择「农历每年重复」即可。

![l](https://cdn.dida365.cn/hc/all/6709b85a51f449704dc8b3defc47b19c.png)


如果你需要农历每月提醒，在「设置」-「显示农历」开启后，选择农历日期对应的阳历日期，点击「设置重复」，选择「农历重复」-「农历每月」重复即可。

![](https://cdn.dida365.cn/hc/all/d5c8490c84b1e4cb0a79103608b08863.png)

## 艾宾浩斯提醒
我们经常在学习一项新的内容时发现忘得特别快，比如背单词。滴答清单支持「艾宾浩斯重复」，能有效帮你科学安排学习周期，提高你的学习效率。
:::::tabContainer [mobile|desktop]

::::tab [mobile]

![m](https://cdn.dida365.cn/hc/all/42892f7bebb88f936782d4a9bb235158.png)



设置后，该任务就会按记忆曲线添加到你未来的日程中。你还可以根据背诵效果，选择「按日期结束重复」或「按次数结束重复」。

##  位置提醒

你是否有些事项是需要到达具体的地点才能做成的，比如“去打印店复印公司文化宣传册"，然后现实却是，路过打印店时，完全把这件事忘在脑后......

而「位置提醒」功能，能够帮你一招搞定这些烦恼。

- 创建任务例如 “到店复印公司文化宣传册”，进入任务详情页，点击右上角「…」-「位置」，输入打印店位置。
- 设置成功后，当你到达打印店位置，滴答清单就会自动提醒你。

![](https://cdn.dida365.cn/hc/all/1b3d72d402ef6f61ab96fdf491e3b217.png)


> 「位置提醒」暂时只支持在iOS应用使用。




## 结束时间提醒
当你有一个会议或活动安排时，如何轻松知道活动何时结束，不错过任何截止期限呢？通过设置结束时间提醒，你可以在活动接近尾声时得到提醒，确保任务按时结束。

在设置任务时间段后，选择「提醒」，勾选「结束时」即可。设置后，你将会在该任务的结束时间收到提醒。

![l](https://cdn.dida365.cn/hc/all/a3093aabb095da69654a3534deb1f248.png)



# 如何设置提醒铃声
为任务设置好提醒时间后，你可以在「设置」-「声音、提醒与通知」-「提醒铃声」中选择自己喜欢的铃声。

![m](https://cdn.dida365.cn/hc/all/4f7c2680a9dc6005b64b6510bea84dc4.png)


如果你想为“不同优先级的任务“设置”不同的提示铃声”：时间一到，不用打开手机也能通过铃声来分辨任务的优先级，你可以开启「按优先级设置提醒」。

![m](https://cdn.dida365.cn/hc/all/efaf06c64f3a81aafe328e3eb5717e89.png)
