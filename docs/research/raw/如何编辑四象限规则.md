# 如何编辑四象限规则

> 原文: https://help.dida365.com/articles/6950381682822217728
> articleId: 62c5575d1e3a8b2ac64c7f8b

在四象限中，每个象限都对应一组筛选规则。任务会根据当前视图的规则，自动显示在符合条件的象限中。

为了帮助你快速开始使用，我们提供了两套常用规则方案：

- **规则方案 1：象限对应任务优先级**
	
	根据任务优先级，将任务显示到不同象限。
- **规则方案 2：象限对应重要程度和紧急程度**
  
	使用优先级判断重要程度，使用任务时间判断紧急程度。
 
你也可以根据自己的需求，自定义每个象限的规则。

# 选择四象限规则
## 规则方案 1：优先级（默认）
该方案根据任务优先级，将任务显示到对应象限。


![m](https://cdn.dida365.cn/hc/all/be688fb48e32a3437c8045591771c528.png)

例如：

将「工作汇报」设置为高优先级后，该任务会自动显示在「重要且紧急」象限。

![m](https://cdn.dida365.cn/hc/all/c700c8205698905289cba67059715398.gif)


当你拖动任务到其他象限时，任务的优先级也会根据目标象限自动调整。

![m](https://cdn.dida365.cn/hc/all/2b071f1d56ba1108dd8dc0c751985e81.gif)




## 规则方案 2：时间 + 优先级
该方案结合任务的时间和优先级进行分类：
- **任务时间**：判断任务的紧急程度。
- **优先级**：判断任务的重要程度。

![m](https://cdn.dida365.cn/hc/all/a96b2031a80fdd3dfc9143affdaa7748.png)

例如：
- 「今天到期 + 高优先级」的任务，会显示在「重要且紧急」象限。
- 「较远日期 + 低优先级」的任务，会显示在「不重要不紧急」象限。

![m](https://cdn.dida365.cn/hc/all/6b9dfe38966ccc7f5a407c1592524e06.png)

当你拖动任务到其他象限时，任务的日期和优先级也会根据目标象限自动调整。

随着任务日期变化，任务所在象限也会自动更新。

> 例如：
一个原本距离截止日期较远的任务，随着日期临近，可能会自动进入紧急象限。

**编辑象限时，你可以通过以下条件筛选任务，设置每个象限显示的任务范围。**

## 清单 / 标签
通过选择清单或标签，筛选符合条件的任务。

例如：

- 选择「工作」清单，只显示工作相关的任务。

- 选择「项目」标签，只显示带有该标签的任务。



## 时间
通过设置任务的日期范围，筛选不同时间段的任务。

例如：

* 设置「已过期、今天～明天」，筛选需要紧急处理的任务。

- 设置「后天～未来 7 天」，筛选近期需要处理的任务。

## 优先级
通过设置任务优先级，筛选不同重要程度的任务。

例如：

- 设置「高优先级」，筛选需要重点关注的任务。

- 设置「低优先级」，筛选优先级较低的任务。


## 指派人
在包含共享清单的视图中，你还可以根据任务的指派人筛选任务。只有包含共享清单时，才会显示「指派人」筛选条件。

例如：

- 设置「指派给我」，只显示分配给自己的任务。

- 设置「未指派」，只显示尚未分配负责人的任务。



> 注意： 如果象限规则设置为「指派给其他成员」，将任务拖动到该象限时，可能会提示操作失败。遇到这种情况，可以直接修改任务的指派人，使其符合该象限的规则。


# 多个条件组合
你可以组合多个条件，重新定义每个象限显示的任务。

设置多个条件后，任务需要**同时满足所有条件**，才会显示在该象限中。


通过组合不同条件，你可以根据自己的任务管理方式，定义适合自己的四象限。

| 象限 | 设置条件 | 示例 |
| :---: | :---: | :---: |
| 重要且紧急 | 工作清单 + 高优先级 + 今天～明天 | 近期需要优先处理的重要工作 |
| 重要不紧急 | 生活/运动/兴趣 + 中高优先级 + 本周 | 需要持续推进的个人目标 |
| 紧急不重要 | 工作/生活 + 低优先级 + 今天～明天 | 临时需要处理的事务 |
| 不重要不紧急 | 想法/待整理 + 无日期或未来日期 | 暂时不需要处理的事项 |

通过组合不同条件，你可以根据自己的任务管理方式，定义适合自己的四象限。
