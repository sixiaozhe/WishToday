# 周视图：轻松安排周计划

> 原文: https://help.dida365.com/articles/6950641140068515840
> articleId: 62c649001e3a8b2ac64c81c7



滴答清单提供的「周视图」能协助你有效达成目标，井井有条地安排计划，并有效督促你完成一项又一项任务 。



# 认识周视图


:::::tabContainer [mobile|desktop]

::::tab [mobile]

移动端周视图提供时间轴样式和格子样式。

1. 时间轴样式

由「全天任务栏」、「竖向时间轴」组成，能清晰地查看你当前的任务、同时也可以有效地对每日进行横向比较。

![m](https://cdn.dida365.cn/hc/all/c600d545f608799d6725ab347fcc7c8e.png)



- 全天任务栏：当天“未设置时间”的任务、全天任务、跨天任务都会显示在这里。
- 竖向时间轴：设置了时间的任务会直接展示在时间轴中。

> 除此之外，在移动端我们还提供了「日视图」、「三日视图」，方便你聚焦短期任务。


2. 格子样式

由八宫格组成，第一格是迷你日历，提示当前的一周处于当前月的哪一周，而剩下的每一格则代表着一周中的每一天，对应日期的任务会显示在对应的格子里，能清晰的展示你的一周任务安排。

![m](https://cdn.dida365.cn/hc/all/6319950f3786d88b600555803a3dbded.png)



::: spoiler 如何切换移动端周视图样式？
在日历模块选择周视图后，点击顶部切换样式即可切换为时间轴样式或者格子样式。

![l](https://cdn.dida365.cn/hc/all/ceef316947bca815d5b97e2648ab202c.png)



:::

# 添加任务
任务多种多样？有的任务是一天都在做、也有具体时间段需要完成的任务、甚至还有持续几天都需要进行的任务... 不用担心，在滴答清单都能轻松制定。

## 添加全天任务
:::::tabContainer [mobile|desktop]

::::tab [mobile]

你可以点击右下角「+」号添加，或者长按「全天任务栏」添加全天任务。

![m](https://cdn.dida365.cn/hc/all/dc6219bb9dbc55da538a3b9d0b89b34a.png)

在周视图格子样式中，你还可以拖动右下角的“+”号到日期格子中添加对应日期的任务。

![l](https://cdn.dida365.cn/hc/all/7df3bd6c550673636d091822fb1a9329.png)

::::

::::tab [desktop]

点击日期旁空白处添加。


![](https://cdn.dida365.cn/hc/all/01d31cbbbea0f65fe6e4661d7c6fdfc0.png)

::::

:::::



## 添加时间段任务

:::::tabContainer [mobile|desktop]

::::tab [mobile]

在时间轴样式中，你可以通过以下步骤添加时间段任务：

- 在「时间轴」上长按，会默认添加时长为“一小时”的任务。
- 你还可以通过长按拖动，添加任意时长的任务。
- 长按任务块后松手，拖动任务块边缘的两个小点，可调整任务时长。

![m](https://cdn.dida365.cn/hc/all/241a907767df64a9c53efd2664b63b50.png)


在格子样式中，你可以通过以下步骤添加时间段任务：

- 点击某一日期进入对应日期日视图页面；
- 在时间轴上长按拖动，即可添加任意时间段的任务；
- 点击左上角“返回”按钮，或者滑动手机侧边即可返回周视图。

![](https://cdn.dida365.cn/hc/all/0ff24dcb1bf0cd5fd221775e2d1b8add.png)


::::

::::tab [desktop]

- 在「时间轴」上点击默认添加一个时间点任务。

![](https://cdn.dida365.cn/hc/all/265c49237b4f629517020b33dd61edda.png)


- 你还可以通过长按拖动，添加任意时长的任务。
- 将鼠标放置在任务块边缘，出现上下箭头图标后即可拖拽调整任务时长。
::::

## 添加跨天任务

:::::tabContainer [mobile|desktop]

::::tab [mobile]

使用时间轴样式时，点击右下角「+」号，选择日期时，点击「时间段」，开启「全天」按钮，选择开始和结束日期即可。

![](https://cdn.dida365.cn/hc/all/0ae7b8b729dcee3537cd48470b396eb5.png)


使用格子样式时，你可以通过长按某一日期格子并拖动选择多日，即可添加跨天任务。

![l](https://cdn.dida365.cn/hc/all/3dba42d9e0db243a7e5b27ec25374583.png)


::::

::::tab [desktop]

在日期格子上长按拖动，即可选中多个日期，添加跨天任务。

![](https://cdn.dida365.cn/hc/all/54055ff859f16961a2a58481b2e73b68.png)

# 安排任务

## 轻松调整任务时间

临时有事，安排的任务需要调整时间？在日历视图里轻松用手指就能完成，按住任务块，将它拖动到相应的时间即可完成。

在格子样式中，你还可以长按任务并拖动到屏幕边缘将任务调整到下一周，或者将任务拖动到小日历上直接更改日期。

![l](https://cdn.dida365.cn/hc/all/34d6fad26709654a19f5c5cb1a484b9e.png)


## 安排没有时间的任务

把安排任务栏打开，你可以在这里查看到所有无日期的任务，快来给它们安排一个合适的时间吧。
:::::tabContainer [mobile|desktop]

::::tab [mobile]
左滑右侧屏幕边缘，或者点击日历视图右上角「···」-「安排任务」，拖拽到日历中即可。

![l](https://cdn.dida365.cn/hc/all/e7fbe1d541e132787c18d97d0fd99837.png)


::::

::::tab [desktop]
点击日历右上角「···」-「安排任务」，拖拽至日历中即可。

![](https://cdn.dida365.cn/hc/all/98bce98f802b132e51831b68765bd678.png)

# 查看任务



## 轻松滑动查看过去与未来的安排
:::::tabContainer [mobile|desktop]

::::tab [mobile]

滴答清单还支持「任意滑动」，快滑切换一周，拖动慢滑可以自由控制显示 7 天的范围。
- 轻轻松松，将本周的未完成的工作调整到下周。
- 双击页面上方月份，可快速跳回本周。

![m](https://cdn.dida365.cn/hc/all/284ec68d854a06607d1b4bff05956927.png)



我们在时间轴视图里还支持以下功能：

- 「时间轴」支持双指缩放。看不清或者由于任务块宽度限制显示不出名称的任务，双指放大；想一次性看更多小时段，双指缩小。
- 「时间轴」支持隐藏时间段。
> 点击隐藏的时间段即可展开，点击展开的隐藏时段随便一处即可隐藏。
>
> 展开隐藏的时间段之后，长按上下拖拽该按钮即可对其进行调整。

![m](https://cdn.dida365.cn/hc/all/24a23c700d795aaa5528615d0a736892.png)


在移动端查看「周视图」时，如果觉得任务太密、时间轴太挤，不妨切换到「三日视图」。

「三日视图」依然采用时间轴结构，但一次只显示三天，整体排布更宽松，任务名称和时间段显示得更清晰。适合用来细化最近几天的计划，比如排布这三天的重点事项、时间段安排。

![](https://cdn.dida365.cn/hc/all/df90d8afb487c8926f385c364ce29205.png)



::::

::::tab [desktop]

- 使用笔记本触控板双指左右滑动可以向前或向后滚动显示的时间范围；你也可以点击右上角的左右箭头按钮，或者使用键盘左右/上下方向键来切换显示的时间范围。

- 点击界面右上角「今天」按钮可快速回到今天。

![](https://cdn.dida365.cn/hc/all/13cebc11dc933b6cafccf31a9f0db2be.png)


我们在时间轴视图里还支持以下功能：

- 拖动**全天任务区域底部边缘**，可自定义全天区域的显示高度，扩大区域高度可以查看更多任务，避免重叠或遮挡。

![](https://cdn.dida365.cn/hc/all/0318cd608ae607f817bd443e03a68519.png)


- 「时间轴」支持缩放查看：使用笔记本触控板进行**双指捏合**（缩小）或**双指张开**（放大）操作，可以查看更多或者更少小时段；你也可以按住 Ctrl 键并滚动鼠标滚轮，亦可实现同样的缩放效果。

- 「时间轴」支持隐藏时间段：单击隐藏的时间段即可展开，点击展开的隐藏时段随便一处即可隐藏；展开隐藏的时间段之后，拖拽隐藏时间段边缘按钮即可隐藏时间段进行调整。

![--72.07%](https://cdn.dida365.cn/hc/all/a8dd5f06d434d9633652ffc298a6ded9.png)

![--72.07%](https://cdn.dida365.cn/hc/all/de7766181e1adabff076988565dd4600.png)


希望能够用更加灵活的方式查看一段时间的日程？不妨尝试「多日视图」。

无论是为了规划10天的工作安排，还是为了安排3到5天的旅行行程，这一功能都能轻松满足你的要求。

![](https://cdn.dida365.cn/hc/all/762431ab3bcddacd67c81049d46e1baa.png)

你还可以使用「多周视图」来查看2周或3周的任务安排。

![](https://cdn.dida365.cn/hc/all/571c03a639e87dfc017da32018982205.png)


> 多日视图、多周视图仅限桌面端。
