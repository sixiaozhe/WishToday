# 在第三方日历中订阅滴答清单

> 原文: https://help.dida365.com/articles/6950000444106080256
> articleId: 62c3f44e0223aebb27da25ac

滴答清单支持生成「URL 链接」，你可以通过这个方式将滴答清单日历同步到 Google、Outlook 等其他日历中。



登录滴答清单桌面端， 点击「头像」-「设置」-「关联与导入」，找到「其他」-「订阅滴答清单」。

![](https://cdn.dida365.cn/hc/all/975f47ab526de258be9aa144206038e7.png)


点击「获取 URL」选择需要订阅的清单，生成对应的 URL 链接，在其他应用输入链接即可完成订阅。

![](https://cdn.dida365.cn/hc/all/eb17096a9737fc053ca669fdb5ad9703.png)

![](https://cdn.dida365.cn/hc/all/6820743cb31b0a8b10bd2a9276f5cdf4.png)
