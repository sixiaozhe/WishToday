# 用标签管理任务

> 原文: https://help.dida365.com/articles/6950656299306582016
> articleId: 62c6571e1e3a8b2ac64c82ff

给任务添加「标签」可以更加快捷的进行任务管理。一个任务可以添加多个标签，标签常常和类别、状态或者地点关联。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
- 使用前，确认侧边栏中是否已经开启显示标签，开启后，标签将显示智能清单下面。


![m](https://cdn.dida365.cn/hc/all/3faa4645b3bdfc8475c327e0e29c6e8d.png)


如果标签未在侧边栏中显示，点击侧边栏右下角「设置」进入清单管理页，点击「标签」，选择「显示」即可。

![l](https://cdn.dida365.cn/hc/all/e35a9290c099b3c6bf29fadc5a90dfea.png)

::::

::::tab [desktop]
使用前，确认侧边栏中是否已经开启显示标签，开启后，标签将显示在清单下面。

# 为任务添加标签

:::::tabContainer [mobile|desktop]

::::tab [mobile]

- 方式一：在创建任务时，点击任务输入栏下方的「标签」图标，选择添加已有标签或创建新标签。

- 方式二：创建任务时输入「#」快速创建标签。

![m](https://cdn.dida365.cn/hc/all/4f5529e99e8606a255de6288ee83f28a.png)


::::

::::tab [desktop]

- 方式一：右键单击任务，选择「标签」添加已有标签或创建新标签。

![--71.11%](https://cdn.dida365.cn/hc/all/16a924832dfcf27c621bc5e523e275eb.png)

- 方式二：创建任务时输入「#」或在任务详情中输入「#」快速创建标签。

![--80.32%](https://cdn.dida365.cn/hc/all/1100a2d12c67ba9106ae18d81651767b.png)

- 方式三：将任务拖动到已有标签上快速为任务添加标签。

![--71.11%](https://cdn.dida365.cn/hc/all/55c0eb6176fdd0c637209d48c7a7f201.png)

# 管理标签

:::::tabContainer [mobile|desktop]

::::tab [mobile]
在侧边栏左滑某个标签，会出现「置顶」「编辑」和「删除」3个选项。

- 点击「编辑」图标，即可进入「标签编辑」页面，你可以修改标签的颜色和上级标签。操作成功后，所有包含该标签的任务都会对应更新。
- 点击「删除」图标，该标签会从侧边栏、和任务上移除，但任务并不会被删除。

![l](https://cdn.dida365.cn/hc/all/c8924ac6d7bfe16137d4bf7ab20abcee.png)


你也可以在左侧边栏底部点击「管理清单和标签」-「标签」，进入对应标签的编辑页面。

![](https://cdn.dida365.cn/hc/all/b37de3b754c79cfc1628b5c00f9f153b.png)

::::

::::tab [desktop]
右键单击某个标签，会出现「置顶」「编辑」和「删除」等选项，点击「编辑」选项，即可进入「标签编辑」页面。

![--71.11%](https://cdn.dida365.cn/hc/all/dfecc84ba07b23d2e64cffb40a2683b2.png)

##  创建二级标签
标签层级支持创建「二级标签」。
在侧边栏中拖动标签至另一标签下方，即可为拖动的标签选择上级标签。


![m](https://cdn.dida365.cn/hc/all/679a17867dbb4930395aeadddf9a2f10.png)

你也可以左滑某一标签，点击「编辑」，为其选择上级标签。


![l](https://cdn.dida365.cn/hc/all/7ba6fdf6e582658f0ea71593fb603fa0.png)


##  标签排序

滴答清单支持用户对标签进行自定义排序，通过在侧边栏「长按标签」即可进行拖拽，可以对清单进行自由排序。

另外，你也可以在任务列表 -「···」-「排序」中，将任务按标签进行排序，帮助你更加快速地了解自己的日程安排。

![m](https://cdn.dida365.cn/hc/all/87d13f93e5d3c7ea049c1b22fbef4a8d.png)
