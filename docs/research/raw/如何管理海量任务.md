# 如何管理海量任务

> 原文: https://help.dida365.com/articles/6950652964327391232
> articleId: 62c654031e3a8b2ac64c82ad

滴答清单提供了强大的管理任务方式，一共5个层级，包括「文件夹」-「清单」-「分组」-「任务」-「子任务」，能够帮助你高效管理海量任务。

![l](https://cdn.dida365.cn/hc/all/8c312c0d431478da314a2dfd9dcf9be6.png)


- [文件夹](/articles/6957521286893404160)：文件夹常被用来管理清单。如果你的同类清单数量较多，例如：会议、报告、差旅，你可以创建一个“工作”文件夹去整理它们。

- [清单](/articles/6950654234933067776)：清单可以被用来对任务进行分类整理。你可以根据个人的生活和工作安排创建常用清单，将同类任务放入同一个清单。另外，清单还可以被共享出去，与他人进行协作。

- [分组和排序](/articles/7054273336087412736)：每个项目里的小分类，如「部门会议」、「 项目会议」。

- [任务](/articles/6950361599374786560)：任务是进行日程管理的基础层级。

- [子任务](/articles/6950660746367729664)：子任务是比任务低一级的层级，任务可以被拆分成几个子任务，一一达成。

除此之外，我们还提供了「[标签](/articles/6950656299306582016)」、「[过滤器](/articles/6950655961044353024)」，帮助你更好的管理任务。

::: spoiler 清单和标签、过滤器的区别？
- 清单是任务的归属地，每个任务必须放在某一个清单里。
- 标签是任务的属性标记，同一个任务可以有多个标签，并且可以跨清单使用。
- 过滤器是智能筛选器，帮你自动筛选展示符合条件的任务，例如日期为下周 + 高优先级的任务。
:::
