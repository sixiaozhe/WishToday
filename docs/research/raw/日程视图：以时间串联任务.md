# 日程视图：以时间串联任务

> 原文: https://help.dida365.com/articles/7213438708429619200
> articleId: 6682564f47c89fff9258f132

滴答清单桌面端提供日程视图，你所有安排好时间的任务会显示在一个时间轴中以线性的方式展示，滚动鼠标滚轮即可轻松查看。

在浏览日程视图中，你可以同时看到过去已完成的任务、当前的进度和未来的计划，有助于你追踪自己每天的时间线，及时调整计划，促进规划和安排。

![](https://cdn.dida365.cn/hc/all/c03dbc33d6baaabc498bb3eaa8a5c04e.png)


## 如何开启日程视图？

点击日历右上角切换视图的选项，选择“日程视图”。

![](https://cdn.dida365.cn/hc/all/527f07a761e980ed83e316983ffec6b4.png)
