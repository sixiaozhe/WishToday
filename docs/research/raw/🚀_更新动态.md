# 四象限升级！多套视图随心切换 🔄（11月2日）
现在，四象限已经支持创建并保存多套视图。无论是工作、生活，还是不同项目，都可以拥有各自独立的象限设置。

![--56.3%](https://cdn.dida365.cn/hc/all/4acafebd1322458ec486c334bbdcae59.png)

无需反复修改象限规则，就能在不同领域或项目之间轻松切换，让不同场景的任务都能独立、有序管理。

> 使用方式：点击四象限右上角「...」-「管理视图」即可添加视图。

# ✨ 编辑与任务管理体验优化（9月15日）

这次，我们优化了编辑、整理和浏览任务的体验，让记录内容、整理任务和查找信息都更加顺手。

## 编辑体验优化

![--56.25%](https://cdn.dida365.cn/hc/all/e3226797deabd012034edf89f5d59338.png)

- Markdown 编辑更清爽

现在，编辑 Markdown 内容时，格式符号会自动隐藏，你不会再被 `#`、`*` 等符号干扰，可以更专注于正在记录的内容。

- 更多高亮颜色

现在，已支持更多高亮颜色，你可以用不同颜色标记区分不同信息，让重要内容更加醒目。

- 长内容阅读更轻松

任务详情内容较多时，你可以通过标题暂时折叠不需要查看的章节，也可以随时展开查看，让长篇笔记、会议记录或项目资料更容易浏览。

## 分组与排序体验优化

![--56.25%](https://cdn.dida365.cn/hc/all/13c4457d6ddcdb0d4da3b501686ec9d9.png)

新增按**创建时间分组**，以及按**创建时间、修改时间排序**，你还可以自由选择排序从新到旧还是从旧到新，方便快速找到最近添加或更新的任务，整理清单中的任务更加方便。

## 其他更新

- 新增视图多端独立配置

Android、Web 已支持分别设置清单视图，手机和电脑可以使用不同的视图配置。

- 更多字号选项

iOS、Android 已支持更小的应用字号，一屏可以展示更多任务。

> 调整方式： 设置 → 外观 → 显示 → 字体大小

# 倒数纪念日体验优化｜记录更加灵活 ✨（3月9日）

为了让重要日子的记录方式更加灵活，本次更新为纪念日新增了多项功能：

## 新增天数计算方式

在添加纪念日时，现在支持选择是否将当天计为第 1 天，让天数计算方式更加符合不同场景的需求。

![--56.3%](https://cdn.dida365.cn/hc/all/e18ac9d0137f70a1c6e0aa6ed7ac23fb.png)

> 使用方式：添加纪念日 → 选择日期 → 在「天数计算方式」中选择「标准」或「标准 +1 天」。

## 新增自定义重复

倒数纪念日现在支持更灵活的重复规则，例如每年 X 月第 X 个星期几、每月的 X 日 等，可以满足更多纪念日提醒场景的需求。

![--56.3%](https://cdn.dida365.cn/hc/all/8514ac0a9fcd17f7bf49061f6c192e39.png)

> 使用方式：进入一个纪念日 → 点击右上角「...」进入「编辑」 → 点击「重复」 → 选择「自定义重复」。

## 新增备注功能

现在，你还可以为每一个纪念日添加备注，用来记录属于这一天的提醒信息或独特记忆。

![--56.3%](https://cdn.dida365.cn/hc/all/48f8c28808d48370b2659cfe22489edf.png)

> 使用方式：进入倒数纪念日详情页 → 点击左下角备注图标 → 添加备注。

## 其他功能更新

- PC 端新增习惯桌面小部件

PC 端现已支持习惯打卡桌面小组件，无需打开应用，即可在桌面查看习惯并完成打卡，日常记录更加方便。

- 日历支持自定义图标显示

现在，你可以自由选择是否在「日历」中显示内容的类型图标。点击日历右上角「…」 → 「显示设置」 → 「样式」 → 「显示类型图标」即可设置。

- iOS 与电脑端支持暗色主题

现在，iOS 与电脑端也已经支持自定义暗色主题颜色。你可以进入【设置】 → 【外观】 → 【主题】 → 选择【夜间】主题，并挑选喜欢的主题色即可。


# 8.0 重磅更新｜任务与日历体验全面升级 🚀（1月8日）
这次更新，我们重点升级了任务规划与日历体验，希望通过更清晰的信息结构与视觉呈现，帮助你在不同时间尺度下，更轻松地安排事情、回顾时间。
