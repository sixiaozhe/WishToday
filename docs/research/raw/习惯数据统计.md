# 详情页的数据统计
在习惯详情页的统计中，我们提供了「月度打卡表」和「打卡数据」，你可以随时查看自己的打卡情况。
:::::tabContainer [mobile|desktop]

::::tab [mobile]
在单个习惯页面中向上滑动就能够看到这个习惯整体的打卡数据。
![--100%](https://cdn.dida365.cn/hc/all/01b70380df1b976437d728b8f6876d37.gif)

::::

::::tab [desktop]
点击当个习惯就能在右侧查看到习惯整体的打卡数据。

![--58.83%](https://cdn.dida365.cn/hc/all/705156aedbf8b669045edce67df3779d.png)
::::

:::::

## 习惯年度热力图
在打卡数据中点击「更多」，还能够进入到该习惯的年度热力统计页，方便你回顾这一年的完成情况。

![l--101.59%](https://cdn.dida365.cn/hc/all/0b7fdbed441d429a76de6fd88fb0dd05.png)

# 回顾习惯打卡情况
点击习惯页面中的统计图标，就能够查看到所有习惯的打卡情况。

![m--216.42%](https://cdn.dida365.cn/hc/all/5645b386ca6a82b7a32890c7801ed86a.png)

## 周、月视图
你可以快速查看这周的习惯打卡统计，高级会员还能够直接查看你这一整个月的习惯打卡进度。

![l--101.59%](https://cdn.dida365.cn/hc/all/d5ff8be5087693c5f0c890b7ba50b6d3.png)

::: spoiler 如何在电脑端查看周、月视图？
目前仅支持手机端查看。

:::

## 记录回顾
在记录中你可以更好的查看到每天习惯的完成情况，点击「>」还能够查看到具体完成的时间轴。
如果你记录了打卡日志，在时间轴中也能展示出来。

![l--101.59%](https://cdn.dida365.cn/hc/all/1f78e2e1a9528358d2d0f5aa0db25573.png)
