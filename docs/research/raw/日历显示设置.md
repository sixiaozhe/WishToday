# 颜色

日历中只有一个颜色，不仅显得单调，也不好区分不同的任务、习惯与纪念日。你可以为任务、习惯和纪念日设置不同的显示颜色，一眼区分各类内容。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
点击日历右上角「**···**」-「**显示设置**」-「**颜色**」，即可设置任务、习惯和纪念日的颜色显示方式和显示颜色。

![--66.01%](https://cdn.dida365.cn/hc/all/6d0b26bc36dc0acd8ceb27e6fad6060a.png)

::::

::::tab [desktop]
点击日历右上角「**···**」-「**显示设置**」-「**颜色**」，即可设置任务、习惯和纪念日的颜色显示方式和显示颜色。

![--65.64%](https://cdn.dida365.cn/hc/all/64dbe58fcc42f98a379b34cb2714e8d6.png)

## 任务颜色

任务支持选择「**按清单**」、「**按标签**」、「**按优先级**」显示颜色。选择「按清单」或「按标签」时，可在下方直接自定义清单/标签的颜色，「按优先级」则使用固定优先级颜色。

![--65.97%](https://cdn.dida365.cn/hc/all/01ddbabe9e138bbc5d6f48336975d603.png)


## 习惯&纪念日颜色

习惯与纪念日可选择**固定颜色**显示（所有习惯/纪念日使用同一个颜色），或为每个习惯/纪念日**单独设置颜色**，两种方式均可在下方自由选择颜色。

![l--101.54%](https://cdn.dida365.cn/hc/all/10296f7b7256ca7968e5a648ccdf89a2.png)

# 样式

想要日历的界面风格更符合你的个人品味？你可以点击日历右上角「**...**」-「**显示设置**」，找到「**样式**」，按喜好选择「**现代**」或「**经典**」样式。

![--66.01%](https://cdn.dida365.cn/hc/all/6749f80d8f89d8b5b6a0fcb230944c6e.png)


此外，你还可以在样式中设置「**显示类型图标**」，自由控制是否显示任务、订阅日历、习惯、倒数纪念日等内容的类型图标。

::::tab [mobile]

# 辅助时区
生活中有跨国工作、旅行等场景，需要同时协调多个时区的日程安排，如何让不同时区的时间对照更加直观呢？启用“辅助时区”吧！

:::::tabContainer [mobile|desktop]

::::tab [mobile]
点击日历右上角「...」-「显示设置」，找到「辅助时区」并启用。启用后，日历视图的时间轴可以显示多个时区。


![](https://cdn.dida365.cn/hc/all/afa01f0af2da4ef354266583a3ef5e83.png)

点击「添加时区」，可以自由选择添加你需要的时区，并为不同的时区设置图标与备注。长按并拖动，可以对你添加的时区进行排序。
::::

::::tab [desktop]
点击日历右上角「...」-「显示设置」，找到「辅助时区」并启用。启用后，日历视图的时间轴可以显示多个时区。

![](https://cdn.dida365.cn/hc/all/114b6bb63c6f684799405432629b2435.png)


点击「辅助时区」下方「时区设置」，可以自由选择添加你需要的时区，并为不同的时区设置图标与备注。
::::

:::::

提示：多时时区的上限为五个，包含一个当前时区和四个可配置时区。

# 批量操作
为了帮助你更高效地管理任务安排，现已支持在日历视图中进行批量操作。

操作方式：
按住 Ctrl（Windows）或 Command（Mac），使用鼠标点选或框选多个任务进行批量操作，包括右键批量完成、删除任务等，以及拖动批量修改任务时间。

::: video https://cdn.dida365.cn/hc/all/b312c221646caf7f795744e7d3dbfd24.mp4
:::

该功能适用于临时调整项目计划、周计划优化、清理过期任务等场景，让任务管理更高效、操作更顺畅。
> Windows & web 已上线，macOS 正在开发中。

# 推迟功能
新增了「推迟」功能，让你可以批量选择任务，一键将所有任务时间延后1小时，帮你轻松调整被打乱的计划。

操作方式：
在任务列表或者日历中批量选择任务后，点击“推迟”按钮将被选中的任务的时间进行批量延后。

::: video https://cdn.dida365.cn/hc/all/a77aed41693d243e153a8984eb593593.mp4
:::



无论是临时会议、交通堵塞，还是意外插入的新安排，都能快速应对，保持任务清单井然有序。
> Windows & web 已上线，macOS 正在开发中。
# 其他显示选项
:::::tabContainer [mobile|desktop]

::::tab [mobile]
你可以在日历视图的右上角「···」-「显示设置」中来设置。

![l](https://cdn.dida365.cn/hc/all/d76ded1e822cc856307977a1a4ffd052.png)


- 点击「显示详细」，可以在日历中显示任务的详细属性如时间、所属清单等。
- 点击「显示已完成」，可以在日历中显示已完成的任务、打卡和订阅的日历事件。
- 点击「显示检查事项」，可以在日历中显示任务中设置的检查事项。
- 点击「显示所有重复周期」，设置重复的任务会在日历中按重复周期进行重复显示。
- 点击「显示打卡」，可以在日历的任务栏里显示打卡。
- 点击「显示专注记录」，可以在日历中显示专注记录。
