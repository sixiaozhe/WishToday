# 搜索任务

> 原文: https://help.dida365.com/articles/7473271683613196288
> articleId: 6a339aa06dd5c0432b3bd943

对于任务较多的用户，搜索功能可以帮助你快速查找任务、清单和标签，无需逐个浏览列表。

# 搜索入口
:::::tabContainer [mobile|desktop]

::::tab [mobile]

在「**设置**」→「**功能模块**」中启用「**搜索**」后，即可通过底部 tab 栏进入搜索页面。

::::tab [desktop]

点击侧 tab 栏中的搜索按钮即可进入搜索页面。

:::::

# 搜索任务、清单和标签

进入搜索页面后，在顶部搜索框中输入关键词即可开始搜索。

搜索框下方提供「任务」「清单」和「标签」三种搜索类型。选择对应类型后，可以快速查找相关任务、清单或标签。

![l--101.59%](https://cdn.dida365.cn/hc/all/b6ad21e5dd07f0a6cebf778d802b867c.png)

# 使用筛选条件搜索

**当选择搜索「任务」时**，你还可以组合筛选条件进一步缩小搜索范围，包括清单、标签、优先级、日期等，更精准地定位目标任务。

如果经常使用同一组筛选条件，可以将当前搜索条件保存为过滤器。保存后，无需重复设置筛选规则，只需打开对应过滤器，即可快速查看符合条件的任务。
