# iCloud 日历

> 原文: https://help.dida365.com/articles/7190959639616290816
> articleId: 66308f0b47c89fff9258e204

当你想在滴答清单中查看 iCloud 日历，你可以通过订阅 iCloud 的方式，轻松实现。

# 添加日历

进入「设置」-「导入与关联应用」-「日历」，点击「iCloud」，添加 iCloud 账号。

![--65.93%](https://cdn.dida365.cn/hc/all/b7f83aea9b0fe8a8ebd971872f8e61e8.png)

iCloud 要求需要有 App 专用的密码才能连接账号。

# 获取专用密码
iCloud 要求生成一个App专用的密码才能连接账号，点击「生成 App 专业密码」选项，前往 Apple 网站。在页面中登录你的 Apple ID后，选择 App 专用密码生成密码。将获取到的密码，输入滴答清单中完成添加账号。


![--65.93%](https://cdn.dida365.cn/hc/all/841d480c912aadd06eb0beae02201a0c.png)


# 添加日历事件

订阅成功后，你可以在滴答清单中订阅日历中看到日历，并且点击「+」，可添加日程。添加成功后，也会同步到 iCloud 日历中。 

![--65.93%](https://cdn.dida365.cn/hc/all/87599015c3eda8492853319e98e8ccc8.png)
