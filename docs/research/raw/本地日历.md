# 本地日历

> 原文: https://help.dida365.com/articles/7193075395720118272
> articleId: 6638417f47c89fff9258e401

如果你想要在滴答清单中显示当前设备中的日历事件，你可以通过订阅本地日历的方式轻松实现。


# 添加日历
:::::tabContainer [mobile|macOS]

::::tab [mobile]
在「设置」-「导入与关联应用」-「本地日历」，开启「开关」即可在日历中查看本地日历。


![l](https://cdn.dida365.cn/hc/all/ff4f73344b6536b723ab4e049761a89d.png)


::::

::::tab [macOS]
点击「头像」，选择「设置」-「导入与关联」-「本地日历」，开启「开关」即可在日历中查看本地日历。

![](https://cdn.dida365.cn/hc/all/349dfb516dd992a54093a360c5d0205c.png)
![](https://cdn.dida365.cn/hc/all/5c985e1e2ec1a3637f84c01192616f67.png)



你还可以对本地日历进行设置「显示」、「仅日历中显示」、「隐藏」状态。

::::

:::::

> 目前仅安卓、iOS、Mac 客户端可设置本地日历。


# 查看日历事件
订阅成功后可以在侧边栏「订阅日历」中查看日历事件。
