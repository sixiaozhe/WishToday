# 管理倒数纪念日

> 原文: https://help.dida365.com/articles/7322147514604322816
> articleId: 680dd1461c42a13a390ba033

管理你的重要日子，让每一个倒数纪念日清晰有序，重要时刻一目了然。


# 分组
当你添加了越来越多的纪念日，为了更好地浏览和管理，可以点击倒数纪念日首页右上角「...」开启「显示分组」。开启后，所有日子将根据类型自动分组：**倒数日、纪念日、生日、节日**。

::::tab [mobile]
你可以点击顶部分组名称或左右滑动页面切换分组，管理更高效，分类更清晰。

# 编辑

想修改纪念日名称？输入日期有误？需要调整类型或者计时方式？别担心，随时可以轻松编辑，保持信息准确无误。

:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入对应的倒数纪念日页面，点击右上角「...」-「编辑」，即可修改图标、名称、日期、重复、类型、计时方式、提醒等信息，快速更新内容。

![](https://cdn.dida365.cn/hc/all/c288deb7fb0eed3ff7e1eab9c6727c17.png)


::::

::::tab [desktop]
右键单击或者点击倒数纪念日卡片右上角「...」，选择「编辑」，即可修改图标、名称、日期、重复、类型、计时方式、提醒等信息，灵活调整。

![](https://cdn.dida365.cn/hc/all/72514f53fb32364d305e6dc05a403ecc.png)

::::

:::::


# 置顶

项目截止日期，考试日期，婚礼倒计时...... 想让当前最关心的倒数纪念日始终优先呈现？

:::::tabContainer [mobile|desktop]

::::tab [mobile]

进入倒数纪念日页面，点击右上角「...」-「置顶」，即可将这个日子固定在列表顶部，随时查看，无需翻找。

![](https://cdn.dida365.cn/hc/all/1d1a36a2516d30f4935a2426687a66bc.png)


::::

::::tab [desktop]

鼠标悬停在倒数纪念日卡片上，点击右上角「置顶」按钮，即可将其固定在列表第一位，方便随时查看，无需反复寻找。


![](https://cdn.dida365.cn/hc/all/297911019e39961ef65095c11b9d102d.png)

::::

:::::


# 归档

一些已经完成的倒数纪念日，不舍得删除？可以选择归档，既保留回忆，又让主列表保持清爽。

:::::tabContainer [mobile|desktop]

::::tab [mobile]

进入倒数纪念日页面，点击右上角「...」-「归档」，即可将它收纳到「已归档」列表中，整洁又不丢失重要回忆。

![l](https://cdn.dida365.cn/hc/all/3498a4559f1ed6ad38860cbe632886aa.png)


::::

::::tab [desktop]

右键单击或者点击这个倒数纪念日卡片右上角「...」，选择「归档」，即可将其移入「已归档」列表中，保持主列表清爽。

![](https://cdn.dida365.cn/hc/all/b2841976a22ff8ec7a9828f18be7077e.png)

::::

:::::

# 删除

已取消的倒计时、不再需要的纪念日，可以选择彻底删除，让你的列表更简洁清爽。

:::::tabContainer [mobile|desktop]

::::tab [mobile]

点进该倒数纪念日，点击右上角「...」-「删除」，轻松清理冗余项目，释放空间。


![l](https://cdn.dida365.cn/hc/all/8e751a9c1013c6271e9776aa06f77b46.png)


::::

::::tab [desktop]

右键单击或者点击倒数纪念日卡片右上角「...」，选择「删除」，让列表保持干净有序。

![](https://cdn.dida365.cn/hc/all/0ee2c64ab8de0697a5c10cb98820ed30.png)

# 添加到实时活动（iOS）

有些重要日子想时刻记在心上？可以将倒数纪念日添加到实时活动，直接显示在锁屏上，无需打开 App，也能随时查看。

进入一个倒数纪念日，点击右上角「...」-「添加到实时活动」，即可将它固定到锁屏。

![--65.97%](https://cdn.dida365.cn/hc/all/cf1a90413156b896bec784d870dea170.png)

# 常见问题

::: spoiler 倒数纪念日支持滑动操作吗？
支持！在倒数纪念日列表中左滑，即可快速进行置顶、归档或删除操作，管理更高效。


![m](https://cdn.dida365.cn/hc/all/78e5ba8c5c1e54b6518c37e1cc05f5e4.png)


:::


::: spoiler 可以同时置顶多个纪念倒数日吗？
目前只支持置顶一个倒数纪念日，其他项目将按照时间自动排序。
:::

::: spoiler 删除的倒数纪念日可以找回吗？
删除操作不可恢复，请谨慎操作。如需保留记录，推荐使用「归档」功能代替删除。
:::
