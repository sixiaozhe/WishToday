# 认识四象限
四象限是一种基于**艾森豪威尔矩阵（Eisenhower Matrix）的任务管理方法，通过任务的重要程度和紧急程度，** 将任务分为四个象限，帮助你明确优先级，把时间和精力集中在真正重要的事情上。

四个象限分别是：
- **重要且紧急**：需要优先处理的任务，例如即将截止的重要工作。
- **重要不紧急**：对长期目标有帮助，但不需要立即完成的任务，例如学习计划、个人成长。
- **紧急不重要**：需要尽快处理，但重要程度较低的任务，例如部分临时事务。
- **不重要不紧急**：优先级较低，可以延后处理的任务。

![l](https://cdn.dida365.cn/hc/all/78e864183c6a2ffbb48f72fe96c959ba.png)

::: spoiler 任务如何显示在四象限中？
四象限会根据设置的[筛选规则](https://help.dida365.com/articles/6950381682822217728)，自动将符合条件的任务显示在对应象限中。你也可以根据自己的需求，自定义各个象限的筛选条件。

需要注意的是，**四象限只是任务的另一种展示方式**。任务仍然保留在原来的清单中，不会因为出现在四象限里而被复制或移动到其他清单。
:::

# 开启四象限
你可以在移动端或桌面端开启「四象限」功能，开启后即可通过四象限视图管理任务。


:::::tabContainer [mobile|desktop]

::::tab [mobile]
前往「设置」>「功能模块」，开启「四象限」。开启后，可通过底部导航栏进入四象限。


![](https://cdn.dida365.cn/hc/all/0c291393535674fe1290c472f2a9b7cc.png)


::::

::::tab [desktop]
点击头像，前往「设置」>「功能模块」，开启「四象限」。开启后，可通过侧边栏进入四象限。

![](https://cdn.dida365.cn/hc/all/19a769e378b8f61e2b9b53bd914da583.png)


::::

我们会根据你对任务设置的优先级，自动将任务放入到对应的象限中。

# 使用四象限管理任务
## 添加任务
你可以直接在四象限中创建任务。长按并拖动「+」按钮至任意象限，即可在对应象限中添加任务。


![l](https://cdn.dida365.cn/hc/all/5fc7e1d5f81b0312bc14f60536f1d50b.png)


新建任务时，系统会根据所在象限的规则，自动设置相应的任务属性。

例如，在「重要且紧急」象限中创建任务，系统会自动将任务日期设置为今天，优先级设置为高。

![m](https://cdn.dida365.cn/hc/all/fdc2a734ca5932942159499cdd9ce582.png)


任务仍会保留在原来的清单中，你也可以在对应的清单或「今天」视图中查看。


> 当然你在清单中添加任务，也会根据你设置的属性自动判断当前所属的象限。


## 移动任务
长按任务并将其拖动至其他象限，即可调整任务的分类。系统会根据目标象限的规则，自动调整相应的任务属性。

![m](https://cdn.dida365.cn/hc/all/f349395e6bc0bfa1330db5a6ce496b19.gif)


同样，当你修改任务的日期、优先级等属性时，四象限也会根据筛选规则，自动更新任务的显示位置。

## 象限中的操作

:::::tabContainer [mobile|desktop]

::::tab [mobile]
点击任一象限后，点击右上角的「...」按钮，可以执行以下操作：
**编辑象限、显示详细、显示已完成、显示检查事项、排序、分享、打印、批量编辑**等。

![](https://cdn.dida365.cn/hc/all/cb3fa1171a125d6033576e9229698cc0.png)

# 常见问题

::: spoiler 如何隐藏或显示已完成任务？
在四象限页面，点击右上角的「···」，选择「隐藏已完成」或「显示已完成」，即可切换已完成任务的显示状态。
:::

::: spoiler 为什么同一个任务会出现在多个象限中？
如果一个任务同时符合多个象限的规则，就会同时显示在这些象限中。你可以检查各象限的规则设置，确认是否存在重叠。
:::


::::::: spoiler 如何调整四象限顺序？
:::::tabContainer [mobile|desktop]

::::tab [mobile]
点击右上角「...」，选择「编辑」，选中需要更改顺序的象限，拖动调整即可。

![m](https://cdn.dida365.cn/hc/all/23e72f6b48b2525124bf728527865386.gif)

::::

::::tab [desktop]
点击单个象限直接拖动调整即可。

![l](https://cdn.dida365.cn/hc/all/0db624b75b1a73e46433e941deb68074.gif)
