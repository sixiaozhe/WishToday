# Outlook 日历

> 原文: https://help.dida365.com/articles/7190959706343473152
> articleId: 66308f1b47c89fff9258e20d


如果你想要在滴答清单中显示 Outlook 中的日历事件，你可以通过订阅 Outlook 的方式轻松实现。

# 添加日历

:::::tabContainer [mobile|desktop]

::::tab [mobile]
进入「设置」-「导入与关联应用」-「日历」，选择 Outlook，进行授权，授权成功后即订阅成功。


![](https://cdn.dida365.cn/hc/all/e45c5c7173408da2ec65a52a90758728.png)


::::

::::tab [desktop]
点击头像 -「设置」-「关联与导入」，选择 Outlook，进行授权，授权成功后即订阅成功。

![](https://cdn.dida365.cn/hc/all/ceac230a0ac9b9344848036ec7a4736a.png)

::::

:::::


# 查看日历事件
订阅成功后可以在侧边栏「订阅日历」中查看日历事件。
