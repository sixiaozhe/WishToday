# 月视图：每月总结复盘

> 原文: https://help.dida365.com/articles/6950640298334617600
> articleId: 62c648371e3a8b2ac64c81ae

总结复盘是自我成长的重要法宝。按月对工作、生活、学习做一个总结回顾，可以让我们的成长轨迹更加清晰明确🌲。

滴答清单的「月视图」提供了一整个月的全局概览。
- 当你需要回顾一整个月做了哪些事情，看一下月视图就能轻松搞定。
- 当你需要规划某件事时，不妨先看看月视图，合理安排时间。


![](https://cdn.dida365.cn/hc/all/2e08ee047a7d43265c44d94b829704b1.png)


# 添加任务
除了常规添加任务的方法，你还可以在月视图中直接创建一个超长时间段任务。
进入月视图，长按起始日期的单元格，向左/向下拖动至结束日期，松开鼠标即可创建。

![](https://cdn.dida365.cn/hc/all/649abb1ae069df0f8647ebd53e3c94c7.png)



# 回顾任务
对照当初制定的月目标，回顾这一个月完成任务的情况。

清单太多，任务太多，怎么分门别类地回顾任务呢？很简单，筛选一下清单吧。你可以根据生活中不同的方面，如工作、生活、学习等，来筛选清单。

**缩放调整显示的周数**

想更灵活地查看近期计划？你还可以使用**双指捏合**手势缩放调整显示的周数：向外张开可放大显示更少的周数、更多任务，向内捏合可缩小恢复整月显示。

![l](https://cdn.dida365.cn/hc/all/4bbf5b0f07add2c89d9af50e9a68b9f2.png)




缩放至多周视图，你还可以点击右上角「**恢复默认**」图标快速返回整月视图。

# 总结本月
分析原因并总结，是复盘至关重要的步骤：

- 从经历中找到金子：明确自己的成果
- 从失败中找到教训：知晓自己的不足

总结规律，能够从中提炼出方法和规律，不仅有助于解决该具体案例中的问题，还能够解决某一类问题。
记录心得才是这次复盘的关键，用「笔记」保存下来吧👉[笔记](/articles/6950671600370843648)

1. 新建一个“总结复盘”的笔记清单，创建一个笔记“ 8 月复盘”。

![--64.31%](https://cdn.dida365.cn/hc/all/64fb4fce27e51240b8c3ae148311e2d3.png)

2. 双击该笔记，打开独立弹窗。

![--64.31%](https://cdn.dida365.cn/hc/all/6a15893c08910be7a450ae7a12d9746a.png)

3. 将日历界面显示 8 月，查看这一个月里的任务情况，轻松复盘 ✌️。

![--64.31%](https://cdn.dida365.cn/hc/all/e804e5d5532ab36150caca6fa6d0a160.png)
