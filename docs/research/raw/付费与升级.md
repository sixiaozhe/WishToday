# 礼品卡

时间是最宝贵的礼物。为他人或者自己购买一张礼品卡，享受一年高级会员权益，认真过好每一天吧。👉[购买入口](https://dida365.com/card)

![--54.3%](https://cdn.dida365.cn/hc/all/18f2bd378b32da5a111a98246d5f0b58.jpg)


礼品卡邮件中的兑换码可用于兑换高级会员。你可以通过以下途径来兑换：

- 邮件：复制兑换码 - 点击「在滴答清单中兑换」 - 「兑换」页面 - 输入兑换码；
- Android：进入「设置」页面 -「升级到高级账户」- 页面底部「兑换」- 输入兑换码；
- 网页端：点击「头像」-「设置」-「高级会员」-「兑换」- 输入兑换码。

兑换成功后，会员权益立即生效。

# 发票

如果你是通过微信、支付宝进行支付的，可以在 Web 端对近1年的订单记录申请开具、查看并下载电子发票。

具体操作步骤如下：

桌面端：
1. 点击头像 - 「设置」，在左侧边栏中点击「高级会员」；
2. 点击「历史订单」，即可查看近期订单记录并开具发票。

移动端：
1. 点击「设置」- 头像，在头像下方点击「高级会员」；
2. 下滑到页面底部，点击「历史订单」，即可查看近期订单记录并开具发票。

申请开票成功后，我们将在3个工作日内向您开具电子发票。您可在开具发票页面了解开票进度、查看及下载发票。

> 已退款的订单不支持开具发票。


如果你是通过苹果App Store进行支付的，在支付后将收到苹果发送到邮箱的订单的电子收据。请注意，由于苹果渠道支付的款项是由美国苹果公司收取的，我们无法为你开具发票，需前往苹果应用商店开具电子收据，具体请联系苹果客服（400-666-8800）。



# 退款
:::::tabContainer [iOS|Android|macOS|Web]

::::tab [iOS]
由于苹果官方限制，开发者无权直接处理退款申请。如果您是在 iOS 或 macOS 平台订阅的滴答清单高级会员，需要直接向苹果申请退款。具体步骤如下：
1. 前往 reportaproblem.apple.com ；
2. 使用您的 Apple ID 和密码登录；
3. 在请求帮助栏内选择「请求退款」；
4. 按照页面上的说明选择退款原因并提交申请即可。 更多关于向苹果官方申请退款的内容可参考： 针对从 Apple 购买的 App 或内容申请退款 。
::::

::::tab [Android]
在 Android 端使用支付宝或微信购买的高级会员，可以在 Android 端对购买 14 天内的订单申请退款，超过 14 天将无法申请退款。
1. 点击「设置」- 头像，在头像下方点击「高级会员」；
2. 下滑到页面底部，点击「历史订单」，即可查看符合退款条件的订单，申请退款。申请退款成功后，我们将在3个工作日内为你处理退款。您可在历史订单页面/预留的邮箱中查看退款进度。
> 已开具发票的订单不支持退款。
> 使用支付宝连续包月的用户，除了以上的方式外，也可以在支付宝应用中，进入「设置」 - 「支付设置」 - 「免密支付/自动扣款」中取消。
::::

# 取消自动续费

## **取消 Apple 订阅：** 
可以去到 App Store 中 - 点击头像 - 订阅 - 找到滴答清单订阅然后取消即可。具体操作可以参考：

https://support.apple.com/zh-cn/HT202039

##  **取消支付宝订阅：**
  如果你是使用支付宝连续包月的用户，可以在支付宝应用中，进入「设置」 - 「支付设置」 - 「免密支付/自动扣款」中取消滴答清单的订阅。
	
	
# 常见问题
::: spoiler 使用支付宝支付时，为什么没有出现支付宝支付的界面？
支付宝支付会弹出新的网页进行支付，可能是浏览器阻止了新的页面弹出，请在浏览器设置界面中打开允许弹出窗口的设置。
:::


::: spoiler 高级账户到期后数据会丢吗？
我们非常注重保护您的数据安全。高级账户到期后，您的数据将被完整保留，您依然可以像免费账户一样正常使用滴答清单，但不能继续享受高级账户对应的特权。
:::
