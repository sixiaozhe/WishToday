# 滴答清单（Dida365）功能调研

> 调研日期：2026-11-05  
> 资料来源：滴答清单帮助中心 <https://help.dida365.com>（抓取 98 篇帮助文档，原文见 `raw/`）、官方功能介绍页 <https://dida365.com/features>、官方定价页 <https://dida365.com/upgrade?language=zh_cn>、官方下载页 <https://dida365.com/download>。  
> 目标：为“无需登录、无需购买会员、功能完整”的复刻产品提供功能边界、业务规则、数据模型和验收依据。

---

## 1. 结论先行

滴答清单不是一个单纯的待办列表，而是由 **5 个核心模块 + 6 类视图 + 一套跨平台能力** 组成的个人时间管理系统：

- 核心模块：任务、日历、四象限、番茄专注、习惯打卡、倒数纪念日、笔记/摘要。
- 任务视图：列表、看板、时间线、日历（日/三日/周/月/年/日程/列表/课表）、四象限。
- 组织体系：文件夹 → 清单 → 分组 → 任务 → 子任务（最多 5 级），外加标签（二级）和过滤器。
- 提醒体系：多提醒、持续提醒、结束提醒、重复提醒、农历、法定工作日/节假日、艾宾浩斯、位置提醒（iOS）。
- 跨平台：Web、Windows、macOS、Linux、iOS/iPadOS、Android、HarmonyOS、手表、浏览器插件、小组件、桌面便签。
- 开放能力：URL Scheme、Siri/快捷指令、MCP、CLI、API 口令、CSV 备份、第三方日历订阅、第三方应用导入。
- 游戏化：成就值（12 级）、勋章。

“完美复刻”在功能层面可行；**云端协作、微信生态、应用商店会员、iOS 系统级能力** 需要替代方案或原生开发。复刻版建议采用 **本地优先（local-first）+ 可选自建同步** 架构，把官方的高级会员限制全部取消，并把依赖云端的 AI、分享、MCP 改为“自带密钥 / 本地服务”。

## 4. 功能模块详解

### 4.1 任务（Task）

#### 4.1.1 添加任务

支持入口：

- 桌面清单顶部任务添加栏，回车创建；`Shift+Enter` 添加描述，`Cmd/Ctrl+Enter` 创建。
- 移动端全局 `+` 按钮；按钮位置可左右拖动，鸿蒙支持“智感握姿”自动换边。
- 底部功能栏顺序可自定义（日期、优先级、标签、清单等）。
- 全局快捷键 `Ctrl/Cmd + Alt + A` 呼出快速添加条。
- 小组件添加。
- 语音添加：长按 `+` 模式、录音模式（最长 30 分钟，Pro 可同时保存录音和文字）。
- 微信：公众号发文字/语音/图片；`@滴答小助手`（Pro）。
- 邮件：专属邮箱链接、`todo@mail.dida365.com`（需注册邮箱）。
- Siri / iOS 快捷指令。
- 剪贴板：识别含时间信息的内容；多行文本可批量创建。
- 浏览器插件、右键菜单、微博 @ 等。
- 任务模板、任务副本、任务链接 `[[` 快速引用。

添加时可以设置：日期、时间段/全天/跨天、优先级、标签、清单、提醒、重复、附件、子任务、模板。

#### 4.1.2 任务字段与详情

| 字段 | 规则 |
|---|---|
| 标题 | 必填；支持智能识别日期/时间/重复/提前延后提醒 |
| 正文 | 富文本 + Markdown；标题、加粗、高亮（多色）、斜体、下划线、删除线、有序/无序/待办列表、引用、代码块、分割线、链接、日期、图片、文件、视频、录音 |
| 日期 | 单日、时间段、全天、跨天；固定时间 / 固定时区 |
| 提醒 | 最多 5 个（免费 2 个）；自定义时间、多个提醒、结束时间提醒；持续提醒 |
| 重复 | 每天/每周/每月/每年/法定工作日/法定节假日/每周末/农历每年/农历每月/艾宾浩斯/自定义 |
| 优先级 | 无、低、中、高（内部值 0/1/3/5） |
| 标签 | 多标签，可跨清单 |
| 清单 | 任务必须归属一个清单；可快速搜索移动 |
| 检查事项 | 可勾选、排序、单独设提醒；完成进度自动计算；全部完成时主任务自动完成 |
| 子任务 | 最多 5 级；每级功能与普通任务一致；可拖动生成、关联主任务、取消关联 |
| 附件 | 图片、录音、文件、视频；免费 1 个/天、10MB、20 个/任务；Pro 199 个/天、20MB、39 个/任务 |
| 进度 | 0-100%；有检查事项时按检查事项完成比例自动计算 |
| 评论 | 共享清单协作；个人清单可当备注 |
| 置顶 | 列表最前端 |
| 状态 | 未完成 / 已完成 / 已放弃 / 已删除（垃圾桶） |
| 动态 | 创建、修改、完成等历史；共享时记录操作人 |
| 分享 | 文本、图片、日程链接 |
| 转换 | 任务 ↔ 笔记（带子任务的任务不能转笔记） |
| 模板 | 保存为模板；从模板添加 |
| 专注 | 开始专注、预计番茄/时长 |
| 锁定屏 | iOS 实时活动 / 鸿蒙实况窗 |

#### 4.1.3 状态与特殊操作

- 完成：勾选复选框；重复任务完成后生成下一周期。
- 放弃：不删除但不再执行；进入“已放弃”；可重新开始。
- 删除：进入垃圾桶，可恢复。
- 副本：复制任务。
- 跳过重复周期：跳过当前周期；重复任务未完成前不能操作后续周期。
- 仅此周期：在日历中修改重复任务的单个周期。
- 批量操作：多选后改日期、清单、优先级、标签、完成、删除、合并、分享、关联主任务、分配。
- 推迟：批量把选中任务时间延后 1 小时。
- 滑动操作：移动、删除、改日期；完成、置顶；可自定义。
- 拖动：排序、改清单、加标签、变智能清单条件、变子任务、取消子任务。

#### 4.1.4 智能识别（NLP）

必须支持中文自然语言，例如：

- “1 月 10 号下午两点补油漆”
- “明早十点开会”
- “每周五 13:00 安排下周工作”
- “提前 30 分钟提醒”
- “农历 8 月 15 日”
- 模糊时间统一解析为“最近有效时间”（下午 4 点输入“9 点提醒我”→ 今天晚上 9 点）
- 识别后可点击已识别时间取消；设置中可关闭智能识别。

#### 4.1.5 推荐任务

“今天”清单提供推荐任务，规则：

- 最近添加：刚刚/今天/昨天添加且未设时间的新任务。
- 多次修改时间：修改超过 2/3/5 次的任务，按修改次数降序。
- 长时间未完成：创建超过 7/14/30 天未完成。
- 即将到来：明天、后天到期。
- 推荐范围为所有无重复、非今天的未完成任务；可一键加入“今天”。

### 4.2 组织体系：文件夹、清单、分组、标签、过滤器

#### 4.2.1 智能清单

| 智能清单 | 规则 |
|---|---|
| 所有 | 所有未删除任务 |
| 今天 | 到期日为今天；可含习惯/纪念日（可配置） |
| 明天 | 到期日为明天 |
| 最近 7 天 | 未来 7 天 |
| 收集箱 | 未分配清单的任务；不可隐藏/删除 |
| 指派给我 | 共享清单中分配给我的任务 |
| 已完成 | 已完成任务 |
| 已放弃 | 放弃的任务 |
| 垃圾桶 | 删除的任务，可恢复 |
| 摘要 | 任务完成情况摘要生成器 |

显示状态：显示 / 隐藏 / 有内容时显示（自动）。

#### 4.2.2 普通清单

- 创建时设置名称、颜色、图标（Emoji）、所属文件夹、是否在智能清单显示。
- 类型：任务清单 / 笔记清单。
- 背景：跟随主题、纯色、渐变、图片（仅移动端）；已完成/已放弃/垃圾桶不支持背景。
- 编辑、置顶、删除、左滑操作。
- 清单内可共享、设置通知、任务提醒范围、在智能清单显示范围。
- 视图配置可跨设备同步或按端独立（Android/Web 支持）。
- 清单/任务数量：免费 9 个清单、99 任务/清单；Pro 299 个清单、999 任务/清单。复刻版取消限制。

#### 4.2.3 文件夹

- 用于组织清单；可创建、重命名、解散；解散后清单保留。
- 移动端可拖动清单到另一清单上创建文件夹。

#### 4.2.4 分组（看板列 / 清单内分组）

- 仅普通清单支持自定义分组；智能清单只能用智能分组。
- 智能分组：按清单、时间（今天/明天/最近 7 天/以后/已过期）、优先级（高/中/低/无）、标签、指派人、创建时间。
- 分组排序、重命名、删除、拖动、组内添加任务。
- 看板视图由分组驱动；看板列宽小/中/大三档；可显示看板颜色。

#### 4.2.5 标签

- 多标签；二级标签；颜色；置顶；自定义排序。
- 添加方式：任务详情、输入 `#`、拖动任务到标签、右键。
- 删除标签只移除标签，不删除任务。
- 可按标签分组/排序/筛选/日历着色。

#### 4.2.6 过滤器

- 普通筛选：清单、标签、日期、优先级、关键词等多维组合。
- 高级筛选：逻辑词“且/或”，多语句查询；同一条件内标签也支持且/或；支持预览模式。
- 保存为过滤器，侧边栏常驻；搜索条件也可保存为过滤器。

### 4.3 视图

#### 4.3.1 列表视图

- 垂直列表；分组 + 排序。
- 排序：时间、优先级、创建时间（新→旧/旧→新）、修改时间（新→旧/旧→新）、手动。
- 分组：自定义分组、清单、时间、优先级、标签、指派人、创建时间。
- 拖动排序；拖动生成子任务；置顶；滑动操作；批量编辑。
- 显示设置：显示已完成、检查事项、日期显示为倒数日等。

#### 4.3.2 看板视图

- 任何普通清单、智能清单、文件夹、标签均可切换看板（时间线不支持部分智能清单）。
- 列 = 分组；卡片 = 任务；可拖动改分组，从而改属性。
- 支持自定义分组列，重命名、新建、删除。
- 团队场景：按指派人分组、任务评论、任务动态。
- 显示设置：列宽、显示输入框、显示看板颜色（Mac 暂不支持）。

#### 4.3.3 时间线视图

- 横向时间轴；任务按开始/结束时间显示长度。
- 只能显示有时间的任务；无时间任务在右侧“安排任务”栏，可拖入。
- 点击空白处按日期创建任务。
- 缩放：天/周/月显示比例。
- 拖动任务改开始时间；拖动边缘改时长；跨周跨月连续查看。
- 不支持显示所有重复周期。
- 智能清单“所有/收集箱/今天/最近 7 天”等不支持时间线。

#### 4.3.4 日历视图

视图类型：

- 日视图、三日视图（移动端）、周视图（桌面端为时间轴；移动端支持时间轴/格子两种样式）。
- 月视图（可双指缩放调整显示周数，恢复默认）。
- 年视图（热力图；点击月跳月视图、点击日期跳周视图；可切换年份）。
- 日程视图（桌面端，线性时间轴串联任务）。
- 列表视图（按天展示，可显示时间轴）。
- 课表视图（课程表）。

周视图结构：

- 全天任务栏：未设时间、全天、跨天任务。
- 竖向时间轴：有时间任务。
- 默认隐藏 00:00-07:00、21:00-00:00，可展开/调整。
- 双指缩放时间轴、隐藏时间段、调整全天栏高度。
- 多日视图、多周视图（仅桌面端）。
- 拖动任务改时间；拖动边缘改时长；Ctrl/Option+拖动复制任务。

显示设置：

- 显示范围（筛选清单）。
- 颜色：任务按清单/标签/优先级；习惯/纪念日统一色或单独色。

#### 4.3.5 四象限（艾森豪威尔矩阵）

- 四象限：重要且紧急、重要不紧急、紧急不重要、不重要不紧急。
- 规则方案：
  1. 优先级（默认）：高→重要且紧急，中→重要不紧急，低→紧急不重要，无→不重要不紧急（以官方默认映射为准）。
  2. 时间 + 优先级：时间判断紧急，优先级判断重要。
- 自定义规则条件：清单、标签、时间范围、优先级、指派人；多条件为“且”。
- 一个任务可同时出现在多个象限。
- 拖动任务到其他象限会修改任务属性；任务日期变化会自动换象限。
- 象限可改名、调整顺序、排序、显示详细/已完成/检查事项、分享、打印、批量编辑。
- 多视图：最多 9 个自定义四象限视图，各自独立规则；可切换、重命名、排序、删除。
- 新建任务：拖 `+` 到象限，自动按象限规则设置属性（如重要且紧急→今天+高优先级）。
- 小组件支持切换视图。

## 6. 复刻版的关键设计决策

### 6.1 无需登录

- 首次启动创建本地档案（Profile），不要求邮箱/手机号。
- 数据默认存本地 SQLite（桌面）或 IndexedDB（Web/PWA）。
- 可选设置应用锁（PIN/系统生物识别），但不是账号体系。
- 可选“多档案”用于工作/生活隔离。
- 可选“自建同步”：WebDAV、Syncthing、局域网、或自建 API；不依赖官方云。

### 6.2 无需会员

- 所有限额取消，并在设置中提供“性能保护”上限（例如单清单 10 万任务、附件总大小）而非商业限制。
- 官方主题、图标、背景全部可用；另加自定义主题。
- AI 使用用户自己的 API Key（OpenAI 兼容 / Ollama / 本地模型），不设月度额度。
- MCP / CLI 直接连本地数据库，不做 OAuth。

### 6.3 云端能力的替代

| 官方能力 | 复刻替代 |
|---|---|
| 多端同步 | 本地优先；可选自建同步（WebDAV/Syncthing/CRDT 服务） |
| 共享清单 | 本地多档案；或自建服务 + 邀请链接；或导出/导入 |
| 微信提醒/小助手 | 本地通知、邮件、Telegram/Bark/Webhook |
| 邮件创建任务 | IMAP 轮询 / 本地 SMTP 收件 / 手动导入 |
| 微信/微博/QQ 登录 | 不需要登录 |
| 微信二维码共享 | 自建邀请码/链接 |
| 课表教务网导入 | 手动添加、图片 OCR（本地 PaddleOCR/Tesseract）、ICS 导入 |
| Google/iCloud/Outlook 订阅 | 标准 ICS URL 订阅；本地日历读取（平台原生） |
| Notion 关联 | 导入/导出 Markdown；可选 Notion API（用户自带 Token） |
| 官方 AI | 自带 Key 的 AI 助手/语音/录音总结 |
| iOS 系统闹钟/实时活动/小组件 | 需要原生开发；Web/PWA 只能降级为通知 |
| 桌面便签/全局快捷键 | Tauri/Electron 原生能力 |
| 微信小程序 | 不做或做独立 Web/PWA |

### 6.4 品牌与合规

- 不复制滴答清单的商标、Logo、图标、插画、文案和像素级 UI。
- 功能可以等价，视觉与命名应原创；URL Scheme 建议使用自有 scheme（如需兼容自动化，可提供可配置映射）。
- 不抓取、不内置官方付费内容（主题、铃声、字体）除非有合法授权。

## 9. 风险与注意事项

| 风险 | 说明 | 应对 |
|---|---|---|
| 品牌/版权 | 直接复制 UI、图标、文案、主题可能侵权 | 功能等价、视觉原创、名称独立 |
| 微信生态 | 公众号、小助手、微信提醒依赖官方平台 | 替换为本地通知/邮件/Webhook/Telegram |
| iOS 系统能力 | 闹钟、实时活动、小组件、位置提醒需原生 | 桌面/Web 先降级；移动端原生补齐 |
| 法定节假日 | 每年调休数据变化 | 内置年度数据 + 可更新数据源 |
| 农历 | 转换和闰月复杂 | 使用成熟库（如 lunar-typescript / 6tail）并测试 |
| OCR/教务网 | 课表格式多样、教务网需适配 | 先手动/ICS，OCR 作为增强 |
| 同步冲突 | 本地优先多端同步复杂 | 先单机；后续用 CRDT/版本向量 |
| AI 成本 | 无官方额度后需用户自付 | 支持本地模型 + 自带 Key + 明确提示 |
| 性能 | 大量任务/附件/全文搜索 | 索引、分页、虚拟列表、FTS |
