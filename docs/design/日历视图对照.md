# 日历视图对照（滴答清单截图 → Dayline）

> 参考图：`docs/design/日历视图/`（日视图、周视图、月视图、年视图、日程视图、多日视图、多周视图）
> 日期：2026-11-05

---

## 1. 从截图提取的设计语言

### 1.1 顶栏

- 左侧：日历图标 + **月份标题**（如“9月”），年视图为“2026年”。
- 右侧：`+`、视图下拉（如“日⌄”）、上一段/今天/下一段、更多。
- 不再用大段范围标题（“11月2日 – 11月8日”）。

### 1.2 时间网格（日/周/多日）

- 一周从**周日**开始。
- 顶部日期栏：星期在上、日期在下；今天用蓝色圆形数字。
- “全天”独立一行，放在时间轴上方。
- 时间轴默认展示 **08:00–20:00**，隐藏凌晨；每小时一条横线，12:00 显示“正午”。
- 任务按 **开始/结束时间** 渲染为时长块，而不是简单列表。
- 块内：复选框 + 标题 + 时间范围；颜色使用清单色的浅色背景。
- 当前时间显示红色指示线。
- 重叠任务按泳道并排。

### 1.3 月视图

- 一周从周日开始。
- 单元格显示日期数字；今天用蓝色圆形。
- 任务是小色块：复选框 + 标题 + 时间（右侧）；无时间任务不显示时间。
- 单元格高度足够显示多条任务，超出再折叠。
- 月份标题只显示“9月”。

### 1.4 年视图

- 12 个迷你月历，按 3×4 或 4×3 排列。
- 日历格子用蓝色深浅表示当天任务密度（热力图）。
- 月份标题可点击跳转。

### 1.5 日程视图

- 按天分组的线性时间轴。
- 左侧日期 + 星期，右侧时间刻度与任务卡片。
- 任务卡片显示时间范围 + 标题，颜色浅色。
- 适合快速浏览连续几天。

### 1.6 多日 / 多周

- 多日视图：3 天时间网格，结构同日/周视图。
- 多周视图：2 周紧凑格子，任务以条状块显示，不显示小时刻度。

### 1.7 底部视图切换条

- 悬浮在底部中央的深色胶囊。
- 选项：年视图 / 月视图 / 周视图 / 日视图 / 日程视图 / 多日视图 / 多周视图。
- 当前视图高亮；右侧有“立即升级”（复刻版不需要）。

## 2. 当前已对齐

- 顶栏：月份标题、`+`、视图下拉、上一段/今天/下一段。
- 日/周视图：08:00–20:00 时间轴、全天行、按时长渲染任务块、复选框、时间范围、当前时间线。
- 周视图：周日开始、今天蓝色圆形、浅色任务块。
- 月视图：周日开始、今天圆形、任务小色块 + 时间。
- 底部深色视图切换条：年/月/周/日/日程/多日/多周。
- 年视图：12 个迷你月历 + 任务密度热力图 + 点击日期/月份跳转。
- 日程视图：按天分组的时间线卡片。
- 多日视图：3 天时间网格。
- 多周视图：2 周紧凑格子。
- 农历/节日标签：月视图显示春节/元宵/清明/端午/中秋/教师节/国庆等主要节日；隐藏财神节、天灸日等冷门条目。
- 拖拽：周/月/多周改日期，日/周/多日改时间；拖动时间块底边改结束时间（非重复任务）。

|---|---|---|
| 法定节假日/调休数据 | 2026 已接入 | 月视图显示 `休`/`班`；其他年份降级为周一至周五/周末，年度更新流程见 `docs/specs/法定节假日数据.md` |
| 隐藏时间段设置 | 已接入 | 日历“⋯”中配置开始/结束小时，持久化到本地库 |
| 重复任务单周期操作 | 已接入 | 拖拽/改时间写入 override；详情支持“跳过此周期”和“恢复默认时间” |
| 多任务重叠泳道优化 | 部分 | 已按泳道并排，但未按重叠簇细分宽度 |
| 年视图密度算法 | 初版 | 按当天任务数量分 4 档，后续可按专注时长/完成率加权 |
| 日程视图拖拽 | 未做 | 目前只支持点击打开 |
| 任务块跨天显示 | 已接入 | 月视图/全天行分段连续显示，时间块按天分段；拖动整体平移结束日期 |

## 4. 下一步建议顺序

1. 年度法定节假日数据更新（2027 及以后）。
2. 日程视图拖拽、重叠泳道细化。
3. 跨天任务在周/日视图的持续条视觉打磨。
4. 自动合并后的提示与历史说明优化。
5. 视觉打磨：颜色/字号/间距与截图逐项对照。

> 品牌边界：布局与信息密度对齐滴答，但不复制其图标、插画、文案、主题素材和像素级界面。
