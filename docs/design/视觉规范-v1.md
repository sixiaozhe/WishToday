# 视觉规范 v1

> 目标：让从滴答清单迁移过来的用户“不用重新学”，但一眼能看出这是另一个产品。
> 原则：**视觉语言一致，品牌资产原创**。不复制 Logo、图标、插画、文案、主题、铃声、字体和像素级界面。

---

## 1. 设计原则

1. **高密度但可呼吸**：一屏能看到足够多任务；行高、留白、分割线克制。
2. **层级靠排版，不靠重装饰**：标题、正文、元信息用字号/颜色区分，少用阴影和边框。
3. **操作就近**：完成、删除、改期等高频操作出现在任务行/详情当前上下文。
4. **颜色有语义**：优先级、清单色、标签色、危险操作各自稳定，不随意复用。
5. **键盘优先**：桌面端核心流程可用键盘完成；快捷键可发现。
6. **深浅一致**：浅色/深色使用同一套 token，不单独写死颜色。

---

## 2. 布局

| 区域 | 尺寸 | 说明 |
|---|---|---|
| 左侧栏 | 252px | 品牌、智能清单、清单、标签、底部设置 |
| 顶栏 | 56px | 当前视图标题、任务数、搜索、主题切换 |
| 内容区 | 自适应 | 标题、快速添加、任务分组列表 |
| 详情栏 | 360px | 任务详情；窄屏变为覆盖层 |
| 内容左右留白 | 26px（桌面）/14px（移动） | 保持高密度 |
| 任务行高 | 约 52–64px | 标题 + 元信息两行 |

响应式断点：

- `> 1180px`：三栏（侧栏 + 内容 + 详情）。
- `861–1180px`：侧栏 + 内容；详情从右侧覆盖。
- `<= 860px`：单栏；侧栏抽屉；详情全屏覆盖。
- `<= 520px`：搜索框收成图标，展开后占满顶栏。

## 3. Design tokens

代码位置：`apps/web/src/styles.css` 的 `:root` 与 `[data-theme="dark"]`。

### 3.1 颜色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f6f7f9` | `#101216` | 应用背景 |
| `--bg-elevated` | `#ffffff` | `#171a20` | 卡片/任务行/详情 |
| `--bg-sidebar` | `#fbfbfd` | `#14171c` | 侧栏 |
| `--bg-hover` | `#f0f2f5` | `#20242c` | 悬停 |
| `--accent-soft` | `#e9efff` | `#1b2a49` | 选中/激活 |
| `--text` | `#1f2329` | `#e7e9ee` | 主文本 |
| `--text-secondary` | `#596170` | `#a5acb8` | 次要文本 |
| `--text-muted` | `#8b929e` | `#7b8290` | 元信息/占位 |
| `--border` | `#e6e8ec` | `#262b34` | 分割线/边框 |
| `--border-strong` | `#d4d9e1` | `#363d49` | 控件边框 |
| `--accent` | `#3b6ef6` | `#6b96ff` | 主色/选中/完成 |
| `--danger` | `#e5484d` | `#ff6b6b` | 删除/危险 |
| `--success` | `#12a150` | `#35c27a` | 成功/完成态 |
| `--warning` | `#d97706` | `#f0a23a` | 警告/中优先级 |

优先级色：

- 低：`#3b82f6`
- 中：`#f59e0b`
- 高：`#ef4444`

> 主色与滴答的蓝色系保持同一语义，但不直接取官方色值；后续如需更接近，可在 token 层调整，不影响组件。

### 3.2 字号

| 层级 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 22px | 680 |
| 视图标题 | 15px | 650 |
| 任务标题 | 13.8px | 400/500 |
| 正文/备注 | 13px | 400 |
| 元信息 | 11.5px | 400 |
| 分组标题 | 12px | 650 |
| 侧栏分组 | 10.5px | 700（大写/字距） |

字体：`"Segoe UI", "Microsoft YaHei", system-ui, -apple-system, sans-serif`。不内置官方字体。

### 3.3 间距与圆角

- 间距基准：4px；常用 6/8/10/12/16/20/24。
- 圆角：控件 7px，卡片/列表 10px，大容器 14px，标签 999px。
- 阴影：仅用于浮层/详情覆盖；列表本体用边框和 1px 间隔。

## 4. 组件规范

### 4.1 侧栏

- 品牌区：31px 方形渐变标记 + 产品名 + “本地优先”副标题。
- 智能清单：图标 17px，文字 13.5px，右侧计数 11px。
- 选中态：`--accent-soft` 背景 + `--accent` 文本；不使用左侧粗色条。
- 清单：8px 色点 + 名称 + 计数。
- 新建清单：行内输入，Enter 提交，Esc 取消。
- 底部：主题切换 + “数据默认保存在本机”。

### 4.2 任务行

- 左侧圆形复选框 18px；完成后填充主色并显示对勾。
- 标题 13.8px；完成态删除线 + 弱化色。
- 第二行元信息：日期/时间、清单色点、标签、删除态。
- 优先级：左侧小旗，低蓝/中橙/高红；无优先级不显示。
- 悬停/选中显示删除/恢复按钮；移动端常显。
- 点击整行打开详情；复选框和操作按钮阻止冒泡。

### 4.3 快速添加

- 单行输入，左侧 `+`，右侧 `Enter` 提示与“添加”按钮。
- 聚焦时主色边框 + 3px 光环。
- 在“今天”视图添加时自动带今天日期；在清单视图添加时归属该清单；其他视图默认收集箱。

### 4.4 任务详情

- 标题输入 19px；备注多行 13px。
- 日期/时间/优先级/清单两列网格；窄屏单列。
- 标签为可切换 pill。
- 底部固定操作区：完成/重新打开 + 删除/恢复。
- 垃圾桶任务显示顶部提示条。

### 4.5 空态

- 56px 圆角图标容器 + 标题 + 一句说明。
- 文案短、具体、不卖萌；不使用官方插画。

### 4.6 按钮

- 主按钮：主色填充，白字，高 32px。
- 次按钮：边框 + 次要文本。
- 危险按钮：红色文本 + 边框，悬停浅红底。
- 图标按钮：30px 方形，悬停浅底。

## 5. 交互规范

| 操作 | 行为 |
|---|---|
| `N` | 聚焦快速添加（输入框内不触发） |
| `Enter` | 提交快速添加 / 标题编辑确认 |
| `Esc` | 关闭详情 / 关闭侧栏 |
| 点击任务行 | 打开详情 |
| 点击复选框 | 完成/取消完成，不打开详情 |
| 悬停任务行 | 显示删除/恢复 |
| 切换视图 | 关闭详情，保留搜索词 |
| 主题切换 | 立即生效，持久化到本地 |

后续补充：拖拽矩阵、批量选择、右键菜单、日历/看板/时间线操作。

---

## 6. 与滴答清单的边界

| 可以一致 | 必须原创 |
|---|---|
| 三栏布局、任务行信息结构 | Logo、应用图标 |
| 高密度列表、分组标题位置 | 插画、空态图 |
| 快速添加的交互路径 | 文案、提示语 |
| 优先级/清单色/标签的语义 | 主题命名、付费主题素材 |
| 快捷键习惯 | 字体、铃声、音效 |

**验收**：把截图并排看，布局节奏和操作路径相似；但品牌、图标、插画、文案明显不同。
