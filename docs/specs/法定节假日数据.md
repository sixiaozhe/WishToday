## 2. 判定规则

### 2.1 法定工作日

```text
if 日期在表中:
  type = workday → 上班
  type = holiday → 不上班
else:
  周一至周五 → 上班
  周六周日 → 不上班
```

包含调休上班日，例如 2026-10-10（周六）算上班。

### 2.2 法定节假日

```text
if 日期在表中:
  type = holiday → 放假
  type = workday → 不放
else:
  周六周日 → 放假
  周一至周五 → 不放
```

包含周末；因此“法定节假日”重复会落在所有周末 + 法定放假日期。

### 2.3 数据缺失年份

当前只内置 2026 年。其他年份自动降级为“周一至周五上班 / 周末放假”，UI 会提示数据范围。

---

## 3. 在应用中的使用

- **日历标签**：月视图显示 `休` / `班` 徽标；主要节日名称由农历/公历节日库提供。
- **重复规则**：
  - “法定工作日”：跳过法定放假日期，包含调休上班日。
  - “法定节假日”：命中法定放假日期和普通周末。
- **未来**：可把数据写入 `holiday_calendar` 表，支持用户更新年度数据；当前用代码内静态数据，保证离线可用。

---

## 4. 年度更新流程

1. 获取国务院办公厅下一年度放假通知。
2. 在 `packages/core/src/holidays.ts` 增加 `addRange` / `addDay`。
3. 更新 `HOLIDAY_DATA_YEARS`。
4. 增加对应单元测试（放假、调休、跨年边界）。
5. 更新本文档与 `docs/design/日历视图对照.md`。

> 不要用算法推算调休；每年安排由国务院发布，必须使用权威数据。
